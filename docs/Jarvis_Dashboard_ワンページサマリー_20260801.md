## 30秒で分かる

Jarvis ダッシュボードは、**秘書 AI が集めた情報を「見る」ためのハブ**。  
重い収集は Mac、表示は Vercel、直しは Cursor で**承認後**に実行する。  
朝・夜に開く入口は **ホーム（Soft Card）**: 要確認カード（赤／橙／青）＋メールざっと見→クリックで詳細。

---

## 何ができるか（いま）

| 領域 | できること |
|---|---|
| **ホーム** | 状況ウォッチの要注意＋メール pending を一目で。詳細は `/mail/[id]` |
| **レーン** | パートナー／オプチャ／それ以外のトリアージ詳細 |
| **状況ウォッチ** | 電力・ETC・Vポイント・LINE 公式エクスポート・815・Zaim 品質 など |
| **数値** | 家計 CF・電力など（モチベーション用） |
| **課金** | SaaS／定額・従量の一覧（やめ時・無料枠の注視） |
| **NotebookLM** | Drive `200_NoteBookLM` 作業セット（Mac は Finder＋ブラウザ） |

---

## 設計の芯（4つ）

1. **見る＝クラウド／集める＝Mac**（iPhone でも閲覧可）
2. **気になることはレベル付きで見せる**（要確認／注意／参考。ok はホームに出さない）
3. **勝手に外へ出さない**（メール送信・Zaim 変更は承認後）
4. **正本は YAML／ファイル、DB は投影**（作り直せる）

```text
[考える] OneDrive 検討メモ
   → [実装] git-repos（コード・YAML）
   → [投影] Supabase jarvis-dashboard
   → [見る] Vercel ホーム
   → [伝える] Drive 200_NoteBookLM → NotebookLM
```

## ホームの見方（今夜・明朝）

1. 上の数字チップで「要確認が何件か」
2. 赤カードがあれば先に状況ウォッチへ
3. メールはざっと流し、気になる行だけタップして本文
4. 「直して」は画面上の見直し／送信確認、または Cursor に依頼（無確認では送らない）

**見た目**: Soft Card（余白・角丸・左ボーダー）。BI の巨大KPIボードにはしない。
