# 参謀室 · 週次統括 — 設計メモ（2026-08-30）

## 方針

ホークアイは **松野の指示の転送係だけにしない**。  
毎週、各部長・統括と会話して全体を統括し、**アテンション・QOL・Not-to-do** を松野へ返す。

## 追加で提言するとよいこと（運用提案）

| # | 提言 | 理由 |
|---|---|---|
| 1 | **矛盾検知**を週次必須にする | リソース制約 vs 買い進め件数、本業繁忙 vs 家族、など |
| 2 | **カード年会費・大型引落**をアテンション候補に常設 | 過去の失敗パターン。リソース部長から吸い上げ |
| 3 | **委任漏れリスト** | 松野がチャットで抱えている仕事を統括へ戻す |
| 4 | **Not-to-do を数字で** | 「来週の並行テーマは最大3」など上限を宣言 |
| 5 | （任意）水曜お昼の **5行パルス** | 週次だけだと火消しが遅い週用。負荷増ならスキップ可 |
| 6 | 週次結果を `10_inbox_from_grok/` に1枚 | Jarvis がダッシュボード／状況ウォッチへ投影しやすい |
| 7 | 家族コーチ週次（21:00）と **重複しない要約** | ホークは横断、家族統括は家庭詳細 |
| 8 | **Notion タスク登録・整理** | MTG／レビュー → 登録。30日停滞・置き換え・重複を整理（§Notion） |
