# Grok アドバイザー週次材料パック — 仕様（2026-09-26）

## 目的

全家系アドバイザーが、SecondBrain（1週間）・パートナーやり取り・アプリ更新を踏まえて助言し、**★Journal に無い重要情報をメンション**して松野の解像度を上げる。

## Journal の位置づけ

| 旧 Implicit | 正（本仕様） |
|---|---|
| Journal に全部書いてある前提 | Journal は **大切なこと・理解していること** の正本 |
| 無い＝起きていない | 無い＝まだ理解レイヤに載せていない可能性 → メンション対象 |

SB全文を Journal に常時ミラーしない（Hot = Genspark）。

## 入口・確認・履歴・停止

| 柱 | 内容 |
|---|---|
| 入口 | Genspark Meeting API（金締土〜金）／215 `5.やり取り.md` 差分／git・PR |
| 確認 | パックは評価材料のみ。対外送信・Todoist無言起票なし |
| 履歴 | Drive `outbox_to_teams/*` ＋ `.jarvis_state/advisor_weekly_pack.json`（Mac）／API応答（Cloud本線） |
| 停止 | `JARVIS_ADVISOR_WEEKLY_PACK_DISABLE=1` または state `disabled`。**GSK_API_KEY を Grok に渡さない** |

## 取得のきっかけ（クラウド本線）

1. **コーチング部長** 日曜 19:00 ルーティンが Vercel `POST /api/advisor-weekly-pack` を叩く
2. 応答ボディのパック MD をその場の材料にする（Mac スリープ可）
3. 任意で Drive outbox へ永続（Mac スクリプト or 後続）
4. ホーク 20:00・各チームは outbox／チャンネル残を消費

フォールバック: FRIDAY Mesh → Mac 上 `jarvis_advisor_weekly_pack.py --apply`（Mac 要起動）

## パックスキーマ

```markdown
# 週次材料パック · 金締 YYYY-MM-DD〜YYYY-MM-DD
## A. SecondBrain（要約のみ）
## B. パートナーやり取り（差分）
## C. アプリ更新
## D. Journalギャップ候補（必須）
## E. チーム別フォーカス
```

ルーティング語彙: `config/advisor_weekly_pack_routing.yaml`

## Grok 返答必須

- 「Journalに無い重要」節を1つ以上（該当なしなら「ギャップなし」）
- SB全文・メール原文の再掲禁止

## 関連コマンド

```bash
cd ~/git-repos && set -a && source .env.jarvis_private && set +a
~/selenium_env/venv/bin/python scripts/jarvis_advisor_weekly_pack.py --dry-run
~/selenium_env/venv/bin/python scripts/jarvis_advisor_weekly_pack.py --apply
```

Cloud: `POST https://jarvis-dashboard-amber.vercel.app/api/advisor-weekly-pack`  
Header: `Authorization: Bearer $ADVISOR_WEEKLY_PACK_SECRET`（または `x-advisor-pack-secret`）
