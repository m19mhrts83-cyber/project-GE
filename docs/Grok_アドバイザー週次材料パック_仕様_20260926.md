# Grok アドバイザー週次材料パック — 仕様（2026-09-26）

## 目的

全家系アドバイザーが、SecondBrain（1週間）・パートナーやり取り・アプリ更新を踏まえて助言し、**★Journal に無い重要情報をメンション**して松野の解像度を上げる。

## Journal の位置づけ

| 旧 Implicit | 正（本仕様） |
|---|---|
| Journal に全部書いてある前提 | Journal は **大切なこと・理解していること** の正本 |
| 無い＝起きていない | 無い＝まだ理解レイヤに載せていない可能性 → メンション対象 |

SB全文を Journal に常時ミラーしない（Hot = Genspark）。

## 入口・確認・履歴・停止

| 柱 | 内容 |
|---|---|
| 入口 | Genspark Meeting API（金締土〜金）／215 `5.やり取り.md` 差分／git・PR |
| 確認 | パックは評価材料のみ。対外送信・Todoist無言起票なし |
| 履歴 | Drive `outbox_to_teams/*` ＋ `.jarvis_state/advisor_weekly_pack.json`（Mac）／API応答（Cloud本線） |
| 停止 | `JARVIS_ADVISOR_WEEKLY_PACK_DISABLE=1` または state `disabled`。**GSK_API_KEY を Grok に渡さない** |

## 取得のきっかけ（運用正 · 2026-09-27〜）

| 優先 | 経路 | いつ |
|---|---|---|
| 1 | **Drive outbox**（`週次材料パック_*.md`） | Mac launchd **日曜 18:40** `jarvis_advisor_weekly_pack.py --apply` |
| 2 | **Computer Skill**（env の `ADVISOR_WEEKLY_PACK_SECRET` · 値はチャット禁止） | コーチング部長 日曜〜19:00 · Mac 起動時 |
| 3 | **Vercel** `POST /api/advisor-weekly-pack` | 検証・Cloud直叩き。Bearer 必須 |
| 4 | 失敗1行＋薄い材料 | FRIDAY Mesh 可 |

1. **コーチング部長** 日曜ルーティン先頭でパックを取得（Drive 優先）
2. ホーク 20:00・各チームは outbox／チャンネル残を **読むだけ**（再取得しない）
3. **GSK_API_KEY は Grok に渡さない**（サーバー／Mac env のみ）

教訓: Skill に Bearer **値**未投入だと 401。値貼付より Drive 本線＋Computer の env 参照が正。

## パックスキーマ

```markdown

## A. SecondBrain（要約のみ）
## B. パートナーやり取り（差分）
```

ルーティング語彙: `config/advisor_weekly_pack_routing.yaml`

## Grok 返答必須

- 「Journalに無い重要」節を1つ以上（該当なしなら「ギャップなし」）
- SB全文・メール原文の再掲禁止
