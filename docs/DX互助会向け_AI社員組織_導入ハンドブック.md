## 第1部：AI社員組織 導入ハンドブック（メンバー向け実務手順）

### 1. はじめに：なぜ「AI社員組織」なのか？
サラリーマン大家にとって、最大の制約は「時間」です。
ChatGPTに都度プロンプトを打つ「一問一答の相談」では、毎回人間が前提を教え、指示を出さねばならず、結局手間が減りません。

本パッケージは、**「神大家さん倶楽部の英才教育を叩き込んだAI社員たちを、Grok Botに配属し、チームとして自走させる」** ためのスターターキットです。
PCを閉じてもクラウド上で24時間働き、毎朝のポータル探索から夕方の業者アプローチ、購入後の周辺MAPチラシ作成までを自動で推進します。

#### コストと教育についてのリアルな考え方
- **ランニングコストの目安**:
  - **ライトに試す場合**: **月額 約4,000円（20ドル）**（Cursor Proプラン）
  - **しっかり本格自走させる場合**: **月額 約9,000円（60ドル）**（Cursor Pro Plusプラン）
  - どちらもドル払いですが、パートや外注を1人雇う費用（月数万〜十数万円）に比べれば、10名の専属チームをこの価格帯で雇えるコストパフォーマンスは圧倒的です。
- **「社員の教育」という本質**:
  - どんなに優秀な人間やAIを採用しても、**「自社のやり方やオーナーのこだわり」を教える教育**は不可欠です。
  - 教育については、本ハンドブックを参考に**ご自身でプロンプトを育てる形**でも進められますし、**松野による個別伴走サポート（教育代行・チューニング）**を活用して即戦力化することも可能です。

### ステップ 2：自分の投資基準設定（買い進めプランの選定ヒアリング）

#### 【最重要】物件調査の前提：「買い進めプラン」を固めてから探す
神大家さん倶楽部の「基礎講座 STEP3（買い進めプランニング）」の教えにある通り、**「何の物件を買うべきか（ゴール）」を決めずにポータルを見ても、良い物件には一生巡り会えません。**
本パッケージでは、物件調査に入る前に、オーナーが現在どの「買い進めプラン」に該当する物件を探すのかを**質問形式で聞いて固めた上で、S1（物件調査）が調査に入る設計**になっています。

大筋の選択肢は、神大家STEP3の具体例に基づく以下の**3大プラン**です：

| # | 買い進めプラン | 想定価格帯 | 目標表面利回り | 土地値割合（積算）目安 | 主な融資・購入戦略 | 狙い・特徴（神大家STEP3具体例） |
|---|---|---|---|---|---|---|
| **1** | **築古戸建て** | **200万〜600万円**<br>（指値前提） | **15%〜20%以上**<br>（満室想定） | **70%以上**<br>（路線価重視・共同担保） | 現金購入 または<br>リフォームローン | 自己資金を保全しつつ手堅くCFを構築。<br>将来の売却やアパート融資時の共同担保原資に。 |
| **2** | **築古アパート** | **1,500万〜4,000万円** | **11%〜15%前後** | **60%〜70%以上** | 地銀・信金・信販<br>（セゾン・トラスト等） | まとまったCFを一気に加速。<br>S4（修繕）と連携した分離発注・再生バリューアップが鍵。 |
| **3** | **新築アパート** | **6,000万〜1.5億円** | **7.0%〜8.5%前後** | **12%〜15%以上**<br>（新築水準） | アパートローン・提携ローン<br>（オリックス・auじぶん等） | 本業の属性をフル活用したフルローン規模拡大。<br>S3需給・S5ペルソナ分析で新築高稼働を狙う。 |

#### 設定方法（2通り）：

**方法A：対話型コマンドで選ぶ（おすすめ）**
質問に番号（1〜3）で答えるだけで、推奨価格帯や利回りが自動プリセットされます。
```bash
python scripts/dx_grok_bot_setup.py --interactive-plan
```

**方法B：設定ファイルを直接編集する**
1. テンプレートをコピー:
   ```bash
   cp config/dx_member_config.example.yaml config/dx_member_config.yaml
   ```
2. `config/dx_member_config.yaml` をエディタで開き、あなたの情報に書き換えます:
   ```yaml
   owner:
     name: "あなたの氏名"
     company: "屋号または法人名"
     email: "your.email@example.com"
     phone: "090-xxxx-xxxx"

   strategy:
     target_area: "愛知県一宮市、稲沢市周辺"
     # 3択から選択: "築古戸建て" | "築古アパート" | "新築アパート"
     buy_plan_type: "築古戸建て"
     target_asset_types: "木造築古戸建（平屋・2階建て）"
     target_price_max_man: 500       # 築古戸建: 200〜600万 / 築古AP: 1500〜4000万 / 新築AP: 6000〜15000万
     target_min_yield_pct: 15.0      # 築古戸建: 15〜20% / 築古AP: 11〜15% / 新築AP: 7.0〜8.5%
     land_ratio_target_pct: 70       # 築古戸建・AP: 60〜70%以上 / 新築AP: 12〜15%以上
     financing_strategy: "現金購入またはリフォームローン"
     parking_requirement: "駐車場1台以上"

     # 物件調査対象ポータルサイトの指定
     # デフォルト4大サイトに加えて、特定サイトがあれば追加可能
     portal_sites:
       - "楽待"
       - "健美家"
       - "LIFULL HOME'S"
       - "アットホーム"
     # 追加ヒアリング: 「他に見たいサイトがあるか」
     additional_portal_sites: ""    # 例: "不動産連合隊、地域特化ポータルなど"
   ```

#### 【重要】物件調査サイトの指定とヒアリングのポイント
物件調査担当のS1には、有力4大サイト（楽待・健美家・HOME'S・アットホーム）を標準装備しています。
初期セットアップ時や導入ヒアリングでは、必ず**「他に確認してほしい指定サイトや地場ポータルはありますか？」**と確認し、上記の `additional_portal_sites` に追記することで、そのメンバー独自の探索網を構築できます。

### ステップ 3：Grok Bot へのAI社員一括自動配属
CursorのCDP（Chrome DevTools Protocol）連携を使い、Grok Botアプリにあなた専用のAI社員たちを一瞬で配属します。

1. **プレビュー（変数が正しく入っているか確認）**:
   ```bash
   python scripts/dx_grok_bot_setup.py --dry-run
   ```
2. **実際にGrok Botアプリへ反映**:
   ```bash
   python scripts/dx_grok_bot_setup.py --apply
   ```
   - Grok Botアプリが自動でCDPモードで起動し、 Instructions（指示書）が設定されます。
   - アプリのサイドバーに「不動産賃貸」セクションが作られ、以下の全社員が自動配属されます:
     - 👔 **不動産賃貸・部長**: 全体の差配と毎晩の日報作成
     - 🔍 **S1 物件調査**: ポータル監視・積算計算（4大サイト＋追加希望サイト対応）
     - 🤝 **S2 業者開拓**: 地場仲介・開発業者への低姿勢かつ買い基準明確なアプローチ
     - 📊 **S3 需給三次判断**: ライバル供給数・成約家賃相場分析
     - 🔨 **S4 修繕業者開拓**: 神大家LINEオプチャ（31修繕相談G等）知見と連動した分離発注・相見積もり
     - 💡 **S5 ペルソナ二次判断**: 入居者生活ストーリー設計
     - ⚖️ **S6 買付・価格交渉**: 論理的指値レター起草
     - 🏦 **S7 融資相談**: 銀行打診用サマリー・事業計画策定
     - ⚡ **S8 物件ライフライン**: プロパン無償貸与・ネット開通交渉
     - 🏢 **S9 管理会社開拓**: 地場客付け最強の管理会社目利き
     - 🎨 **S10 周辺マップ作成職人**: 厳選8施設・A4横製本チラシ風Canvaシート作成

#### 【注目機能】S4 修繕業者開拓の「神大家LINEオプチャ知見連携」
S4は、神大家さん倶楽部のLINEオープンチャット（特に31修繕相談Gのスレッド）に蓄積された、先輩大家・サポート担当（柴田沙記さん、萩原史さん他）の「実際に安くて良かった業者名」「実勢工事費用」「裏ワザ工法」を参照して回答します：
- **水回り・漏水**: リビングステージ等の格安散水テスト・コーキング、FRP浴槽塗装相場
- **内装・壁**: OSBボード直貼り（クロス不要・ビス目立たず安価でお洒落）、ダイノックシート補修
- **設備・電気**: ビリビリガード（簡易漏電遮断器）によるアース問題の低コスト解決
- **不用品・残置物**: ジモティーを活用したエアコン無料取外し・引取ノウハウ
管理会社の見積もり（30万〜50万）を鵜呑みにせず、先輩大家の生きた実績データをもとに分離発注や代替案を即座に提示します。

### 4. 日常の回し方（デイリールーティン）

1. **朝の号令と「買い進めプラン」のヒアリング**:
   - あなたが部長Botに「部長、本日分お願い」と声をかけます。
   - 部長Botは、いきなり調査に突入するのではなく、**質問形式で今回の買い進めプランを確認**します：
     > **部長Bot**:  
     > 「承知いたしました。本日の物件調査に入る前に、探す物件の【買い進めプラン】を確認させてください。  
     > 現在の設定は【築古戸建て】ですが、本日もこのプランでよろしいですか？  
     > 　1. 築古戸建て（価格200〜600万 / 利回り15〜20%以上 / 現金・手堅いCF）  
     > 　2. 築古アパート（価格1,500〜4,000万 / 利回り11〜15% / 地銀・信販・CF加速）  
     > 　3. 新築アパート（価格6,000万〜1.5億 / 利回り7.0〜8.5% / フルローン規模拡大）  
     > 変更がなければ『1でOK』またはそのまま『進めて』とお答えください。」
   - あなたが「1でOK」「今日はアパート見てみて（2で）」と返すと、プランが固まり、部長がS1に指令を出します。
   - **S1（物件調査）**は、指定されたプラン基準（価格帯・目標利回り・土地値70%など）に適合した買い進め候補物件をスクリーニングし、スプレッドシート（Deals）に記録します。
2. **夕方の確認**:
   - 候補物件が上がってきたら、S3需給判断やS5ペルソナ、S6指値案を精査させます。
3. **夜の日報確認**:
   - 部長から届く1通の日報メール・メッセージで進捗を確認し、指示を出します。
4. **物件購入後（周辺マップ作成）**:
   - S10に「〇〇物件の周辺マップ作成をお願い」と指示。
   - 「AI 85%（下準備）＋ 人間 15%（仕上げ）」の黄金原則に従い、Canva上で5〜10分で仕上げて印刷！

### 3. 松野の圧倒的な競合優位性（なぜ松野から買うべきなのか？）
