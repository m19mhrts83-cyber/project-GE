## 第1部：AI社員組織 導入ハンドブック（メンバー向け実務手順）

### 1. はじめに：なぜ「AI社員組織」なのか？
サラリーマン大家にとって、最大の制約は「時間」です。
ChatGPTに都度プロンプトを打つ「一問一答の相談」では、毎回人間が前提を教え、指示を出さねばならず、結局手間が減りません。

本パッケージは、**「神大家さん倶楽部の英才教育を叩き込んだAI社員たちを、Grok Botに配属し、チームとして自走させる」** ためのスターターキットです。
PCを閉じてもクラウド上で24時間働き、毎朝のポータル探索から夕方の業者アプローチ、購入後の周辺MAPチラシ作成までを自動で推進します。

---

### ステップ 0：自分のPC環境を診断する
まずは、お使いのPCでAI組織が稼働できる準備が整っているかをチェックします。

```bash
python scripts/dx_ai_setup_checker.py
```

- **判定結果の見方**:
  - `Level 3 (Full Organization)`: 即座にフル機能が動かせます！
  - `Level 2 (Hybrid Starter)`: 基本機能はOK。不足ライブラリを `pip install` で補完してください。
  - `Level 1 (Setup Needed)`: Grok BotやPythonの導入からスタートしましょう。

### ステップ 1：案件管理スプレッドシートの準備（KURASHIFT代替）
独自アプリがなくても大丈夫です。GoogleスプレッドシートやExcelでそのまま使える3大業務シートのテンプレートを初期化します。

```bash
python scripts/dx_spreadsheet_adapter.py --init-all
```

- 以下の3つのCSVファイルが `data/` 配下に作成されます:
  1. `神大家AI不動産_案件管理.csv` (Deals): 物件名、住所、価格、利回り、ステータス、担当Bot、次のアクション
  2. `神大家AI不動産_業者開拓.csv` (Vendors): 会社名、地域、フォームURL、送信フェーズ、返信メモ
  3. `神大家AI不動産_募集クリエイティブ.csv` (Creative): 物件名、周辺MAP状況、マイソク状況、POP設置メモ
- これらのファイルをGoogleドライブにアップロードし、「Googleスプレッドシートとして開く」にすると、スマホやブラウザからいつでも案件ステータスを共同編集できます。
- **データ確認・追加コマンド**:
  ```bash
  # 各シートの一覧を見る
  python scripts/dx_spreadsheet_adapter.py --sheet deals --list
  python scripts/dx_spreadsheet_adapter.py --sheet vendors --list
  python scripts/dx_spreadsheet_adapter.py --sheet creative --list

  # 物件案件を追加する
  python scripts/dx_spreadsheet_adapter.py --sheet deals --add \
    --name "一宮市浅井町 戸建" --address "愛知県一宮市..." --price 380 --yield-rate 18.5

  # 開拓業者を追加する
  python scripts/dx_spreadsheet_adapter.py --sheet vendors --add \
    --company "ニッショー一宮店" --area "愛知県一宮市" --url "https://example.com/form"
  ```

### ステップ 2：自分の投資基準に合わせた設定ファイルの作成
あなたのお名前、会社名、狙うエリア、物件種別、利回り基準を設定します。

1. テンプレートをコピー:
   ```bash
   cp config/dx_member_config.example.yaml config/dx_member_config.yaml
   ```
2. `config/dx_member_config.yaml` をエディタで開き、あなたの情報に書き換えます:
   ```yaml
   owner:
     name: "あなたの氏名"
     company: "屋号または法人名"
     email: "your.email@example.com"
     phone: "090-xxxx-xxxx"

   strategy:
     target_area: "愛知県一宮市、稲沢市周辺"
     target_asset_types: "木造築古戸建またはアパート"
     target_price_max_man: 500
     target_min_yield_pct: 15.0
     parking_requirement: "駐車場1台以上"
   ```

### ステップ 3：Grok Bot へのAI社員一括自動配属
CursorのCDP（Chrome DevTools Protocol）連携を使い、Grok Botアプリにあなた専用のAI社員たちを一瞬で配属します。

1. **プレビュー（変数が正しく入っているか確認）**:
   ```bash
   python scripts/dx_grok_bot_setup.py --dry-run
   ```
2. **実際にGrok Botアプリへ反映**:
   ```bash
   python scripts/dx_grok_bot_setup.py --apply
   ```
   - Grok Botアプリが自動でCDPモードで起動し、 Instructions（指示書）が設定されます。
   - アプリのサイドバーに「不動産賃貸」セクションが作られ、以下の全社員が自動配属されます:
     - 👔 **不動産賃貸・部長**: 全体の差配と毎晩の日報作成
     - 🔍 **S1 物件調査**: ポータル監視・積算計算
     - 🤝 **S2 業者開拓**: 地場仲介への低姿勢アプローチ
     - 📊 **S3 需給三次判断**: ライバル供給数・成約家賃相場分析
     - 🔨 **S4 修繕業者開拓**: 分離発注・相見積もりコスト削減
     - 💡 **S5 ペルソナ二次判断**: 入居者生活ストーリー設計
     - ⚖️ **S6 買付・価格交渉**: 論理的指値レター起草
     - 🏦 **S7 融資相談**: 銀行打診用サマリー・事業計画策定
     - ⚡ **S8 物件ライフライン**: プロパン無償貸与・ネット開通交渉
     - 🏢 **S9 管理会社開拓**: 地場客付け最強の管理会社目利き
     - 🎨 **S10 周辺マップ作成職人**: 厳選8施設・A4横製本チラシ風Canvaシート作成

### 4. 日常の回し方（デイリールーティン）

1. **朝の号令**:
   - 部長Botに「部長、本日分お願い」と声をかけるだけ。
   - 部長がS1にポータルを調べさせ、S2に業者開拓をさせます。
2. **夕方の確認**:
   - 候補物件が上がってきたら、需給やペルソナ、指値案を精査させます。
3. **夜の日報確認**:
   - 部長から届く1通の日報メール・メッセージで進捗を確認し、指示を出します。
4. **物件購入後（周辺マップ作成）**:
   - S10に「〇〇物件の周辺マップ作成をお願い」と指示。
   - 「AI 85%（下準備）＋ 人間 15%（仕上げ）」の黄金原則に従い、Canva上で5〜10分で仕上げて印刷！

### 3. 松野の圧倒的な競合優位性（なぜ松野から買うべきなのか？）
1. **「現役サラリーマン大家 × 神大家の実践者」であること**:
   - 単なるITプログラマーは、不動産の実務（路線価計算、三タメ、指値交渉、プロパン無償貸与、公取規約80m=1分など）を知りません。
   - 松野は神大家さん倶楽部の理念を深く理解しているため、「大家にとって本当に必要なアウトプット」を提供できます。
2. **「実機テスト済みの85%＋15%の黄金ルール」があること**:
   - Canva自動化での「AIに全部やらせようとすると破綻する」というリアルな失敗と成功の経験値を持っているため、顧客を迷わせません。
3. **Cursor × Grok Bot の最先端ノウハウ**:
   - CDP経由でのアプリ自動操作など、一般のDXコンサルタントが持っていない高度な技術ノウハウをパッケージ化しています。
