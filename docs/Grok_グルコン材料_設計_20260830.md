## 材料ライフサイクル（Q6 確定 · P0）

### status 定義

| status | 意味 | 下書き注入 |
|---|---|---|
| `pending` | 当周期・未使用 | **する** |
| `used` | 投稿完了で使用済 | しない |
| `skipped` | 明示スキップ | しない |
| `cycle_closed` | **グルコン日経過**で周期終了（未投稿含む） | しない |

※ DDL 追加: `cycle_closed` を check 制約に含める（migration 追記）。

### 遷移ルール

```
pending
  ├─ markGluconPosted（activity|result）成功 → used（used_in_period_key 設定）
  ├─ UI「スキップ」→ skipped
  └─ グルコン日（JST）の翌日 0:00 以降、当 period_key の pending 活動材料 → cycle_closed
```

**活動（activity）に限定して cycle_closed**（顧客指定）。  
成果（result）材料は `used` / `skipped` / 手動 cycle_closed のみ（グルコン日自動 close は任意 · 実装者判断可）。

### 「毎回出さない」月の扱い

- グルコンへ **活動報告を投稿しなくてもよい**（スキップ運用可）
- グルコン日を過ぎたら **当該月の pending 活動材料は注入対象から外す**（cycle_closed）
- **月次で投稿する月**は従来どおり下書き→WeStudy 投稿→`markGluconPosted`
- 材料本文は **一覧に残る**（削除しない）

### 周期リセットの実装（実務者）

| 経路 | 内容 |
|---|---|
| **推奨** | `getGluconPageState` または朝オープン runner で `closeExpiredGluconMaterials()` を呼ぶ |
| 条件 | `period_key` に対応する `glucon_date < today(JST)` かつ `kind=activity` かつ `status=pending` |
| 更新 | `status=cycle_closed`, `payload.cycle_closed_at=ISO` |

## 一覧 UI（Q6 · P0 · 新規）

**要件**: グルコンへ投稿していなくても、**活動・成果の材料と下書きを一覧で確認**できる。

### 画面

| 項目 | 内容 |
|---|---|
| URL | **`/glucon/materials`**（`/glucon` からリンク） |
| タブ | **活動** / **成果** |
| 行 | `glucon_material_items` 全件（pending / used / skipped / cycle_closed） |
| 列 | period_key · title · recorded_at · status · source · 本文プレビュー（展開） |
| フィルタ | period_key · status · kind |
| 下書き | 同画面または折りたたみで `glucon_report_drafts`（**draft / ready 含む**）を period ごと表示 |

**既存「これまでの報告」**（`GluconArchiveList`）は posted/skipped 等のみ。**draft/ready 未投稿**と **Grok 材料**が見えない → 本一覧で補完する。

### 受入基準

- ホークが inbox に置いた MD が一覧に出る（取込後）
- グルコン未投稿の月でも、その月の材料を後から読める
- cycle_closed 後は `/glucon` 下書き生成に **載らない**が一覧では **参照可**

## markGluconPosted 連動（P0）

`markGluconPosted(periodKey, kind)` 成功時:

1. 当該 `period_key` + `kind` に注入した material id を `used` + `used_in_period_key`
2. 注入 id の記録: 下書き生成時に `payload.injected_material_ids` を draft payload に保存（新規）

## 取込タイミング（P1 · Q1 系と独立）

| 経路 | 方針 |
|---|---|
| 手動 | `--apply` 可 |
| **定常** | 朝オープンまたは inbox poll のついでに `--apply` |
