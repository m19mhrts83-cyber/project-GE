---

### S6. 改善② — Genspark の強み：常時テキストが残る

| 要素 | 案 |
|---|---|
| 見出し | Second Brain／AIボイスレコーダーの効きどころ |
| 大きく | **録音ボタンを押さなくても、バックグラウンドでテキストが残る** |
| ポイント | ・電話・打ち合わせ中も常時テキスト化のイメージ |
|  | ・明示的に議事録を取るのもよい |
|  | ・加えて **バックアップ**として残る →「取っておけばよかった」を防げる |
| Before | 録る／起こす／まとめるが分断（押し忘れリスク） |
| After | 起きていれば倉庫に入り、あとから司令塔（Cursor）が引き出せる |

**話すこと**: 議事録を丁寧に残す運用と両立。常時テキストは「保険」でもある。

---

### S7. 本題の価値 — 司令塔 Cursor が倉庫を参照できる

| 要素 | 案 |
|---|---|
| 見出し | いちばん伝えたいこと |
| 大きく | **Cursor（司令塔）が、Genspark に溜まったナレッジを参照できる** |
| 補足 | 全文コピー不要。「さっきの電話」と頼む → 宿題・下書きへ |
| 図 | 電話 → Genspark倉庫 → オンデマンド → **Cursor＝司令塔** → 下書き／Notion／日誌 |

※「手足」とは言わない。**自分と並ぶ司令塔**。

---

### S8. どうやって接続したか

| 要素 | 案 |
|---|---|
| 見出し | 接続の中身 — 「コピペ自動化」ではない |
| 結論 | **公式の取り出し口（CLI）で、必要なときだけ倉庫を読む** |
| 4段 | ① gsk ② 認証は秘密ファイル ③ 検索・取得 ④ Cursorルールで連動 |
| 要点 | 公式／オンデマンド／スクレイピングしない／正本は Genspark |

---

### S9. 接続のビフォーアフター

| | 接続前 | 接続後 |
|---|---|---|
| 起こし | 手動渡し・品質で止まる | 倉庫に入っている（常時テキスト含む） |
| Cursor へ | コピペ／ファイル指定 | 「さっきの電話」と**言葉で頼む** |
| 蓄積 | 散らばる or 全部コピーしたくなる | 倉庫に置き、必要時だけ参照 |
| 次の仕事 | 要約で疲れがち | 宿題・下書き・Notion まで一気通貫 |

---

### S10. 役割分担 — 混ぜない（全体地図）

| 役割 | 誰／何 | 例 |
|---|---|---|
| **司令塔** | 自分 ＋ **Cursor** | 方針・依頼・判断・下書き指示（並ぶ存在） |
| **社員** | Grok bot | ポータル・ルーティン・案件推進 |
| **声の倉庫** | Genspark（Second Brain 系） | 常時テキスト・起こし・要約 |
| **外部ナレッジ** | **Notion** | 外との打合せ・調整を、意思を持って見返す |
| **自分の日誌** | Obsidian 等 | 思考ログ。全文倉庫にしない |

**話すこと**: 全部を1ツールに寄せない。接続する。

---

### S11. Notion の役割 — 外部を「見返すナレッジ」に（新規）

| 要素 | 案 |
|---|---|
| 見出し | Notion：外との話を、あとで意思を持って確認する場所 |
| 使い方の核 | 外部打ち合わせ・外部調整の内容を蓄積し、**自分で参照するときのナレッジ**にする |
| これまでの使い方（実例の型） | ・電話・面談メモのハブ（「電話・面談録音メモ」） |
|  | ・Genspark／議事録／JPR から **Save to Notion**（Inbox → 振分） |
|  | ・接頭辞例：`[議事録]`／`[SB]`／`[JPR]` |
|  | ・家族コーチング等、テーマ別の蓄積も Notion |
| 対比 | Genspark＝まず全部寄りで残る倉庫／Notion＝**残す価値を選んで、見やすく並べる棚** |
| 一言 | 「溜まったまま」ではなく、**見に行く意思**が働く置き場 |

**図（任意）**:

```
[外部打合せ・調整]
   ↓ Save / 振分
[Notion ＝ 見返すナレッジ棚]
   ↑ 自分や Cursor が「確認しに行く」
```
