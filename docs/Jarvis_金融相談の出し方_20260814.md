# Jarvis 金融相談の出し方（2026-08-14）

金融・資産・カード引落・保険貸付などの**相談回答**は、次の型で出す。  
理念の正本は `.cursor/rules/jarvis-finance-philosophy.mdc`。

## 回答の型（必須順）

1. **用途ラベル** — 何のための現金か（例: Olive Infinite 引落バッファ）
2. **比較表** — 候補を並べ、金利・副作用・完了のしやすさを短く
3. **チェックリスト** — 実行前に埋める項目（返済日・原資・口座など）
4. **1行推奨** — いま取る一手だけ
5. **禁止リスト** — やらないこと（あかつき元本売却、SBIコア、計画なし貸付 等）
6. **次の具体手** — 画面・コマンド・誰が何をするか

## カード引落・借りに関する一行ルール

*返済カレンダーを書けない安い借りは未完了の宿題。衛星（Bloomo）売却で終わらせる方がよいことが多い。*

**補足（2026-08-14）**: 「毎月定額で返す」と決められるなら、それはカレンダーあり。株再建と同型の**自分への強制貯蓄**として契約者貸付を使ってよい。ただし返済は **防衛・次物件キープ・NISA月9万のあと**の余りから。

調達ラダー（KURASHIFT `/money-ops`）:

1. 銀行内の無料寄せ
2. 海外債の既入金利金のみ
3. 契約者貸付は短期ブリッジのみ・常態化禁止。返済カレンダー（定額可）・返済原資が書けるときだけ
4. Bloomo（衛星）清算（書けない借り ＜ 衛星現金化）
5. SBIコアは最終手段／原則禁止

### 比較の型（貸付 vs 衛星売却）

| 観点 | 契約者貸付＋定額返済 | Bloomo（衛星）清算 |
|---|---|---|
| 完了の形 | 負債がゼロになるまで毎月続く | 一度売ればカード穴は閉じる |
| コスト | 年約2.5%＋運用機会の拘束 | 売却タイミング・税金・再建のやる気 |
| 向く人 | 定額習慣が続く／保険CSVを戻したい | 宿題を早く終わらせたい／返済枠が給与に乗らない |
| ライフプラン | 余り枠に定額を割り当てる | 再建は余り枠で任意積立 |

### ライフプラン比率（返済・再建の上限）

1. 防衛＋物件バッファ  
2. 次物件キープ  
3. NISA 9万固定  
4. 余り → 貸付定額 or Bloomo再建（比率は本人が決める）  
5. Theme はさらにその上  

## いつこの型を使うか

- カード引落・寄せ・契約者貸付・衛星売却の相談
- 「借りた方が得？」「現金が足りない」系
- 金融アドバイスで選択肢が2つ以上あるとき

無関係な依頼（パートナーメール、LINE 等）では持ち出さない。
