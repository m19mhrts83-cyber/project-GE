# 買い進め · 利回り・返済比率の評価どこでやるか

**更新**: 2026-08-30  
**正本数値**: `config/grok_property_search_criteria.yaml` → `buy_economics`

---

## いままでの基準（反映前）

| 項目 | どこにあったか | 値 |
|---|---|---|
| 利回り（内部） | `grok_property_search_criteria.yaml` の `yield_pct_internal_min` | **15%**（0.15）。S1聞く判定にはほぼ未配線 |
| 利回り（学習・Notion） | 神大家トライアングル／編集者メモ | 築古戸建 **20%**（交渉後ターゲット寄り） |
| 返済比率 | `docs/KURASHIFT_不動産賃貸経営.md` · `/roi` | **年返済÷年収 ≈50%前後**（MG・中津さん） |
| S1聞く判定の本線 | 土地値100% · ハザード · 耐震 | 利回りゲートなし |

## 反映後の基準（戸建）

| 段階 | 基準 |
|---|---|
| 聞く（表面） | 表面利回り **≥10%** |
| 買う（交渉後） | 修繕込みで **15〜20%** に持っていける |
| 返済比率 | 金利上昇込みで **≈50%**（購入時は満室年収） |
| 金利ストレス | 楽天等の高金利帯目安 **年7%前後**（断定しない） |

一棟AP: 土地値150%が主。表面は最低 **8%** 補助。

---

## どこで評価するか（推奨配置）

| 段階 | Bot / 画面 | やること | やらない |
|---|---|---|---|
| **S1 物件調査** | `@物件調査` | 表面利回りゲート · 15〜20%到達見込み1行 · 返済比率はフラグのみ | 精密なローン計算 · 地場文面への利回り%記載 |
| **S6 買付交渉** | `@買付交渉` | **本線**: 修繕＋減額で15〜20% · 返済比率50%に合う買付額 | 銀行送信 |
| **S7 融資** | `@融資相談` | 金利ストレス（例7%）と返済比率の整合 · 名銀/滋賀の打診準備 | 承認保証 |
| **確定評価** | KURASHIFT **`/roi`** | 表面／実質／返済比率の確定表 | Grokに二重の正本を置かない |

S5/S3（ペルソナ・需給）は従来どおり入居・需給。利回りゲートの主担当にはしない。
