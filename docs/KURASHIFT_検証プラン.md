## 後回しバックログ（要望メモ）

### B-IFA-1 — 特別勘定の比率確認 → 石河さん連絡 → 結果の要約・見直し確認

| 項目 | 内容 |
|---|---|
| **目的** | 配分％を取ったあと、石河さん（IFA）へ連絡し、**返信待ちで終わらず**、返答を要約して「変更するか／見直すか」をユーザーと確認する |
| **前提** | 保険配分スクレイプ（ユーザー指定 URL）が動く／または snap・YAML で現状比率が見える |
| **連絡チャネル** | **まず iMessage**（現行の原稿送付経路）。明らかに文字数不足なら、メールアドレスを聞いて **メールへ切替** |
| **Jarvis の動き（案）** | ①現状比率（対アクサ差分含む）を短く整理 → ②iMessage 下書きを提示し送信確認 → ③返信取込 → ④要約＋「変更案／据え置き案」を確認質問 → ⑤合意後に YAML／snap／必要なら各社画面の次アクション |
| **やらないこと（当面）** | 石河さん宛の無断送信。メールアドレス推測。比率の勝手な本番変更 |
| **状態** | **トライアル中**（iMessage送信済・返信待ち。共有あり次第要約→変更／据え置き確認） |
| **連絡先** | `.env.jarvis_private` の `IFA_ISHIKAWA_*`（氏名: 石河旦善） |

関連: `config/insurance_allocations.yaml`（advisor）／`docs/Trade_Desk.md` Core 保険

## 合格の定義

| 分類 | 自分の操作だけで言える／できること |
|---|---|
| ① | 週次で資産と保険借入が見える。テーマを提案→承認→完走アシストまで回せる（実弾なし） |
