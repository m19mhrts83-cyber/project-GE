# KURASHIFT 検証プラン（ユーザー実行）

プラン末尾 To-do: **`verification-with-user`**

技術単体ではなく、**あなたがアプリからサイクルを回し、意図どおり実行できるか**を見る。  
指摘はその場で Jarvis へ。直しながら実務レベルまで上げる。

---

## 頭の整理 — やりたいことは大きく2本

あなたの理解どおり、本線はこの2分類です。

| 分類 | やりたいこと | 画面の主な入口 |
|---|---|---|
| **① 資産運用** | 全体把握／提案・相談・実行 | ホーム・資産・テーマ・（相談） |
| **② 暮らしの計画と税** | ライフプラン更新／確定申告ネタ整理 | ライフプラン・ROI・個人申告 |

検証も **① → ②** の順で項目立てして回す（途中で止めてよい）。

### それ以外にあるもの（本線ではない）

| 区分 | 内容 | 検証での扱い |
|---|---|---|
| **0. 前提** | ログイン・設定（秘密）・ジョブ worker | ①の前に一度だけ |
| **横断・安全** | 未承認で実弾／Zaim本番／弥生本登録が走らない | ①②のついでに確認 |
| **脇・後回し** | Lab（平均回帰・立花）／リサーチ inbox | 本検証の対象外 |
| **参考** | 相談記録の閲覧・年次お知らせバナー | ①②に付随。あれば触る |

Jarvis ダッシュボード（パートナーメール等）は **別アプリ**。KURASHIFT 検証には含めない。

---

## 合格の定義

| 分類 | 自分の操作だけで言える／できること |
|---|---|
| ① | 週次で資産と保険借入が見える。テーマを提案→承認→完走アシストまで回せる（実弾なし） |
| ② | LP で実績→ギャップ→CSV まで回せる。個人申告で弥生CSVと証憑が一覧に出る |
| 横断 | どこで止まったか・次に何を押すかが画面で分かる。境界を破っていない |

**前提（初回）**

- `http://localhost:3003` または本番 Vercel
- Mac で `jarvis_kurashift_job_worker`（画面キューだけでは裏が走らない）
- ログインは Jarvis ダッシュボードと同じアカウント

```bash
cd ~/git-repos && ~/selenium_env/venv/bin/python scripts/jarvis_kurashift_job_worker.py --once
```

| 1B-5 | （任意）**相談**一覧に記録が見える | 相談レーンがつながっている |

# 横断 — やってはいけない境界

①②のどこかで一度確認。

- [ ] 未承認のまま売買・振替が動いていない  
- [ ] Zaim 本番を押していないのに予算が変わっていない  
- [ ] 秘密がジョブ詳細やチャットに残っていない  
- [ ] 弥生本登録が勝手に走っていない
