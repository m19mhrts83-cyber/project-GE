プライバシーポリシー — Jarvis 個人自動化

最終更新: 2026-08-26 · 運営: 松野真治（個人利用）

1. 対象

本ポリシーは、Google OAuth 2.0 経由で Gmail / Google Calendar 等にアクセスする個人用 Mac 自動化（Jarvis）に適用されます。第三者向けの公開サービスではありません。利用者は運営者本人および、運営者が明示的に許可した少数のアカウント（本人が管理する Google アカウント）に限ります。

2. 取得する Google ユーザーデータ

  • Gmail: パートナー・業務連絡のメール本文・ヘッダ・添付（読取・ラベル変更・本人からの送信）
  • Google Calendar: 本人カレンダーへの予定登録・参照

上記は、連絡先一覧に登録された相手とのやり取り整理、リマインダー登録、本人の業務効率化のためにのみ使用します。

3. データの利用目的（Limited Use）

Google ユーザーデータは、次の目的に限定して使用します。

  • メール・メッセージの取り込みとローカル／本人管理ストレージへの記録
  • 本人が指示した返信下書き・送信補助
  • 本人カレンダーへの予定登録
  • 本人のみがアクセスするダッシュボードへの投影（認証付き）

広告、第三者への販売、信用調査、機械学習モデルの学習用データセット化、本ポリシーで明示していない目的には使用しません。

4. 保存場所と期間

  • OAuth トークン: 運営者の Mac 上のローカルファイル（Git 非共有）
  • メール・やり取りログ: 運営者の OneDrive / ローカルリポジトリ（本人管理）
  • ダッシュボード投影: 運営者本人用 Supabase（認証付き）

保存期間は業務上必要な期間。不要になったデータは運営者が削除します。

5. 第三者への共有

Google ユーザーデータを第三者に販売・貸与しません。クラウドホスティング（Vercel / Supabase 等）へ投影する場合も、運営者本人のアカウント・認証下で、上記利用目的の範囲に限ります。

6. セキュリティ

トークン・秘密情報は Git や公開チャットに含めません。Mac ローカルおよび運営者管理の秘密ストアに保管します。

7. データの削除

運営者は Google アカウント設定から本アプリのアクセス権をいつでも解除できます。解除後、新規の API アクセスは行いません。既存のローカルログの削除は運喸者が手動で実施します。
