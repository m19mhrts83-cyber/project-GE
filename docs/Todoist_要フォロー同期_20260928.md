# ホーム要フォロー → Todoist 正本同期
#
# 入口: Supabase watch_status（HomeWatchBand と同条件）
# 確認: Todoist で処置／コメント。ダッシュボード「確認した」は次回 sync で complete
# 履歴: `.jarvis_state/watch_todoist_sync.json` + payload.todoist_* / display_hints
# 停止: `JARVIS_WATCH_TODOIST_SYNC_DISABLE=1` または yaml `enabled: false`

## 対象

- **A のみ**: ホーム「要フォロー」＝ `watch_status`
- **対象外**: パートナー／メール triage、GenMail

## コマンド

```bash
cd ~/git-repos && set -a && source .env.jarvis_private && set +a
~/selenium_env/venv/bin/python scripts/jarvis_watch_todoist_sync.py --ensure-label
~/selenium_env/venv/bin/python scripts/jarvis_watch_todoist_sync.py          # dry-run
~/selenium_env/venv/bin/python scripts/jarvis_watch_todoist_sync.py --apply
```

定期: `launchd/bucho_inbox_poll_runner.sh`（15分）＋画面ロック解除 catchup（同 runner）。

## 起票ルール

| 項目 | 内容 |
|---|---|
| 先 | 共有『受信箱』 |
| タイトル | `[要フォロー][{watch_id}] {summary短縮}` |
| ラベル | `要フォロー` ＋（warn/attention なら）`要Jarvis連携` |
| 重複 | `watch_id`（state）。同一キーで増やさない |
| 完了 | Todoist close → payload `user_ack`（ack_source=todoist） |
| ダッシュボード確認 | `ack_source=dashboard` + `todoist_complete_requested` → sync が complete |

## 完了だけでホームから消える（本線）

Todoist でチェック完了するだけでよい。`表示: 抑制` は不要。

| 経路 | タイミング |
|---|---|
| Webhook `item:completed` | 受信後、15分帯（または画面ロック解除）の `jarvis_todoist_webhook_handle.py` |
| 保険 | 同帯の `jarvis_watch_todoist_sync.py` が完了タスクを見て `user_ack` |

状況が変わって再発したら fingerprint 変化で reopen／再表示。

## コメント学習（表示）— 任意

タスクを**残したまま**ホームだけ隠したい・ピンしたいとき用。完了の代わりではない。

タスクコメント先頭（定型のみ）:

| コメント | 効果 |
|---|---|
| `表示: 抑制` | ホームから外す（quiet 既定30日） |
| `表示: ピン` | ホーム先頭寄せ |
| `表示: 通常` | ヒント解除 |
| `表示: 降格` | ホームでは info 表示（level 自体は変えない） |

Webhook: `jarvis_todoist_webhook_handle.py` が `note:added` を拾って即反映（`--reply` 不要）。

## 設定

- state: `.jarvis_state/watch_todoist_sync.json`
- hints: `.jarvis_state/watch_display_hints.json`
