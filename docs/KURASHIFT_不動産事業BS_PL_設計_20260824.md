## 目的

不動産事業を **一番素直に** 評価するための伝統的 PL / BS。  
MQ要素法・資金繰り・家計BSは置き換えず、役割を分けて見る。

| 画面 | 見るもの |
|---|---|
| **事業BS・PL** | 減価償却・利息・税込みの利益と期末BS |
| **資金繰り** | 現金の月次（元本返済の正） |
| **MQ会計** | PQ/VQ/F/G の構造評価（PLの代替ではない） |
| **家計BS** | 家計全体（事業合計を二重計上しない） |

## 計算（Excel準拠）

- 税前 = 収入 − 経費（償却除く） − 減価償却 − 支払利息  
- 税金 = max(0, 税前 × 20%)（初回固定）  
- CF = 税後 + 償却 + 税金 − 税金支払 − 元金返済  
- 自己資本比率 = 純資産 / 資産合計  
- 流動比率 = 流動資産 / 流動負債  
- 債務償還年数 = 固定負債 / 年CF  
- ROI = 年CF / 純資産
