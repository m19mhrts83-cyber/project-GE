# コミュニティ添付の絞り込みと名前表示

- executor: Chappy
- status: implementation-tested / release-pending
- request: コミュニティコメント一覧にも「添付のみ」を追加し、取得済みのファイル名を表示する。
- scope: Raimo HTML/JS（正本と配備用ミラー）、LINE queueの既存名前補完、回帰試験。

## 仕様

「添付のみ」はログイン中の添付インデックスにあるコメントを表示する。本文・ファイル名検索、分類、日時フィルター、100件ページ送りと併用する。根拠から特定コメントへ移動するときは添付チェックを解除し、添付のない根拠も隠さない。読込中/失敗時は暫定件数と案内を表示し、「添付なし」と断定しない。

取得できた実ファイル名はtextContentで表示する。汎用のimage/video/audio/file、空名は「画像/動画/音声/添付ファイル（ファイル名未取得）」と表示。投稿や画像内容から名前を推測しない。会員権限、署名URL発行、バケット公開範囲を変更しない。

LINEで後から同じroom/messageの実名が取得できた場合のみ、queueの汎用名を補完してmetadata_dirtyを立てる。既に保存したバイナリを再取得せず、既存の日次metadata同期で反映。既存の意味ある名前は上書きしない。追加AI呼出しなし。

## 検証と適用

両JSミラーでフィルター併用、ファイル名検索、ページ送り、未確認状態、汎用名/実名、既存のXSS安全性を試験。Pythonで保存済みデータの名前補完・再uploadなし・名前の保護を試験する。

PR/CI後にRaimoのHTML/JSだけ反映し、認証API定義を維持。queueは既存日次runtimeの新しい固定コピーへ反映する。元画像の名前が取得できていない場合は未取得のままとし、名前のために全ファイル再走査はしない。
