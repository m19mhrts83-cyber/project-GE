# HOME'S投資（toushi.homes）ログイン壁 — 対応手順

**更新**: 2026-09-30（Jarvis 実測）  
**対象**: Grok 物件調査 Bot / 不動産賃貸部長 / Jarvis Mac

## 何が「壁」か

| 症状 | 実態 |
|---|---|
| `blocker=homes_login_required` | 資料請求・会員限定表示に **ログイン必須** |
| 公開スクレイプだけで inquire 不可 | `/inquire/input/` は会員セッション前提 |
| Grok Computer が止まる | **秘密（PW）を Grok に持たせていない**のが正。壁＝Mac Jarvis へ委譲 |
| 掲載終了 | 詳細が「お探しの物件は掲載終了しました」（例: homes 4718203） |

CAPTCHA は 2026-09-30 時点のログインでは **出なかった**。出たらボス介入。

## 役割分担（Grok Bot 環境を含む）

| 環境 | できること | やらないこと |
|---|---|---|
| **Grok Computer / Browser** | 公開ページの概要取得・スコア・`homes_login_required` 判定・inbox 依頼 | `HOMES_*` / `PORTAL_*` パスワードを Instructions や ch に書く |
| **Jarvis Mac** | Playwright ログイン → 資料請求送信 → estate／ホークへ1行返報 | まとめてチェックの大量同送（既定オフ） |
| **松野（ボス）** | CAPTCHA・会員情報の手修正 | 日常の portal 送信 |

**正**: 秘密は `.env.jarvis_private` のみ（`HOMES_LOGIN_EMAIL` / `HOMES_PASSWORD`、空なら `PORTAL_LOGIN_*`）。

## URL 正本（ログイン後）

```
詳細:   https://toushi.homes.co.jp/bukkendetail/index/{homes_id}/
問合せ: https://toushi.homes.co.jp/inquire/input/?property_id={homes_id}
ログイン: https://toushi.homes.co.jp/login/
検索:   https://toushi.homes.co.jp/bukkensearch/?keyword={住所キーワード}
```

- 誤: `/mansion/{id}/` `/kodate/{id}/` `/detail/{id}/` → ほぼ 404
- 完了URL例: `/inquire/complete/?ask_ids=…`

## Jarvis Mac 手順（手動でも可）

```bash
cd ~/git-repos && set -a && source .env.jarvis_private && set +a
~/selenium_env/venv/bin/python scripts/jarvis_homes_portal_inquire.py \
  --ids 4660406,4715985 --apply
# 確認のみ
~/selenium_env/venv/bin/python scripts/jarvis_homes_portal_inquire.py \
  --ids 4718203 --dry-run
```

送信時の注意:

1. 「物件の詳細が知りたい」をチェック
2. **「物件をまとめてチェック」はすべて外す**（他社へ大量同送防止）
3. ボタン順: **確認ページへ進む** → **送信する**
4. 完了画面の `ask_ids` を記録

## Grok 側の書き方（inbox / 調査メール）

ログイン壁で送れないとき:

```yaml
---
action: homes_portal_manual
priority: high
target: jarvis
source: hawk   # または property_bot
---
blocker: homes_login_required
homes_id: 4660406
name: 瀬戸市松原町3丁目2号棟
price_man: 2980
agency: P-EIGHT
url: https://toushi.homes.co.jp/bukkendetail/index/4660406/
inquiry_action_expected: portal_sent
```

- `[Grok調査]` には `blocker=homes_login_required` と homes_id を必ず書く
- **Grok は portal_sent を偽らない**（未送信なら `kurashift_handoff` または blocker 付き investigate）
