# AI一枚絵試行 — 「全部AI生成」の難しさが分かる例

**用途**: 7/29 運営説明で、幸田さん方式／Step4.1（ChatGPT・Geminiで地図ごと作り込む）の**限界**を見せる参考画像。  
**本線ではない**（本線は実地図＋Canva）。見栄えが良くても地理が崩れる、という話の実例。

---

## 口頭で伝えるポイント（短く）

1. **見栄えは出せる**（チラシっぽい色・人物・吹き出し）
2. ただし画像生成は骨格を「編集」せず **似た地図として再描画**しやすい
3. 典型トラブル: **位置ずれ**／**入力にない駅・店の追加（幻覚）**／**動線の描き替え**／直しにくい
4. だから本線は **地図は実地図のまま／店は載せる前に実在検証／仕上げはCanva**
