# 時間の使い方の記録（週1行）

松野さんの時間を4つに分けて週ごとに数え、Jarvis ダッシュボード（`/agent-team` の先頭）に出す。**直しは減らす対象ではない**（見て分かりやすくする直しは価値。2026-11-27 松野さん）。減らしたいのは、ルーティンや聞くまでもない物を AI が松野さんに聞くこと。物差しは **「聞くまでもない確認」の割合が下がること**。

## 分け方（初版・チューニング前提）

| 区分 | 中身 | 向き |
|---|---|---|
| 舵取りの判断（`steering`） | 方向性・経営上重要で、松野さんが決めるべき物。Orca 項目の Needs you への回答、[`65_`](./65_決定記録_20261127.md) の行 | 価値。増えてよい |
| 分かりやすくする直し（`clarity`） | 見せ方・言葉・画面を分かりやすくする直し | 価値 |
| 方針づくり（`policy`） | 新しい決まり・仕組みを松野さんと一緒に考えた時間 | 価値（別枠） |
| 聞くまでもない確認（`needless`） | ルーティン・どちらでもよい・影響が小さいのに AI が聞いた物。AI の間違いのやり直しを含む | 減らす |

- **聞くまでもない確認の割合 = 聞くまでもない確認 ÷ 4区分の合計**。ダッシュボードが計算するので書かない。
- 表示の主役は、この割合の推移（線）と、価値の3区分の内訳（積み上げ棒）。旧の「判断の比率」は使わない。
- 迷ったら：松野さんが決めなければ方向が変わる物は舵取り。AI が決めて事後報告で足りた物は聞くまでもない確認。基準は [`62_`](./62_ボット共通ルール入口_20261123.md) の「聞く基準」。

## 付け方

- 金曜18時の大佐の振り返りが、毎週1行足す（週の開始日は月曜）。
- 記録の場所：`apps/jarvis-dashboard/data/timeUse.json` の `weeks` の末尾。
- 1行の項目：`week_start`（月曜の日付）／`steering`／`clarity`／`policy`／`needless`／`memo`（一言）／`source`（65_ の行や Orca の項目番号）。
- 件数は出どころ（65_ の行・Orca の項目）から数える。見積もりの時は memo に「見積もり」と書く。取引先名・物件名・金額・個人名は書かない（公開リポ）。
- 数え方を変えたら、memo に書いて、この文書の分け方も直す。
- 見え方：ダッシュボードの `/agent-team` 先頭「時間の使い方」。今週の割合と4区分の数、先週との差、直近12週の積み上げ棒（価値の3区分）と線（聞くまでもない確認の割合）。
