# 時間の使い方の記録（週1行）

松野さんの時間を「判断」「直し」「方針づくり」に分けて週ごとに数え、Jarvis ダッシュボード（`/agent-team` の先頭）に出す。物差しは **判断の比率が上がり、直しが減ること**。方針づくりは減らす対象ではなく、別の数として見るだけ。

## 分け方（初版・チューニング前提）

- **判断**：松野さんが選ぶ・決める。Orca 項目の Needs you への回答、[`65_`](./65_決定記録_20261127.md) の行。
- **直し**：ボットの出した物を、松野さんが直させた・やり直させた・言い直した。
- **方針づくり**：新しい決まり・仕組みを松野さんと一緒に考えた時間。
- 判断の比率 = 判断 ÷（判断 + 直し）。ダッシュボードが計算するので書かない。

## 付け方

- 金曜18時の大佐の振り返りが、毎週1行足す（週の開始日は月曜）。
- 記録の場所：`apps/jarvis-dashboard/data/timeUse.json` の `weeks` の末尾。
- 1行の項目：`week_start`（月曜の日付）／`decisions`／`fixes`／`policy`／`memo`（一言）／`source`（65_ の行や Orca の項目番号）。
- 件数は出どころ（65_ の行・Orca の項目）から数える。見積もりの時は memo に「見積もり」と書く。取引先名・物件名・金額・個人名は書かない（公開リポ）。
- 数え方を変えたら、memo に書いて、この文書の分け方も直す。
- 見え方：ダッシュボードの `/agent-team` 先頭「時間の使い方」。今週の数、先週との差、直近12週の棒（判断・直し）と線（比率）。
