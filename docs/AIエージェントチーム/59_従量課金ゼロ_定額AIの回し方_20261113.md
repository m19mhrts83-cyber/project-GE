# 従量課金ゼロ：定額AIの回し方（2026-11-13）

松野さんの方針: 神大家AIナビを除き、従量課金の AI API は使わない。定額の AI 使用量で自動化を進める。今の機能は維持する。

## 回す順（松野さん指定）

| 用途 | 順番 | 理由 |
|---|---|---|
| 定期処理（要約・やること抽出・家族会議の整形・録音の要約） | GenCode → Codex → Cursor → Claude | GenCode を最優先 |
| ボタンで待つもの（返信案・校正・見直し・和訳・グルコン・Quiet Edge・聞くの予備） | Codex → Cursor → Claude | GenCode は 1 回 5〜30 分かかるため飛ばす |

- GenCode（フライデー／Genspark `gsk task create super_agent --wait`）は Genspark の残クレジットが **500 未満なら使わない**（松野さん）。1 回の実行で使うのは 1 回まで。
- 上限に当たった係は 1 時間休ませて次へ。どの係も上限で止まるだけで、追加購入・従量には進まない（Cursor は On-demand Disabled）。
- 全部使えないときは、要約系は AI なしのルール版、ボタン系は「作れませんでした」を出す。従量の API には落とさない。

## 仕組み

- 共通部品: `scripts/jarvis_flat_ai.py`（`generate()` / `generate_json()`、`--status` で各係の状態）
- ダッシュボード（Vercel）は AI API を呼ばない。`lib/flatAi.ts` が Supabase `ai_jobs` に依頼を置いて最大 55 秒待つ（英語メールの和訳は 8 秒）。待ちきれないときは「作成中」を出し、もう一度押すと Mac が作った結果が出る。一度返した結果は使い回さない（作り直しは新しい依頼）。`geminiReply()` などの関数名は互換のため残している。
- Mac の係: `scripts/jarvis_flat_ai_worker.py`（launchd `com.matsunoma.jarvis.flat-ai-worker`、KeepAlive、3 秒ごと。Supabase が失敗している間は 10 秒から倍々で最大 300 秒あける）。心拍は `sync_meta.flat_ai_worker_at`。依頼は 3 日で消す。
- 録音の文字起こし: `scripts/jarvis_transcribe_m4a.py` は Mac のローカル Whisper（mlx-whisper）。音声は外に出さない。要約だけ定額AI。
- 「聞く」の神大家資料検索（埋め込み）は `GEMINI_FREE_API_KEY`（課金を無効にした Google プロジェクトの無料枠専用の鍵）だけを使う。無ければ語句検索に落ちる。
- `scripts/jarvis_gemini_research.py` も `GEMINI_FREE_API_KEY` だけ。私的な情報は送らない（無料枠は Google が製品改善に使うことがある）。

## Mac 見張り（停止時だけ Slack #ops に 🔴）

- Supabase pg_cron（5 分ごと）→ `/api/mac-watch`（鍵 `MAC_WATCH_KEY`、Vault `mac_watch_key`）
- 見るもの: Mac の常駐ポーラー（Obsidian、60 秒ごと）と定額AIの係の心拍。10 分以上止まったら 🔴、戻ったら 🟢 を 1 回。
- 前提: Mac は常時電源・スリープなし。macOS の自動インストールはオフ（FileVault のため再起動後はログインまで止まる）。
