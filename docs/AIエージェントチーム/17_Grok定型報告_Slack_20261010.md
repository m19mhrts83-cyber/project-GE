# Grok 定型報告 → Slack（土台）

- 確定日: 2026-10-10（松野意向）
- 方針: **都度の相談は Grok チャットのまま**。**定型報告だけ Slack**（`#report` / `#consult` / `#ops`）
- 秘密を Grok に渡さない → Drive inbox → Jarvis が Webhook 投稿

## 流れ

```
Grok（ホーク／部長／統括）が定型報告を書く
        ↓
admin Drive【with Grok bot】/10_inbox_from_grok/
  frontmatter: action: slack_report
        ↓
jarvis_bucho_inbox_poll（15分 or パートナー確認ついで）
  → jarvis_grok_slack_report_apply.py --apply --archive-done
        ↓
Slack Incoming Webhook（#report 等）
```

| 残すもの | 置き場 |
|---|---|
| 都度の質問・壁打ち | Grok チャンネル（チャット） |
| デイリー／夕方／週次／完了サマリ | Slack（本 MD の `action: slack_report`） |
| 部長日報の全文正本 | **estate Gmail**（従来どおり）。Slack は要約並立可 |
| Todoist 起票 | 従来どおり `action: todoist_tasks`（本経路と別） |

## inbox フォーマット

ファイル名例: `YYYY-MM-DD_hawk_slack_weekly.md`

```
---
action: slack_report
channel: report
source: hawk
bot: ホークアイ（参謀）
kind: 週次統括
title: 週次統括 YYYY-MM-DD
priority: normal
target: jarvis
---

# 週次統括 YYYY-MM-DD

- できたこと: …
- 見てほしい点: …
- 次: …
```

| フィールド | 必須 | 値 |
|---|---|---|
| `action` | ✅ | `slack_report` |
| `channel` | 推奨 | `report` / `consult` / `ops`（省略時 `report`） |
| `bot` / `source` | 推奨 | 投稿ヘッダ用 |
| `kind` | 任意 | デイリー／夕方／週次／完了 等 |
| `title` | 任意 | 無いとき本文の最初の `#` 見出し |

禁止: パスワード・APIキー・Webhook URL・トークンを本文に書かない（スクリプト側でも簡易フィルタ）。

## チャンネルの使い分け

| ch | 用途（Grok 定型） |
|---|---|
| `#report` | 週次統括・日次サマリ・完了報告 |
| `#consult` | 要ボス判断の要約（詳細は Todoist／チャット） |
| `#ops` | 連携障害・健全性の定型メモ |

Webhook がチャンネル専用で無いときは REPORT にフォールバックし、本文先頭に `【#consult】` 等を付ける。

## Jarvis コマンド

```bash
cd ~/git-repos && set -a && source .env.jarvis_private && set +a
# 対象確認
~/selenium_env/venv/bin/python scripts/jarvis_grok_slack_report_apply.py --dry-run
# 投稿＋archive
~/selenium_env/venv/bin/python scripts/jarvis_grok_slack_report_apply.py --apply --archive-done
# poll 経由（既定で両方 apply）
~/selenium_env/venv/bin/python scripts/jarvis_bucho_inbox_poll.py
```

無効化: `JARVIS_GROK_SLACK_REPORT_DISABLE=1` または `JARVIS_SLACK_REPORT_INBOX_AUTO_APPLY=0`

## 秘密（Webhook）

`.env.jarvis_private`（チャットに貼らない）:

```bash
SLACK_WEBHOOK_AI_TEAM_REPORT=https://hooks.slack.com/services/...
SLACK_WEBHOOK_AI_TEAM_CONSULT=   # 任意（無ければ REPORT へ）
SLACK_WEBHOOK_AI_TEAM_OPS=       # 任意
```

手順: [`01_Slackセットアップ/00_手順.md`](01_Slackセットアップ/00_手順.md)  
追記後「Slack Webhook 保存した」と一声 → Jarvis がテスト投稿。

## 磨き（土台のあと）

1. 何を知りたいか（見出し・項目の型）
2. 見やすさ（短文・リンク・絵文字は後から）
3. Bot ごとの定期ルーチンに `slack_report` を1行足す（paste 再生成）
