**方針**: Jarvis 中心。Claude Code は **同じ Mac で `~/git-repos` を直接読める**。  
Grok Bot は Drive 経由が必須。役割が違うので、Claude 用に Grok と同等の Drive ボックスは **当面新設しない**。

## 三層（正）

| 層 | 正 | Claude Code の使い方 |
|---|---|---|
| **短い合図・進捗** | Slack `#ai-hub` | Jarvis／FRIDAY／Grok と同じ。依頼・完了の1〜数行 |
| **作業本体・再開** | git 社員フォルダ（`TASK.md` / `input` / `output`） | **本線**。ツール切替 BCP（[`30_`](30_共通Agentフォルダ規格_BCP_20261017.md)） |

| **Grok↔Jarvis 長文・Macキック** | Drive `【with Grok bot】` | **日常キューに書かない**。Grok へ渡す長文は Jarvis 経由で outbox |

**やらないこと（当面）**: Claude 専用 Drive 新設、Grok フォルダの廃止、Slack だけに長文を全部載せる。

後から「Claude ↔ Grok が Jarvis を介さず長文を置きたい」となったときだけ、`【with AI agents】/claude/` 等を検討する。
