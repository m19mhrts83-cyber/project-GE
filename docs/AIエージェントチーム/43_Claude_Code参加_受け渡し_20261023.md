### 完了音（ツール別・被らせない）

| 誰 | 音 | 設定場所 |
|---|---|---|
| Jarvis（Cursor） | Hero | `~/.cursor/hooks/jarvis-done-notify.sh`（`JARVIS_DONE_SOUND`） |
| Miss Lemon（Claude Code） | Aurora（通知音・約2.2秒） | `~/.claude/hooks/misslemon-done-notify.sh`（`MISSLEMON_DONE_SOUND`）・`~/.claude/settings.json` の Stop hook |
| チャッピー（Codex） | Circles（通知音・約2.4秒） | `~/.codex/hooks/jarvis-done-notify.sh`（`CODEX_DONE_SOUND`・名前は複製のなごり） |
| フライデー（GenCode） | Noir（通知音・約1.9秒） | `~/.config/gencode/hooks/friday-done-notify.sh`（`FRIDAY_DONE_SOUND`）・`~/.config/gencode/plugin/friday-done-notify.js`（`session.idle`・子セッションでは鳴らさない） |

止めるときは `MISSLEMON_DONE_NOTIFY=0`／`CODEX_DONE_NOTIFY=0`／`FRIDAY_DONE_NOTIFY=0`。Glass は AppleScript 等と被るので使わない。長さは約2秒が好み（システム音1秒は短い・着信音3.5秒は長い）。iPhone の通知音（`ToneLibrary.framework/…/AlertTones/Modern/*.m4r`）から選ぶ。途中で切ると不自然なので、もともと2秒前後の音を使う
