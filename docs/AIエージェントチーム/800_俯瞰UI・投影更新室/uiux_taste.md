# 好み帳 — 3アプリの画面づくり（UI/UX）

ジャービスダッシュボード・KURASHIFT・ループウェア（Nody）の画面を作る／直すときに、**作る前に必ず読む**。
松野さんの判断ログ（owner_decisions の uiux_plan / uiux_fix / uiux_rule）から土曜にルール案を作り、
Nody の「画面の好み」（/uiux）で松野さんが「採用」したものだけが ## 確定ルール に入る（AI は勝手にルール化しない）。

- 読む: `python scripts/jarvis_uiux_loop.py context --app dashboard|kurashift|loopware`
- 書き出し: `python scripts/jarvis_uiux_loop.py sync-book`（採用済みを DB から ## 確定ルール へ。正本は DB）
- 採点表（apps/jarvis-dashboard/config/uiux_scorecard.json）は「一流との差」、好み帳は「松野さんの好みとの差」を縮める。
  次の一手は「採点表で低い項目を、好み帳に沿って直す」。

書き方（1行1ルール、| 区切り）:
`- R800-<連番> | ui | app:<dashboard/kurashift/loopware/*> & item:<採点表の項目> | v1 YYYY-MM-DD | 根拠 <判断ログid> | ルールの文`

## 仮説

（効かせない。過去のやり取りから拾った候補。Nody /uiux で採否をもらう。2026-11-14 時点）
- H1 | ui | app:* & item:見た目の美しさと統一感 | 成績・成熟度・「溜まった」実感など、気持ちが上がる画面は動き（数え上がる数字・伸びるバー・粒が落ちる）で見せる | 根拠: 成熟度タブ「モーショングラフィックスでかっこよく」(11/13)、判断ログ「溜まった演出が良い」(11/8)
- H2 | ui | app:* & item:集中を守る | ぱっと見で分かる順に置く：要約（リング・点数）→ 次の一手 → 詳細は押して開く | 根拠: 成熟度タブ「ぱっと見でわかりにくい」→ リング・次の一手・バーに作り直し (11/13, PR #395)
- H3 | ui | app:* & item:手数の少なさ | 並べ替えなどの操作はドラッグのように直感的に。先頭の「いまやること」は動かさない | 根拠: ホームのカード並べ替え依頼 (11/13, PR #395)
- H4 | ui | app:* & item:わかりやすさ | 点数や比較は、根拠（比較相手の公式サイト・実測値）へ1タップで飛べるようにする | 根拠: 採点カードに比較相手へのリンク依頼 (11/13, PR #391)
