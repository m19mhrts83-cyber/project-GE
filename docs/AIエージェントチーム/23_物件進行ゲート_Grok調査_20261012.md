### Bカードの表示（モバイル優先・2026-10-13）

- **等幅の表（``` ）は使わない**。iPhone Slack は折返して桁が崩れるため。
- 構成は `*■ 概要*` / `*■ 物件*` / `*■ リスク（足切り）*` / `*■ 判定材料*` / `*■ 判断*` の箇条。折返しても読める形にする。
- **概要**に「価格」「土地値」「土地値率」「所在」を明示する。
  - **土地値**＝相続税路線価 × 土地面積（万円）。`land_appraisal_man`、無ければ `route_price_tsubo`×`land_area` で算出。
  - **土地値率**＝土地値 ÷ 価格（％）。`land_appraisal_man`÷`price_man`、無ければ `land100_ratio` から。
  - **利回り**は2観点で併記：**表面（マイソク賃料）**と**想定（独自調査＝S3需給／ペルソナ）**。
    - 表面＝`yield_pct`（`yield_info` type=confirmed／マイソク賃料）。家賃は `monthly_rent_yen` か価格から逆算。
    - 想定＝`summary_json.yield_info`（type=estimated の `yield_range`・`monthly_rent_range`・`source`）。
      無ければ満室年収（`annual_rent_man`/`満室年収_万`）から算出。出典（スマサテ／SUUMO ONR 等）を併記。
    - 聞くゲート判定は **想定優先**（無ければ表面）。概要に「利回り：表面 X ／ 想定 Y」行、詳細は `*■ 利回り*`。
  - 路線価が複数（91E／110E／115E 等）なら「金額／率」を併記。
- Yes/No/詳細は `<URL|ラベル>` の**ラベル付きリンク**（長い URL を本文に出さない）。
- 実装: `scripts/jarvis_property_gate_lib.py` の `format_judgment_card()` / `format_b_card()` / `land_value_lines()`。
  同項目を「全文」HTML（`apps/jarvis-dashboard/lib/propertyGateAction.ts`）にも反映。

## 保留リマインド＆履歴（2026-10-13）

確定: 2026-10-13。実装: `scripts/jarvis_property_gate_remind.py`。

### 保留リマインド（#consult・1日1回）

- 未判断のBカードを**古い順**に1通へまとめて通知（Yes/No/全文リンク付き）。
- 通知の前に自動整理（**履歴は消さず decision を付けて保留から外す**）:
  - **すでに問合せしたもの**（`inquiry_sent_at`／`inquiry_status`=sending/awaiting_reply/has_reply／`property_gate.decision`）→ 除外
  - **重複**（同一 fingerprint で既に判断済み）→ 除外
  - **問合せ済みで Yes にしたもの** → 除外
- 新しすぎる（既定 12h 未満）カードは次回以降。当日投稿済みは `last_reminder_date` で再投稿しない（`--force` で可）。
- 朝バンドル（`jarvis_property_gate_degraded.py`）から自動実行。
- **洪水対策**: 114 は `--max-b`（既定 5）で1回のBカード投稿を上限化。超過分は `b_deferred_at`
  として保留登録し、翌回以降に順次投稿。未投稿の保留もリマインドが1通で拾う。

### 問合せ履歴

- 問合せ・判断は Supabase **`kurashift_re_deal_events`** に記録（`created` / `grok_applied` /
  `grok_handoff_sent` / `inquiry_sent` / `inquiry_reply` / `review_*` 等。actor 付き）。
- 見る方法:
  - CLI: `jarvis_property_gate_remind.py --history --deal-id UUID` ／ `--history --recent N`
  - 「全文」（ログイン不要ページ `/api/g/d/{id}`）の下部「問合せ・判断履歴」
