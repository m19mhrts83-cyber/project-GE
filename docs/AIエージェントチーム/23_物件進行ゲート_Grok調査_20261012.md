## 3レーン

| レーン | 条件 | 次 |
|---|---|---|
| **A 自動** | `聞く` かつ (`portal_sent` 済 or Tier3相当の高スコア＋`awaiting_first_inquiry`) | 511／Tier3。松野判断不要 |

## Slack Yes/No

1. 114 が `#consult` に Bカード（deal_id・見てほしい3点・Yes/No URL）
2. 松野が **Yes** / **No**（カード内 URL、または Slack ボタン、または CLI）
3. `GET|POST /api/slack/consult-action`（jarvis-dashboard）→ `re_deal_inquiry_send` ジョブ
4. Mac `jarvis_kurashift_job_worker` が `re_inquiry --i-confirm-send`（B の Yes＝了承）
5. No → 見送り（status `passed`、inquiry クローズ）

### 配線（Free 可）

| 項目 | 設定 |
|---|---|
| リンク Yes/No | `.env.jarvis_private` + Vercel の `PROPERTY_GATE_ACTION_TOKEN` |
| ボタン（任意） | Slack App Interactivity Request URL = `https://jarvis-dashboard-amber.vercel.app/api/slack/consult-action`、`SLACK_SIGNING_SECRET` |
| CLI | `jarvis_property_gate_511.py --deal-id … --yes|--no` |
| 無効化 | `JARVIS_PROPERTY_GATE_DISABLE=1` または state `disabled` |
