## 部門状態ボード

各 `NNN_…室/00_状態ボード.md` — registry から生成。手編集より **sync スクリプト**を正とする。

## 必須運用（作成・status変更のたび）

どのAIツール（Claude Code / Cursor / Codex / GenCode / Grok 経由の Jarvis 等）でも:

1. `agents_registry.yaml` の `status` を直す（または新規行を足す）
2. 索引を必要なら直す
3. **必ず同期を実行**:

```bash
cd ~/git-repos && ~/selenium_env/venv/bin/python scripts/jarvis_agent_team_status_sync.py
```

これで: 社員マーカー ↔ 部門 `00_状態ボード.md` ↔ README接頭辞 ↔ Drive写し が揃う。
