# Slack セットアップ（Free 試用）

オーナー推奨: **m19m**（`m19m.hrts83@gmail.com`）。Drive 正本は admin のまま。

## 1. ワークスペース作成

1. https://slack.com/get-started を開く（m19m でログイン）
2. 新規 WS 名: **`AIエージェントチーム`**
3. 当面メンバーは自分1人でよい（Free）

## 2. チャンネル

次の3つを作る（公開で可）:

| チャンネル | 用途 |
|---|---|
| `report` | 業務系AI社員の完了報告 |
| `consult` | 要判断・人確認 |
| `ops` | 連携健全性（GHA／WeStudy／LINE） |

※ Slack 上は `#report` と表示される。

## 3. Incoming Webhook

1. https://api.slack.com/apps → **Create New App** → From scratch  
   - App Name: `Jarvis AI Team`  
   - Workspace: 上記 WS
2. **Incoming Webhooks** → On
3. **Add New Webhook to Workspace** → 先に `#report` を選ぶ → URL をコピー
4. 同様に `#ops` 用も作るとよい（1本で両方に使うなら `#report` のみでも可）

## 4. 秘密の保存（チャットに貼らない）

`~/git-repos/.env.jarvis_private` に追記:

```bash
SLACK_WEBHOOK_AI_TEAM_REPORT=https://hooks.slack.com/services/...
SLACK_WEBHOOK_AI_TEAM_OPS=https://hooks.slack.com/services/...
```

OPS をまだ作っていないときは REPORT だけでもよい。  
追記したら Jarvis に **「Slack Webhook 保存した」** と一声ください（テスト投稿します）。

## 5. テスト投稿（Jarvis 側）

```bash
cd ~/git-repos && set -a && source .env.jarvis_private && set +a
/Users/matsunomasaharu2/selenium_env/venv/bin/python scripts/jarvis_slack_webhook_post.py \
  --channel report --text '【テスト】AIエージェントチーム hub 準備OK'
```

スマホに通知が来れば Phase 1 完了。
