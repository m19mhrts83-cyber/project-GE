## 1. ワークスペース（残り）

1. 「**新しいワークスペース**」を開く（Chrome／Slack アプリ）
2. 設定 → ワークスペース名を **`AIエージェントチーム`** に変更
3. URL（`https://….slack.com`）を控える → 後で jarvis_private の `SLACK_WORKSPACE_URL` に入れる

※ 誤ってもう1つ作らない。旧「AIエージェント」は触らなくてよい（後で削除可）。

## 2. チャンネル

次の3つを作る（公開で可）:

| チャンネル | 用途 |
|---|---|
| `report` | 業務系AI社員の完了報告 |
| `consult` | 要判断・人確認 |
| `ops` | 連携健全性（GHA／WeStudy／LINE） |

※ Slack 上は `#report` と表示される。

## 3. Incoming Webhook

1. https://api.slack.com/apps → **Create New App** → From scratch  
   - App Name: `Jarvis AI Team`  
   - Workspace: **AIエージェントチーム**（新しい方）
2. **Incoming Webhooks** → On
3. **Add New Webhook to Workspace** → 先に `#report` を選ぶ → URL をコピー
4. 同様に `#ops` 用も作るとよい（1本で両方に使うなら `#report` のみでも可）

## 4. 秘密の保存（チャットに貼らない）

`~/git-repos/.env.jarvis_private` に追記:

```bash
SLACK_LOGIN_EMAIL=m19m.hrts83@gmail.com
SLACK_WORKSPACE_URL=https://xxxx.slack.com
SLACK_WEBHOOK_AI_TEAM_REPORT=https://hooks.slack.com/services/...
SLACK_WEBHOOK_AI_TEAM_CONSULT=https://hooks.slack.com/services/...   # 任意
SLACK_WEBHOOK_AI_TEAM_OPS=https://hooks.slack.com/services/...       # 任意
```

CONSULT / OPS が無いときは REPORT にフォールバック（本文先頭に `【#consult】` 等）。  
追記したら Jarvis に **「Slack Webhook 保存した」** と一声ください（テスト投稿＋Grok定型経路の確認をします）。
