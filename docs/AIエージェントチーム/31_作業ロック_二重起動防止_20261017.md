## CLI（実装先）

`scripts/jarvis_agent_run_lock.py`

| サブコマンド | 意味 |
|---|---|
| `acquire --task-id … --agent-id …` | 実行中なら exit 2。取れれば lock 作成 |
| `release --task-id …` | lock 削除／status=done |
| `status [--task-id …]` | 一覧または1件 |
| `stale-clear --hours 6` | 古い running を掃除（落ちたプロセス用） |

## 使い方（社員フロー）

1. 作業開始前: `acquire` → 失敗なら「実行中」と報告して止める
2. `TASK.md` の status=running
3. 処理
4. `release` ＋ TASK.md を done／failed

任意: 主要 runner（例: property_gate）の冒頭で `acquire` を呼ぶ（段階導入）。

## やらないこと（当面）

- 分散ロック（Redis 等）
- Slack からの承認フローと一体化
