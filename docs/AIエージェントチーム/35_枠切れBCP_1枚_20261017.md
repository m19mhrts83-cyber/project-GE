## 切れたときの手順（人承認）

1. **何が切れたか**を書く（Cursor／GenCode／両方）
2. 進行中の仕事があれば社員フォルダの **`TASK.md`** に `executor`・完了条件・途中成果を残す
3. **代行チェーン（先頭固定）**: **GenCode → Claude Code → Codex**  
   - Cursor 本線が残っている／on-demand 可なら、相談・指揮は Cursor のまま可  
   - Claude Code 未課金のあいだはチェーンから飛ばしてよい（611 が提案時に明記）
4. Slack **`#consult`** で切替案を出し、松野了承後だけ反映（611／Jarvis）
5. 完了を **`#ops`** に1通
