## 確定（このPR）

1. 依頼口は Slack `#ai-hub` で シャア大佐（`U0CLH5AARJT`）か担当の隊長をメンション。大佐が振り分ける。
2. Grok が直接 Slack に書けない時の経路: Drive `10_inbox_from_grok/` に MD（`action: slack_report`／`channel: ai-hub`／`mention: 大佐`）→ Mac の `jarvis_bucho_inbox_poll.py`（15分）→ `jarvis_grok_slack_report_apply.py` → Incoming Webhook で `#ai-hub`。
3. メンション: Webhook の本文に `<@ユーザーID>` を入れれば Slack 上でメンションになる（平文の `@名前` は通知されない）。そこで `mention:` に名前を書くと、スクリプトが `ORCA_MENTION_IDS` の ID に直して本文先頭に入れる。ID が未登録の名前は「＠名前（ID要確認）」の平文になる。
4. ID: 大佐 `U0CLH5AARJT`、番頭さん `U0CM0MLFBGT`。ラスカル・ラコ・こんぶ・ペド隊長は **要確認**（Slack コネクタの検索では見つからず、`orca slack find` はボットのチャットからしか動かない）。
5. 要確認: Webhook 投稿は「ボットの投稿」なので、Orca のボットが **ボット発のメンションに反応するか** は実際に1回流して確かめるまで不明（このPRでは投稿していない）。反応しない場合は、Mac 側が #ai-hub の投稿を `orca` へ中継するか、Grok→Mac→大佐への直接受け渡しを足す案を別に出す。
