## 結論

Slack FB（`#report`/`#consult`）と Todoist 人コメントを、チャット依頼なしで拾う。  
**Mac launchd 本線**＋**GHA L1 冗長**＋**Cloud L2（枠あり時）**。担当は **317 コメント起動係**。

## 冗長の3層

| 層 | 内容 | 実行場所 |
|---|---|---|
| L0 | Todoist Webhook 受信 | Vercel（既存） |
| L1 | 拾い・Ack・分類 | Mac／stale 時 GHA |
| L2 | 許可リスト AI 処置 | Mac Local Agent／Cloud（枠あり） |

- heartbeat: `sync_meta.comment_dispatch_heartbeat_at`（約10分無更新で stale）
- 停止: `JARVIS_COMMENT_DISPATCH_DISABLE=1`／`JARVIS_COMMENT_DISPATCH_FAILOVER=0`
- Mac 間隔: launchd **300秒**
- **夜間除外（JST）**: 既定 **0:00〜6:00** は Mac／GHA とも処理スキップ（Mac は quiet heartbeat のみ）。変更: `JARVIS_COMMENT_DISPATCH_QUIET_START`／`END`、無効: `JARVIS_COMMENT_DISPATCH_QUIET_DISABLE=1`
- Hobby Vercel `*/5` Cron は使わない（GHA ping 型）

## 設計ゲート

- 入口: Slack FB ＋ Todoist `note:added`
- 確認: L1 自動。対外・金・方針は人。L2 は許可リスト＋claim
- 履歴: Todoist コメント／Slack／`.jarvis_state/comment_dispatch.json`／heartbeat
- 停止: 上記 env／state

## Phase B（許可リスト AI）

| 経路 | 動作 |
|---|---|
| Mac `--phase-b` | Local Agent（`cursor-agent`）本線。不可なら Todoist キューコメント |
| failover `--phase-b` | Cloud Agent（`CURSOR_API_KEY`）。枠なし→`#consult`「Mac復帰待ち／枠なし」 |
| 上書き | `JARVIS_COMMENT_DISPATCH_PHASE_B_CMD`（shell）／`JARVIS_COMMENT_DISPATCH_CLOUD_L2=0` で Cloud 停止 |

許可リスト例: 表確認・確認のみ・launchd resume・オーナー確認・内容教えて・docs 1行。対外・金は常に人。
