## 6. 作業手順（一本の流れ・必ずこの順）

外部ツール（GHA／launchd）と AI は**別線にしない**。取込手段が違うだけの**分岐→合流**。

1. **枠判定**: 昼／夜／副合図のどれか
2. **取込**（枠に応じて）
   - 昼: Gmail＋Chatwork のみ → `5.やり取り.md`
   - 夜: ダッシュボードを開く ＋ LINEグループ（Tcell／LEAF／823）。必要なら iMessage・MailGates・くらさぽ
   - 815オプチャは本係の `#report` に載せない（ダッシュボード別枠）
3. **正本突合**: `5.やり取り.md` と突き合わせ、未反映の新規差分だけ残す
4. **差分要約**（更新があるとき）: 物件・契約論点／要対応のメモ。Todoist 起票は**案の提示まで**（無言起票しない）
5. **人確認**: 松野が `5.やり取り.md` と Gmail 要対応を見る（夜はダッシュボードも）
6. **合流出口**: 更新があるときだけ Slack `#report`（枠・チャネル別件数・失敗・相談有無）
7. **送信**は別係・了承後のみ（この係では送らない）

**更新ゼロなら 4〜6 の Slack は送らない。**
