# 人が見る場所・対応のしかた（111・Jarvis／代行AI向け）

更新: 2026-10-15（特記のみ・ゼロ1行）

## 結論（短く）

| 見たいもの | どこを見るか |
|---|---|
| **やり取りの正本** | OneDrive `26_パートナー社への相談/*/5.やり取り.md` |
| **定時の気づき** | Slack `#report`（更新・失敗・特記があるとき。ゼロは1行またはスキップ） |
| **要対応の能動チェック** | **Gmail**（要対応ラベル／未読）も見て、適宜 Jarvis に指示 |
| **横断俯瞰（夜）** | Jarvis ダッシュボード |
| **815オプチャ** | ダッシュボード `/openchat`（返信提案しない） |
| **報告のダメ出し・是正** | Jarvis（[`28_`](../../28_Slackダメ出しの繋ぎ_20261015.md)） |

## やらないこと

- **Notion に外部ツールのワークログを残す案は不要**（正本は MD。対処は MD／Gmail／Slack を見て行う）
- 更新ゼロの長いテンプレ連投（「見る」「次」の繰り返し）
- 815 への返信提案をパートナー報告に混ぜる

## 動か方（人と AI）

1. **受動**: Slack `#report`（昼 GHA／夜 Mac）が来たら内容を見て指示・返信判断  
2. **能動**: Gmail の要対応も見て、必要なら「パートナー確認して」「〇〇へ返信案」等を Jarvis／代行に指示  
3. **深掘り**: 該当パートナーの `5.やり取り.md`（必要なら送信下書き）
4. **文面・頻度の是正**: 1on1／チャットで Jarvis にダメ出し（414 は待たない）

この係の報告は「一覧の代わり」ではなく、**差分の知らせ**。詳細は常に MD（と Gmail）が正。

## 社内全体か

当面は **パートナー連絡整理係（111）の運用**として共有。他社員への一律適用は、同型の「正本が MD／Gmail」のときだけコピーしてよい。
