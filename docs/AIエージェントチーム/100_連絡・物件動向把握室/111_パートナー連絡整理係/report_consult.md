## チャネル色分け

| 色 | 昼 | 夜 |
|---|---|---|
| Gmail / Chatwork | GHA 本線 | 必要なら補完 |
| LINEグループ（Tcell/LEAF/823） | 報告に含めない（「夜確認」可） | Mac フル本線 |
| iMessage / MailGates / くらさぽ | なし | Mac フル |
| 815オプチャ | 載せない | ダッシュボード `/openchat`（返信提案しない） |

## フォーマット必須項目

**報告**
- 係名／枠（昼・夜）
- やったこと（チャネル別件数）
- 結果（追記あり／なし）
- うまくいかなかったこと（なければ「失敗なし」）
- 次（相談の有無）

**相談**
- 決めてほしいこと／材料／選択肢（A/B）／急ぐか

## 読みやすさ
