## 新規AI社員の作り方（二段階・正）

詳細: [`06_社員の作り方_二段階_20261009.md`](06_社員の作り方_二段階_20261009.md)

| 段階 | 場 | やること |
|---|---|---|
| **第1** | Agent Team Builder | 全体構成を俯瞰。足りない社員を追加しながら編成を固め、フォルダ構成の目安を決める |
| **第2** | AIオートメーション（Flowforge） | フォルダ配置後、**1体ずつ**動きのたたきを作り、Jarvisと相談しながら磨き上げ。`flow.md` にリンクを残す |

ハブ側の作業順:

1. 第1段階で編成を固める
2. `_template/` → `NNN_名前/`（IDは登記簿）
3. `CLAUDE.md` / `AGENTS.md` / `README.md` / `flow.md` / **`TASK.md`** を埋める。`config/` `input/` `output/` `tests/` を用意（第2段階と並行可）。規格: [`30_共通Agentフォルダ規格_BCP`](30_共通Agentフォルダ規格_BCP_20261017.md)
4. `agents_registry.yaml` と `00_チーム索引.md` に1行追加。権限は `config/agent_team_permissions.yaml`（`can_do`／サイトPWなら `site_logins`）
5. **`jarvis_agent_team_status_sync.py` でマーカー＋部門状態ボード＋権限・運用投影を同期**（`agentTeam.json` を push）
6. Flowforge で動いて Slack に届くまでを **1体分**やりきる

他ツール向け共通指示: [`CLAUDE.md`](CLAUDE.md)（[`AGENTS.md`](AGENTS.md) は互換入口）  
**BCP**: Cursor制限時も同じ `TASK.md`＋入出力で Claude Code／GenCode／launchd に引き継ぐ（[`30_`](30_共通Agentフォルダ規格_BCP_20261017.md)／枠切れ1枚 [`35_`](35_枠切れBCP_1枚_20261017.md)）
