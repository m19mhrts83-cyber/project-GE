## 協業ツール方針（2026-10-09）

- Chatwork **有料維持**（相手窓口。解約して新規にしない）
- Slack **Free試用 → 必要なら有料**
- Todoist Pro 維持
- AI社員の**報告・相談**は Slack。相手との業務連絡は従来チャネル（メール／LINE／Chatwork）

## 新規AI社員の作り方

1. `_template/` をコピーして `NN_名前/` を作る
2. `CLAUDE.md` / `AGENTS.md` / `README.md` / `flow.md` を埋める
3. `00_チーム索引.md` に1行追加
4. Flowforge でフローを描き、動いて Slack に届くまでを1体分やりきる
