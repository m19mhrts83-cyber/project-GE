## 見えたことの整理

1. **CMS 系の更新は対象外**だった。外から見えるものは Next.js 自作アプリと静的ページだけ。
2. **要更新はすべて Next.js の依存**。直す時は別アイテム・別 PR（319 は点検と提案まで）。
   - jarvis-dashboard・loopware・trade-desk は Next 15.5.29 のまま。16 系へ上げるか、15 系の指摘が直る版を待つかの判断が要る（上げ方は松野さんが決める）。
   - 共通して出ているのは画像処理（sharp）・CSS 処理系（postcss・source-map-js）の間接依存。`npm audit fix` で直るものと Next の更新が要るものがある。
3. **Vercel 側**は `deploymentEnabled: false`（git push で自動デプロイしない）。「最終デプロイ日」が古いサイトは、手動デプロイを忘れているだけの可能性がある（prompt-share は 2026-08-10）。
4. `Server` ヘッダは Vercel／GitHub.com／Google Frontend のみ。Apache・nginx などの版は出ていない（出さない構成で良い）。

## 確かめられなかった点

- #11〜#13（agent-team-builder・claude-code-supabase-fukushu・サイトA）: Vercel のチーム一覧に出ないため、デプロイ日・版が読めない。松野さんに「どれが本当に自分のものか・まだ使っているか」を聞く（使っていないなら閉じる提案）。
- #5 kamiooya-qa-web: Vercel の project-ge と同じものかは推定。トップが 503 の理由（意図した停止か）は未確認。
- FlowForge: GCP 側でデプロイ日・Next の版を見ていない（権限がない）。
- ログインが要るページの中身（トップでログイン画面へ転送される #1〜#3）は見ていない。**ログイン後の部分の更新有無は対象外**。
- DNS・独自ドメインの登録（レジストラ・WHOIS）はリポ内に記録が見つからなかった。ドメインの更新期限は未確認。
- 取得は各サイト1回。時間をかけた変化（キャッシュ・ばらつき）は見ていない。
