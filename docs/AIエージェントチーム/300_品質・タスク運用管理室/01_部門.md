### 役割の分け方

- **ホーク**：全体の優先順位・対応判断・担当割当（横）
- **番頭さん**：停滞・抜け漏れの発見と指摘（横）
- **BL**：自分の室の中の実行と把握（縦）。他の室の仕事は引き取らず、気づいたら報告する

### BL の決まり

- 正本はこのハブ（`docs/AIエージェントチーム/`）。ボット自身の記憶と食い違ったらハブを優先し、食い違いを報告する
- 直すときは `~/git-repos` の worktree で直して PR にする。main と Drive の写しは直接編集しない
- 対外送信・削除・課金変更・Todoist の close・社員の `status` 変更は、松野さんの了承まで実行しない
- 動くのはこの Mac が起きている間だけ。本番の定期実行は GHA／launchd のままにする
- 社員フォルダを変更したら、同じターンでその社員の `CLAUDE.md` か docs を更新する

### 試行の見方

- まず 300 室の1体だけで試す。他の室へ広げるかは、報告の質と利用枠の消費を見て松野さんが決める
