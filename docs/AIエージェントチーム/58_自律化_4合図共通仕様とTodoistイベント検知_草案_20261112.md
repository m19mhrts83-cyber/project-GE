- 作成: 2026-11-12 Miss Lemon（313 タスク処置・Todoist `6hwmh95R2946X4Wv`）
- 状態: **承認済み（2026-11-12 松野さん）**。実装担当は Miss Lemon
- 関連: [`config/agent_team_ops.yaml`](../../config/agent_team_ops.yaml)（合図4種）／[`44_`](44_コメント常駐起動_317_20261022.md)（317・Webhook 冗長）／[`55_`](55_Banto_Grok連携運用_20261107.md)・[`54_`](54_Grok_番頭Banto相互補完_20261107.md)（ホーク・番頭）／312 起票整理係

## 結論（案）

1. **合図の言葉は既存の4種をそのまま共通語にする**（新しく作らない）: `human`（人が頼む）／`schedule`（時間）／`event`（何かが届いたら）／`watch`（変化・失敗を見回ったら）
2. **Todoist の変更検知は Webhook を本線**にする。すでに Vercel `/api/todoist/webhook` → Supabase `todoist_webhook_events` が動いている（署名検証あり）。**ポーリングは取りこぼしの補完だけ**（1日1回の差分照合）
3. 新しい常駐の仕組みは作らず、**317 の拾い（L1）にイベント種別を足す**形で広げる

## Webhook とポーリングの比較

| 観点 | Webhook（本線案） | 定期ポーリング |
|---|---|---|
| 速さ | 数秒で受信。処理は 317 の5分間隔 | 間隔しだい（5分〜） |
| 費用 | 0円（Vercel Hobby・Supabase 無料枠） | API 呼び出しが増える。Mac か GHA の枠を使う |
| 取りこぼし | Vercel 停止・署名不一致で落ちうる | 間隔内の中間状態は見えない |
| 既存 | **あり**（note:added・item:completed を処理中） | `jarvis_watch_todoist_sync.py`（監視用） |
| 結論 | 本線 | 補完（日1回、Webhook に無い変更だけ拾う） |

## イベント1件の共通の形

どの合図でも、次の項目を持つ行として扱う（置き場は下の「決めてほしいこと 2」）。

| 項目 | 内容 |
|---|---|
| `event_id` | `<source>:<元のID>`（例 `todoist:note:12345`）。**重複判定キー** |
| `kind` | human／schedule／event／watch |
| `source` | todoist／slack／gmail／gha／launchd 等 |
| `occurred_at` | 起きた時刻 |
| `ref` | 元のタスク・スレ・メールへのリンク |
| `status` | new → claimed → done／failed／skipped |
| `claimed_by` | 担当（社員番号＋ツール名） |
| `attempts`・`last_error` | 再試行の回数と最後の失敗 |

## 流れ（既存の役割に当てはめる）

| 段 | 担当 | 既存の仕組み |
|---|---|---|
| ① 受信 | Vercel Webhook | `todoist_webhook_events` |
| ② 重複判定 | 317 L1 | `event_id` が処理済みなら skipped。同じタスク・同じ種別が5分以内に続いたら1件にまとめる |
| ③ 振り分け判断 | ホーク | 担当が決まっていない／要判断のものだけ。担当が明らかなもの（自分の社員の定型）はホークを通さない |
| ④ 処置 | 担当 AI | 社員 `TASK.md` に書いてから着手（[`31_` 作業ロック](31_作業ロック_二重起動防止_20261017.md)） |
| ⑤ 解決確認 | 番頭さん | 完了申告とは別に、成果物で確かめる（55_） |

- **312 との重複回避**: イベント起点の Todoist 起票は **312 経由だけ**。既存タスクがあればコメントで足す（新規起票しない）
- **313 との関係**: 期日の付いたタスクの処置は 313（毎朝10:30）。イベントでは期日を動かさない

## 再試行・停止・権限・費用

- 再試行: 3回まで（5分・30分・2時間あけて）。だめなら `failed` にして `#ops` に1行
- 停止: 種別ごとの `*_DISABLE=1`。夜間 0:00〜6:00 は処理しない（317 と同じ）
- 権限: 55_ の範囲のまま。対外送信・お金・削除・方針は人。権限は広げない
- 費用: 受信・判定は 0円。AI の処置は Mac の枠内。Cloud は Mac が止まっているときだけ（44_ と同じ）

## 決定（2026-11-12 松野さん）

1. Todoist は **Webhook 本線＋日1回の補完**
2. 共通の形の置き場は **(A) 既存テーブルに列を足す**（`todoist_webhook_events` 等）。共通テーブルは新設しない
3. ホークの判断は **担当未定・要判断のイベントだけ**に挟む
4. 実装担当は **Miss Lemon**（Todoist の【提案】タスクで追う）
