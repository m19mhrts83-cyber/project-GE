## ルール

- **リーダー格（部長・統括・参謀）= 1文字＋先頭★**（H / C / S / R / F / M / P / A）→ UI: `★[H] …`
- **配下 = 文字＋番号（1始まり・★なし）**（S1–S13、F1–F5、M1–M10、P1–P2）→ UI: `[S1] …`
- **W（天気）** はリーダー記号だが部長格ではない → `★` なし（`[W] 天気お知らせ`）
