## 磨きサイクル（正）

少し作る → 使う／確認する → ダメ出し → 直す、を回す。意図OKの報告を見てフィードバックする。

```
ビルダー／Flowforge で1体（または1タスク）作る
        ↓
Slack #report に「できたこと・見どころ・要確認」を報告
        ↓
松野がダメ出し／意図OK
        ↓
Jarvis がフローを直し、再報告
        ↓
（並行）次の社員のレビュー・作成に着手
```

| 役割 | やること |
|---|---|
| AI社員／Jarvis | 定期・節目で Slack に報告。フローURL・変更点・残課題を短く |
| 松野 | 報告を見てダメ出し or 意図OK |
| Jarvis | ダメ出しを Flowforge／ハブに反映し、再報告。次の1体も並行で進める |

報告の型（`#report`）:

```
【社員報告】{係名} / {タスク名}
- 状態: 初回作成 | 磨き中 | 意図OK候補
- フロー: {URL}
- できたこと: …
- 見てほしい点: …
- 次: …
```

ダメ出し・判断は `#consult`。連携障害は `#ops`。
