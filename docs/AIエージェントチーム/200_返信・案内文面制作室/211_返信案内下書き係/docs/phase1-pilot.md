# Phase 1 — パイロット社の決め方

更新: 2026-10-11

## 何を決めるか

朝便の「最初の1回」は、**管理会社1社だけ**で試します。  
全社一斉は Phase 2 以降です。

## 推奨（そのまま使ってよい）

**パイロット社: LEAF（104_LEAF）**

理由（初心者向け）:

1. メール中心で経路が単純（Gmail で完結しやすい）
2. Todoist の管理会社ラベル・要約フッターの検証先として既にある
3. Guest 共有パイロット対象でもあり、後工程とつながる

## 別社にしたいとき

チャットで社名だけ書いてください（例: 「ミニテックで」）。  
候補: ミニテック / ホームプランナー / Tcell

## あなたがやること

1. 下の一文をチャットに送る（推奨どおりならこのまま）  
   `パイロットは LEAF で OK。TODO 全部 OK`
2. 特に操作・インストールは不要

## Phase 1 で AI がやること（OK 後）

1. 夜間〜早朝相当の LEAF 新着を `5.やり取り.md` から読む（必要なら取込）
2. 要返信なら `4.送信下書き.txt` に正本保存（件名1行目）
3. **送信しない**
4. 起案があれば Slack `#report` に件数報告（全文は載せない）。対象0なら Slack は送らない
5. 退去・見積案件なら見積B確認待ちを明示（必要なら `#consult`）

## 成功の見え方

- OneDrive `104_LEAF/4.送信下書き.txt` が更新されている（または「要返信なし」と報告）
- 起案ありなら Slack `#report` に【報告】返信案内下書き係の1通がある
- 「承認待ち・未送信」が分かる（送信はこのフローではしない）
