# リソース・家計室

家計・課金に加え、**AIリソースの見える化と頻度コントロール**を担う。

| ID | 係 | 役割の芯 |
|---|---|---|
| **611** | リソース制約要約係 | 使用状況＋レビュー → 頻度の減／増の提案 |
| 612 | 課金・年会費ガード係 | **払う側** — カード年会費・二重課金 |
| 613 | Zaim鮮度・二重取込係 | 銀行連携鮮度・二重取込の安全直し・**費目学習**（出口 `/zaim`） |
| **614** | ポイント・還元ウォッチ係 | **得る側** — テイチャン／Vポイント／ETC還元 → `/vpoint` `/etc` ＋ **Slack `#report`** |
| **616** | 寄せリマインド係 | 引落バッファ不足の**検知・促し**（送金しない） |
| **617** | 資金移動係（J専） | 寄せの**定型の型**。**実行依頼は Jarvis のみ**（他ツールは送金しない） |

枠切れ時のツール代行は **813**（800室）とセットで動く。
