## B. AIエージェント共通運用ルール 改訂版（#ai-hub 11/1 21:58・ChatGPT 経由で松野投稿）

- **設計は必要なときだけ分ける。実装・テスト・自己レビュー・修正は同じスレッドで完結**する。ChatGPT を毎回のレビューに挟まない。
- 新しいスレッドを提案するのは: 調査→実装へ移る／担当が変わる／目的・範囲が変わる、のとき。同じ実装の直し・検証は続ける。
- 大きい・危ない変更だけ、別 AI の独立レビューを検討する。指摘は元のスレッドで直す。
- 引き継ぎは会話全文でなく、確定事項・制約・未確認事項・成果物。TASK.md の型は Goal / Background / Scope / Requirements / Acceptance Criteria / References / Instructions / Safety / Output。
- **完了報告は #ai-hub に**: 変更内容／テスト結果／未完了事項／次の推奨アクション（短く）。
- 削除・契約・送金・対外送信・有料操作・デプロイは事前承認。秘密は投稿しない。
  （本番反映は「手間を最小に」の方針どおり、了承をもらったうえで実装側が自分で行う）
