### 受けた → 対応した（可視性・必須 2026-10-22）

松野がスレにコメントした時点ではすぐ直せないことがある。**不安にならないよう、拾った／直したことがスレ上で見えるようにする**（Cloud Agent PR #119 で本線化。317 も同コンセプト）。

| 段階 | スレに書く／付ける | いつ |
|---|---|---|
| **受けた（見た）** | 返信 `【Jarvis】受けた（…）` ＋ 元コメントに 👀（`eyes`） | poll／317 L1 直後 |
| **対応した** | `【Jarvis】対応したよ` ＋何をしたか1〜5行 | コード／起票／設定を直した直後 |
| **任意** | 元コメントに ✅（`white_check_mark`） | 対応したと同時 |

- 「受けた」だけで終わらせない（実装・起票が済んだら必ず「対応した」）
- 履歴はスレに残るので、あとから「ちゃんと対応してくれた」と確認できる
- helper: `build_ack_text` / `build_done_text` / `REACTION_SEEN`（`jarvis_slack_report_fb_lib.py`）
- Todoist 側の同コンセプト: `【Jarvis】見たよ（受けた）`（`build_todoist_seen_text`・317／Webhook）
