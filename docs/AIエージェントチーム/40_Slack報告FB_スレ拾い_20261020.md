### 受けた → 対応した（可視性・必須 2026-10-22）

松野がスレにコメントした時点ではすぐ直せないことがある。**不安にならないよう、拾った／直したことがスレ上で見えるようにする**（Cloud Agent PR #119 で本線化。317 も同コンセプト）。

| 段階 | スレに書く／付ける | いつ |
|---|---|---|
| **受けた（見た）** | 返信 `【AIチーム】受けた` ＋ 元コメントに 👀（`eyes`） | poll／317 L1 直後 |
| **対応した** | `【AIチーム】対応したよ` ＋何をしたか1〜5行 | コード／起票／設定を直した直後（`--done`） |
| **任意** | 元コメントに ✅（`white_check_mark`） | 対応したと同時 |

- 「受けた」だけで終わらせない（実装・起票が済んだら必ず「対応した」）
- 履歴はスレに残るので、あとから「ちゃんと対応してくれた」と確認できる
- helper: `build_ack_text` / `build_done_text` / `REACTION_SEEN`（`jarvis_slack_report_fb_lib.py`）
- Todoist 側の同コンセプト: `【AIチーム】見たよ（受けた）`（`build_todoist_seen_text`・317／Webhook）

### 毎日の FB 対応（Phase 2・2026-10-25）

Claude 定期タスク **`slack-fb-daily`**（毎晩 19:45 起動・Miss Lemon。松野さんが 20:00 以降に見るので、20:10 ごろまでにスレへ「対応したよ」を返す。`~/.claude/scheduled-tasks/slack-fb-daily/SKILL.md`）。314 の週次レビューとは別タスク。

```bash
~/selenium_env/venv/bin/python scripts/jarvis_slack_report_fb_poll.py --pending          # 未対応を JSON（スレ本文つき）
~/selenium_env/venv/bin/python scripts/jarvis_slack_report_fb_poll.py --done KEY --summary "…"  # 対応したよ＋✅＋state
```

| 中身 | 処置 |
|---|---|
| 見栄え・プログラム | 直して PR → `--done`（「PR #NNN・マージ後に効く」） |
| 質問 | コード・docs を調べて答えを `--done` で返す |
| 方針（もう送らない等） | 設定・コードで止めて PR → `--done` |
| 他 AI が既に直した | 確かめて `--done`（何をしたかを短く） |
| お金・対外送信・データ削除・リセット | 実行しない。Todoist（「ミスレモン」名乗り）に起票 → `--done`「起票した・松野さん判断待ち」 |

- 未対応 0 件なら記録 MD・PR は作らず終える（AI 使用量）。結果ページには 0 件の行だけ書く
- 結果ページ（2026-10-27〜）: 毎晩の件数・処置・PR を Claude の Artifact「Slack FB 対応ログ」（https://claude.ai/artifact/U1PcgMhx6RmPMNxL27xUXu）に1晩1行で残す。Slack を開かなくても、Claude のプロジェクトから結果が分かるようにするため。書き込みは `ArtifactData` で `runs/YYYY-MM-DD`（形は SKILL.md の手順7）
- スレへの「対応したよ」投稿は自動で可（2026-10-25 松野了承。この Slack は松野のみ閲覧）
- 記録: `300_品質・タスク運用管理室/317_コメント起動係/output/YYYYMMDD_FB対応.md`（git → Drive `★AIエージェントチーム` に同期。他エージェント・ペアエージェントもここを読む）
- 頻度: まず毎日。2週続けて 1日あたり 0〜1件になったら週次（土曜・314 の後）へ落とす。人が判断して cron を変える
