## 初回手順（admin Beginner）

1. [Todoist](https://todoist.com/) に **admin メール**で新規登録（旧 m19m は使わない）
2. Settings → Integrations → Developer → **API token** をコピー
3. `.env.jarvis_private` に追記（チャットに貼らない）:
   `TODOIST_API_TOKEN=...`
4. 保存後「保存した」と Jarvis へ一声
5. Jarvis が実行:

```bash
cd ~/git-repos && set -a && source .env.jarvis_private && set +a
~/selenium_env/venv/bin/python scripts/jarvis_todoist_api.py whoami
~/selenium_env/venv/bin/python scripts/jarvis_todoist_api.py bootstrap --write-config
~/selenium_env/venv/bin/python scripts/jarvis_todoist_api.py seed-nokori --dry-run
~/selenium_env/venv/bin/python scripts/jarvis_todoist_api.py seed-nokori --apply
```

6. アプリで Board レイアウトを確認し、歪みがあれば distortions JSON に追記

## 二重起票防止（タイトル／L-id 突合・2026-09-21）

**原則**: 同じ仕事を Jarvis とホーク（または部長）が別名で2つ作らない。疑わしいときは **新規 create せず、既存の更新・列移動・コメント追記**。

### 起票前チェック（必須・30秒）

1. **L-id**（例: `L-01` / `T-03`）がタイトルや説明にあれば、同レーンでその文字列を検索  
   → ヒットしたら **そのタスクを使う**（完了済みならコメントで再オープン要否を聞く）
2. **タイトルの核**（物件名＋号室／相手名＋用件／機能名）で同レーンを検索  
   → 似ていれば既存にコメント「同一件として扱う」＋必要なら列移動のみ
3. 見つからなければ create。タイトル先頭に既存の記号規約を維持（`[L-xx]` / `[apps]` 等）

### 役割ごとの約束

| 誰 | やる | やらない |
|---|---|---|
| **ホーク／部長**（inbox `todoist_tasks`） | create 前に同タイトル／L-id を意識。迷ったら `comment` または `owner_confirm` のみ | 毎週同じ文言で新規を量産 |
| **Jarvis**（会話中） | 話題の1件は既存を探してから create。ホーク起票済みなら列だけ直す | ホークと同趣旨の別タイトル新規 |
| **松野** | 二重に見えたらコメントで片方を正と宣言 | — |

### 見つかったときの処置

| 状況 | 処置 |
|---|---|
| 同 L-id・別タイトル | 片方に統合コメント → 不要側は完了（「二重のため閉じる」） |
| 同趣旨・L-id なし | 新しい方を閉じるか、古い方へリネームして一本化 |
| 本当に別件 | タイトルで差が分かるようにして両方残す |

自動化（タイトル類似度スコア等）は後続。当面は **運用＋検索** で足りる。
