# 設計書：買う製品の候補比較（シャワー起点）

- 業務：家電・消耗品・住宅設備の購入比較（価格・機能・互換性・維持費を比べて購入先を決め、採用・見送りの理由と購入後の感想を残す仕事です。）
- コンセプト：AI（またはシード）が候補を価格・機能・互換性・年間消耗品代で並べます。人が買う製品を1つ選ぶか、候補の情報を直すか、すべて見送ります。選んだ理由と見送った理由、購入後の満足・後悔をお題ごとに1件にまとめ、チャットのAIに渡して次の候補の絞り方を直します。
- アプリ：Jarvis ダッシュボード `/purchase-compare`（localStorage 保存＋MD／JSON エクスポート）。Supabase は MVP 外。

## ツールの中（AIの案を人が判断し、結果が残る）

- AIが出すもの：買いたい物・予算・必須機能を受け取り、2〜4製品を提案します。価格、機能、互換性、年間の消耗品代を同じ欄で並べ、価格の確認日と情報源、不明な点も示します。**最初はシャワーヘッド1件で試します。**
- 人が決めること：購入する製品を1つ選ぶか、候補を直すか、すべて見送ります。「本体が安い」「手入れが楽」「交換品が高い」などの理由は任意で付けます。
- お題：買い物の条件（最初はシャワー1件。1つのお題に結果は1件）
- 判断の操作：比べて選ぶ（S05。2〜4案を同じ大きさで並べて1つ選ぶ。「どれも違う」も置く。）
- 操作の流れ：条件付きで候補を並べる → 1製品を選ぶか情報を直す → どれも合わなければ全て見送り → 理由を任意で押す → 候補と判断が1件にまとまる → 購入後は追記
- 決め手の選択肢（共通）：本体が安い／手入れが楽／交換品が高い／互換性に不安／必須条件を満たす
- 決め手の選択肢（住宅設備追加）：工事不要で付けられる／接続規格が合う／一時止水が要る／塩素低減が欲しい／価格差に見合う差が不明
- 残る結果：買い物の条件／提示した候補と訂正／最終判断／選択理由／見送り理由／購入後の追記

### 最初に入れておく例（お題1：シャワーヘッド）

```text

```

### 業務の流れ

1. 【人】買い物の条件（お題）を開く／新規作成する。
2. 【提示】2〜4製品を同じ項目で並べる（MVPはシードまたは手編集。AI自動提案は後続）。
3. 【人】買う製品を決める：1製品を選ぶ／候補を直して選ぶ／すべて見送り。理由は任意。
4. 【人】結果を残す：お題ごとに1件保存。購入後の満足・後悔は追記。チャットAIへ渡すときはエクスポート。

## ツールの外（溜まった記録で案の作り方を直す）

- 記録が溜まる速さ：買い物のたびに1件、月に約1〜3件
- 選んだものの共通点（例）：接続・寸法が確認済み／消耗品代の前提が明確／工事不要
- 選ばなかったものの共通点（例）：本体は安いが交換品が高い／必須機能の有無が未確認／価格差に見合う差が不明

### 記録を使うタイミング

1. その場｜今回の修正に使う（恒常好みにはしない）
2. 〜10件｜参照例として渡す
3. 〜30件｜カテゴリ別に共通点を基準化（本人確認したものだけ）
4. 〜100件｜候補の確認順・点検手順を調整（ツール内候補の自動書き換えはしない）
5. 購入後評価｜決め手と使用後を照合して基準を改訂または取り消す

### 基準の例（シャワー／住宅設備）

- 必須機能・接続規格（G1/2 等）・アダプター要否を先に確かめ、不明なら「購入前に確認が必要」と明記する。
- 本体価格と年間消耗品代を分け、交換頻度・使用量・試算期間を添える。
- ヘッド単体交換かホース一体かを実機で確認し、フィルタ・パッキンの扱いを条件に残す。

### 効いているかの確かめ方

- 同じ予算・使用条件で、基準を直す前後の比較案を比べ、接続・寸法・消耗品の訂正が減ったかを見る。
- 購入後の満足・後悔が付いた結果だけを使い、購入時の決め手が使用後も満たされたかを確認する。

## 注意点

- 価格・仕様は確認日付き。実売・在庫・メーカー仕様は購入前に再確認する。
- 年間消耗品代は試算。不明な費用を0円とみなさない。
- 生の判断記録、チャットAIの解釈、本人が承認した基準を分ける。未記入の理由は推測で埋めない。
- 選ばなかった＝嫌い、ではない。今回だけの事情を次の買い物すべてに適用しない。

## 設計の原則

- 理由を毎回書かせない。自然な操作から対象・差分・結果を取り、価値が高い場面だけ追加で聞く。
- 「今回だけ」と「次も同じに」を分ける。
- 本人の理由と、AIが推測した理由を分けて保存する。
- 記録が増えたこと＝精度が上がった、と表示しない。
- 生ログ・AIの解釈・再利用ルールを別に持ち、解釈が誤っていても元の判断に戻れるようにする。

---

業務の元の説明：家電や消耗品を買うとき、候補を2〜4製品に絞って価格・機能・互換性・ランニングコストを比較し、どれにするか決めている。決めた理由と「見送った理由」、購入後の満足／後悔を残し、次に似た買い物をするときの提案精度を上げたい。最初の実案件はシャワーヘッド（TOTO→ReFa等）。
