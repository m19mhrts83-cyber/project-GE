Jarvis 個人自動化

個人用 Mac 上の業務支援スクリプト群（OAuth 同意画面用ホームページ）

機能概要

運営者本人の Gmail・Google Calendar へ OAuth 2.0 でアクセスし、次を行います。

  • パートナー・業務連絡メールの取り込みとやり取りログへの記録
  • 本人からのメール送信補助
  • Google カレンダーへの予定登録

本アプリは個人利用であり、不特定多数向けの公開 Web サービスではありません。

プライバシー

Google ユーザーデータの取扱いは プライバシーポリシー に記載しています。
