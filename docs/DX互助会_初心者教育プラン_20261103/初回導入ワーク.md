# 第01回：話して頼む・見て直す

更新：2026年11月4日。授業内7分の練習用。音声入力が使えなければ、手入力やコピーで進められます。

## 1. この説明メモをAIに渡します

```text
AIを使う仕事は、インプット・プロセス・アウトプットに分けて考えます。
インプットでは、目的と参考材料を渡します。
プロセスでは、小さく作って、結果を見て直します。
アウトプットでは、使う人と目的に合う形に整えます。
講師はCursorで原稿を整理し、NotebookLMで説明用スライドにしています。
```

## 2. 話して頼みます

「初心者向けAI講座の講師としてお願い。この説明メモを参考に、AI活用の流れを3つの見出しで短くまとめてください。」

送る前に、音声が正しく文字になったかを確認します。

- 誰として：初心者向けAI講座の講師。
- 何を参考に：上の説明メモ。
- 何をしてほしい：3つの見出しで短くまとめる。

## 3. 結果を読んで、1つ直してもらいます

例：「専門用語を減らして、各見出しに身近な例を1つずつ入れてください。」

自分が分かりにくいと思った箇所を選んで頼んでも構いません。

## 4. 次に使えるメモを残します

良かった説明と頼み方を、普段使っているメモへ残します。講師は次のようなMarkdownファイルで保存する例も見せます。

```markdown
# Role：誰として
初心者向けAI講座の講師

# Reference：何を参考に
授業で渡したAI活用の説明メモ

# Request：何をしてほしい
3つの見出しで短くまとめる。
専門用語を減らし、身近な例を1つずつ入れる。
```

もう一度使うときは、参考にする説明メモも一緒に渡します。
