# 神大家オプチャ — 添付ファイルをDB連携する場合の要件と概算（2026-10-22）

神大家さん倶楽部への相談・判断用メモ。現状と、メッセージに紐づけて添付を載せる場合に必要なこと・費用感。

## 現状

| 層 | テキスト | 画像・ファイル |
|---|---|---|
| LINE → MD | 差分取込あり | `[非テキスト contentType=N]` プレースホルダのみ（本体は保存しない） |
| MD → Supabase `line_openchat_logs` | 差分登録（2026-10-22〜） | **入っていない**（画像行は意図的にスキップ） |
| Storage（kamiooya-qa） | — | **0ファイル** |
| 個人パートナーLINE | — | Mac の `1.受信添付(Stock)/` へ保存する経路あり（オプチャとは別） |

つまり「文字だけ見たつもりでも転送が増えた」主因は添付ではなく、**意味検索用 embedding を毎回フル返却していたこと**。添付はまだ載せていない。

## メッセージと関連づけて添付を載せるために必要なこと

1. **取得** … CHRLINE（または公式エクスポート）で画像/動画/ファイルをダウンロード可能にする（オプチャは権限・E2EE・Square API の制約あり。要 PoC）
2. **保存先** … Supabase Storage（例: bucket `openchat-media`）または運営共有 Drive。DB にはメタだけ
3. **紐づけ** … `line_openchat_logs.id` に対する子表（例: `line_openchat_attachments`）  
   - `message_id` / `storage_path` / `content_type` / `bytes` / `sha256` / `original_name`
4. **公開境界** … 神大家向け Q&A に出すか、内部のみか。個人情報・物件写真の取り扱い方針
5. **検索UI** … Raimo／管理画面で本文横にサムネ or ダウンロード
6. **egress** … 閲覧のたびに転送が発生。CDN（cached egress）とサムネ縮小が必須

## 費用感（Supabase・現行2プロジェクト前提）

公式: [Pricing](https://supabase.com/pricing)

### A. 今のまま（テキスト＋embedding、添付なし）＋制限回避

| 項目 | 目安 |
|---|---|
| **Pro 組織** | **$25/月** |
| Compute（Micro×2本、クレジット$10） | **約 $35/月 合計**（$25 + $10 + $10 − $10） |
| 転送枠 | 未キャッシュ 250GB / キャッシュ 250GB（差分化後は通常この内に収まる想定） |
| DBディスク | プロジェクトあたり 8GB 込み |

→ **制限回避だけなら月おおよそ $35（約5,000円前後）** がベースライン。

### B. 添付を本格搭載する場合（追加）

Pro 込み Storage **100GB** まで追加課金なし（超過 **約 $0.021 / GB・月**）。

| 規模感（仮） | 保存 | 追加ストレージ課金 | 転送の注意 |
|---|---|---|---|
| 試験（月数百枚・合計数GB） | Pro の 100GB 内 | **$0** | フルサイズ直配信を避けサムネ＋CDN |
| 中（累計 50〜100GB） | 枠内〜ぎりぎり | **$0〜数ドル** | 同上 |
| 大（累計 500GB） | 超過約400GB | **約 $8〜9/月** | 転送超過は未キャッシュ **$0.09/GB** |

画像を「毎回一覧でフル解像度」すると、Storage より **egress の方が先に高くつく**。  
例: 平均 2MB の画像を月 1万回フル取得 → 約 20GB。Pro 枠内なら追加$0、枠超過分は従量。

### C. サービス拡充としての伝え方（運営向け一文）

> テキスト知見の DB 化は稼働済み。画像・PDF をメッセージに紐づけて検索・提示するには、(1) オプチャからの取得可否の技術確認、(2) Storage＋紐づけ表、(3) 公開範囲の合意が必要。インフラは現行 Free 超過対策として Pro（組織あたりおおよそ月 $35・2プロジェクト）が前提で、添付は Pro の 100GB 枠内ならストレージ追加はほぼゼロ。費用の本体は保存量より **閲覧時の転送設計**。

|---|---|---|
