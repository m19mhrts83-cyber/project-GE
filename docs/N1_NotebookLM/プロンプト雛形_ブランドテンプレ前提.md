# プロンプト雛形（ブランドテンプレ前提・ワンスライドワンメッセージ）

**用途**: NotebookLM／Cursor で構成を固め、Plus AI（または Canva／Copilot）に渡して **編集可能なオブジェクト型スライド**を生成する。  
**親ガイド**: [AI説明資料_後から直しやすい作り方.md](AI説明資料_後から直しやすい作り方.md)  
**スタイル（ゆるイラスト）**: [NotebookLM_マスタースタイル_cute-illustration.md](NotebookLM_マスタースタイル_cute-illustration.md)

---

## 使い方

1. **§1 アウトライン表**を埋める（ここが正本）
2. NotebookLM には §1 をソースまたはチャットで渡し、事実確認・言い回し磨きだけ行う（**画像デッキは必須ではない**）
3. Plus AI には **§2 生成プロンプト**＋§1 の表を貼る
4. イラストが必要なら **§3** で枠用画像だけ別生成し、PPT のプレースホルダに差し込む

---

## §1 アウトライン表（コピペ用）

Markdown のまま Plus AI／NotebookLM／Cursor に貼ってよい。

```markdown
# デッキ概要
- タイトル:
- 想定読者:
- 目的（この資料で相手にしてほしいこと）:
- トーン: 丁寧ビジネス / やさしい解説 / 提案
- 言語: 日本語
- 枚数目安:
- 禁止: 根拠のない数値、ロゴ改変、全面イラスト焼き付け

# スライド一覧（ワンスライド・ワンメッセージ）

| slide_id | 見出し（短く） | ワンメッセージ（1文） | 根拠・箇条書き（最大3） | ビジュアル指示（右枠など） | 出典メモ |
|----------|----------------|------------------------|-------------------------|----------------------------|----------|
| s1 | | | 1.  2.  3. | | |
| s2 | | | 1.  2.  3. | | |
| s3 | | | 1.  2.  3. | | |
```

### 記入ルール

- **見出し**: 12字前後まで。説明文にしない
- **ワンメッセージ**: そのスライドで伝えたいことを1文だけ
- **根拠**: 最大3点。4点以上は次のスライドへ分割
- **ビジュアル指示**: 「右枠に〜のイラスト」「比較の2箱」など。**文字を画像に埋め込まない**旨を書く
- **出典メモ**: NotebookLM ソース名やページ。数字はここから転記

## §2 Plus AI／PowerPoint 向け生成プロンプト

ブランドマスターを開いた状態で、次をそのまま使う（`【】` を埋める）。

```
あなたは社外提出用のスライド編集者です。今開いている PowerPoint の
マスター／レイアウト／フォント／ロゴを崩さず、編集可能なテキストボックスと図形だけで
プレゼンを作ってください。

【制約】
- 言語: 日本語のみ
- 原則: ワンスライド・ワンメッセージ
- 各スライドは「見出し＋短い本文（または箇条書き最大3）＋必要なら図形」
- スライド全体を1枚の画像として描画しない
- イラストや写真は「画像プレースホルダ／右（または左）1/3の枠」に置く前提。文字は画像に焼き付けない
- 数値・固有名詞は下記アウトライン以外を創作しない。不明なら「（要確認）」と書く
- 装飾より可読性。余白を確保

【デッキ概要】
（§1のデッキ概要を貼る）

【スライド一覧】
（§1の表を貼る）

【出力】
上記の slide_id 順にスライドを生成してください。
```

### 1枚だけ直すとき（Remix／追記）

```
slide_id【s○】だけ修正してください。他のスライドは変えないでください。
変更内容: 【誤字修正／文言を次のように／箇条書きを2点に削減】
新しいワンメッセージ: 【…】
テキストは編集可能なテキストボックスのままにしてください（画像化しない）。
```

### Copilot 利用時の追加一文

```
生成結果は Insert で画像貼り付けせず、テキストとして出力してください。
私がスライドのテキストボックスに貼ります。
```

## §3 イラスト枠だけ生成するプロンプト（任意）

NotebookLM Studio／Gemini／画像生成向け。**文字なし・枠用**。

```
【用途】PowerPoint の右1/3に置く挿絵だけ。スライド全体は描かない。
【スタイル】（cute-illustration を使う場合）白背景、水彩風ゆるイラスト、細いペン線、2〜3頭身。
詳細はマスタースタイルに従う。
【内容】【ビジュアル指示の一文】
【禁止】画像内に文字・ロゴ・数値を入れない。余白はシンプルに。
【出力】透過または白背景の1枚イラスト。
```

生成後: PPT の画像プレースホルダを選択 → 画像の変更。

## §4 NotebookLM 用（構成だけ磨く）

画像デッキを出さず、構成の品質だけ上げるときの指示。

```
登録ソースだけを根拠に、ワンスライド・ワンメッセージのアウトライン表を Markdown で作ってください。
各行に slide_id / 見出し / ワンメッセージ / 根拠最大3 / ビジュアル指示 / 出典メモ。
数値はソースにないものを作らない。
スライド画像の生成は不要です。表だけ出力してください。
```

トーンを cute に寄せる場合は、続けて:

```
ビジュアル指示は「ゆるイラスト・白背景・文字なし挿絵」前提で書いてください。
マスタースタイル（cute-illustration）に合わせる。
```

## §5 Canva／Gamma 向け（オブジェクト編集が主戦場のとき）

Canva 内で直す前提なら:

```
日本語。ワンスライド・ワンメッセージ。
各ページはテキストレイヤーと図形を分けて編集できるようにする。
背景と本文を1枚の画像にまとめない。
ブランドカラー: 【…】 フォント: 【…】
以下のアウトライン表に従う:
（§1を貼る）
```

Gamma で作って PPTX 書き出す場合は、**書き出し後に整形時間がかかる**前提で、客先提出の正本は Plus AI 側を優先する。

## §6 校正プロンプト（生成後・テキストだけ）

PPT からテキストを書き出して Cursor／ChatGPT に渡すとき。

```
以下は提出前スライドのテキスト抽出です。
- 誤字脱字
- 表記ゆれ（です・ます統一）
- 1スライドにメッセージが複数ある箇所
だけ指摘し、修正後の文言を表で返してください。
内容の意味は変えないでください。新しい事実を足さないでください。

（テキストを貼る）
```

指摘を受けたら **PowerPoint 上で直接修正**する（画像再生成に戻さない）。
