# いけともゆるキャラプロンプト（cute-illustration）

**用途**: NotebookLM のソース追加・チャット冒頭・Studio（Nano Banana Pro）で、スライド・図解の見た目を揃える。

- **正本（Cursor コマンド）**: `~/git-repos/.cursor/commands/cute-illustration.md`
- **詳細版（NotebookLM 用）**: [NotebookLM_マスタースタイル_cute-illustration.md](NotebookLM_マスタースタイル_cute-illustration.md)
- **運用メモ**: [運用まとめ_会話からの記録.md](運用まとめ_会話からの記録.md) §3.5

---

## 目的

初心者向けに優しく説明する資料用の「ゆるいイラスト」スタイル。

---

## スタイル指定

- 日本のビジネス書・解説本でよく使われる「ゆるいイラスト」スタイル
- **線**: 黒の細いペン線、手描き感のあるやや不均一な線（デジタルだが手描き風）
- **塗り**: 水彩風の淡い色（クリーム、薄い青、薄いオレンジ、薄い緑）、べた塗りではなくムラのある塗り
- **人物**: 2〜3頭身のデフォルメキャラ、丸い顔、シンプルな表情（点の目、線の口）
- **アイコン・オブジェクト**: シンプルな線画＋淡い色、影なし、フラット

## 色彩

- **背景**: 白（`#FFFFFF`）
- **メインカラー**: 黒（線）、薄いオレンジ/黄色（強調・見出し背景）
- **アクセント**: 薄い青、薄い緑、薄いピンク
- **強調**: 赤（×マーク、重要ポイント）、緑（✓マーク、OK）

## レイアウト

- グリッド状に情報を配置（1〜4列）
- 各セルに「イラスト＋短いテキスト」のセット
- 見出しは黄色/オレンジの帯やマーカー風の背景
- 矢印は手描き風、曲線的

## 人物表現

- **頭身**: 2〜3頭身
- **髪**: シンプルな塊で表現
- **服**: 青、グレーなど落ち着いた色のシンプルな服
- **表情**: ◯と線だけで表現（困った顔、笑顔、考え中など）
- **ポーズ**: 説明的なジェスチャー（指さし、腕組み、PC操作など）

## テキスト

- **フォント**: 丸ゴシック風、手書き風
- **サイズ**: 大きめ、読みやすさ重視
- **配置**: イラストの横または下に短いキャプション
- **強調**: 黄色マーカー風のハイライト、太字

## 避けるべき要素

- リアルな人物描写
- グラデーション
- ドロップシャドウ
- 複雑な背景
- 3D表現

---

## NotebookLM での使い方（短いチェックリスト）

1. ノートに **話の土台となる MD** を入れる。
2. **このファイル（または `NotebookLM_マスタースタイル_cute-illustration.md`）をソースとして追加**する。
3. **チャットの最初**で下記「コピペ用プロンプト」を貼り、「登録済みマスタースタイルに従うこと」「Studio で出す**すべてのスライド画像**も同一スタイル」と宣言する。
4. **Studio** で **Nano Banana Pro**（利用可能なら）を選び、スライド／ビジュアルを生成する。
5. ブレたら **白背景・水彩風ゆるイラスト・丸ゴシック**であることを一言で指摘して再生成する。

---

## コピペ用プロンプト（チャット・Studio 共通）

以下を **そのまま** NotebookLM のチャットや Studio の指示にコピーしてよい。

```
【スライド・図解の統一スタイル（全枚で厳守）】
目的: 日本のビジネス書・解説本の「ゆるいイラスト」で、初心者向けに優しく説明する。

線: 黒の細いペン線。デジタルだが手描き感があり、やや不均一な線。
塗り: 水彩風の淡い色（クリーム、薄い青、薄いオレンジ、薄い緑）。べた塗りではなくムラのある塗り。グラデーションは使わない。
背景: 白 #FFFFFF。複雑な背景パターンは入れない。
人物: 2〜3頭身のデフォルメ。丸い顔。目は点、口は線などシンプルな表情。髪はシンプルな塊。服は青・グレーなど落ち着いた色。ポーズは指さし・腕組み・PC操作など説明的なジェスチャー。
アイコン・物体: シンプルな線画＋淡い色。影なし。フラット。
レイアウト: 1〜4列のグリッド。各セルは「イラスト＋短いキャプション」。見出しは薄いオレンジや黄色の帯、またはマーカー風の背景。
矢印: 手描き風で曲線的。
テキスト: 丸ゴシック風で大きめ。画像内の長文は避け、短い見出しと箇条書き程度。強調は黄色マーカー風のハイライトと太字。
強調記号: 重要・注意は赤（×）、OK・正解は緑（✓）。

禁止: リアルな人物写真風、グラデーション、ドロップシャドウ、複雑な背景、3D表現。

出力は上記に合わせたスライド1枚分（または指定の図）として。モデルは Nano Banana Pro を使う前提。
```

## Studio 用の短い追い文（例）

```
先に合意したマスタースタイル（白背景・水彩風ゆるイラスト・丸ゴシック）を守って。このスライドだけ生成してください：slide_id ○○。画像内テキストは最小限。
```

（`slide_id ○○` を `s1` 等に置き換える。）
