# Plus AI 導入手順（編集可能な PowerPoint／Google スライド）

**目的**: 客先提出用スライドを、最初からテキスト箱・図形として編集できる形で生成する。  
**親ガイド**: [AI説明資料_後から直しやすい作り方.md](AI説明資料_後から直しやすい作り方.md)  
**プロンプト**: [プロンプト雛形_ブランドテンプレ前提.md](プロンプト雛形_ブランドテンプレ前提.md)

公式: [https://plusai.com/](https://plusai.com/)

---

## 1. 向いている／向いていない

| 向いている | 向いていない |
|------------|--------------|
| `.pptx` を客先に渡す・共同編集する | ゆるイラスト一体型の「画像1枚」見た目を最優先したい |
| 誤字・数値をあとから自前で直したい | リンク共有だけで足りる（その場合は Gamma 等でも可） |
| 会社のマスター／ブランドテンプレがある | デザイン自由度だけを最大化したい |

## 3. PowerPoint へのインストール（Mac）

1. Microsoft PowerPoint を最新に更新する
2. PowerPoint を開き、**挿入** → **アドインを取得**（または **Get Add-ins**）
3. 「**Plus AI**」を検索 → **追加**
4. リボンに **Plus AI** タブが出ることを確認
5. Plus AI タブからサインイン（ブラウザで plus.ai 認証が開く場合あり）

うまく出ないとき:

- PowerPoint を再起動
- Microsoft アカウントでアドインストアにサインインしているか確認
- 組織ポリシーでアドインが禁止されていないか確認

---

## 4. Google スライドへのインストール

1. Google スライドで任意のプレゼンを開く
2. **拡張機能** → **アドオン** → **アドオンを取得**
3. 「Plus AI」を検索 → インストール
4. **拡張機能** → Plus AI → 起動 → サインイン

## 5. ブランドテンプレの用意（初回だけ）

編集性と見た目の両立の鍵は **マスター側**にある。

1. 既存の会社／案件用 `.pptx` をコピーして「AI用マスター」にする
2. スライドマスターで次を固定する:
   - ロゴ位置、フォント、ブランドカラー
   - レイアウト例: タイトルのみ／タイトル＋本文／タイトル＋本文＋右イラスト枠
3. **右（または左）1/3 に「イラスト用」の画像プレースホルダ**を置く（全面背景に焼き付けない）
4. Plus AI のテンプレート／ブランド設定（Pro 以上でカスタムテンプレ対応。プランはサイト確認）にマスターを登録するか、**そのファイルを開いた状態で生成**する

チェック:

- [ ] ロゴが全スライドで同じ位置
- [ ] 見出し・本文のフォントが統一
- [ ] イラスト枠が「差し替え可能な画像」である

## 6. 日常の生成フロー（推奨）

```text
NotebookLM / Cursor
  → 1枚1メッセージのアウトライン（表または Markdown）
  → Plus AI（マスターPPTを開いた状態）でデッキ生成
  → PowerPoint で誤字・数値・言い回しを直接修正
  → イラスト枠だけ差し替え（任意）
  → 客先提出
```

### 6.1 アウトラインを渡す

1. [プロンプト雛形](プロンプト雛形_ブランドテンプレ前提.md) の「アウトライン表」を埋める
2. Plus AI の「New presentation / Generate」に貼る（または PDF／Word／テキストをアップロード）
3. **モードは必ず「Slides」（Fully editable）**。`Images` は見た目重視で **全面画像になりやすく、編集性検証で失敗する**（2026-07-27 確認）
4. **スライド枚数・言語（日本語）・トーン**を明示する

> **検証メモ**: Web の `Images` → Export は各スライドが全面 JPEG。`Slides` → Download .pptx は Title／本文がテキスト箱。PowerPoint アドインでも同様に Slides 側を選ぶ。
>
> **ゆるキャラ／cute-illustration との両立（2026-07-27）**: Slides に水彩・ゆるキャラ指示を書いてもテンプレ優位で NotebookLM トーンにはほぼならない。Images（Friendly Illustrated 等）はイラスト寄りだが全面画像。いけとも向けは「見た目＝NotebookLM／直し＝Plus Slides（イラストは枠差し込み）」のハイブリッドが現実解。詳細: `200_NoteBookLM/99_PlusAI検証_20260727/05_ゆるキャラテイスト検証/`

### 6.2 生成後の必須確認（客先提出前）

| 確認 | やり方 |
|------|--------|
| テキストが本物の箱か | 見出しをクリックしてカーソルが出るか（画像なら出ない） |
| 数値・固有名詞 | ソースと突き合わせ（AI 暗記に頼らない） |
| ロゴ・余白 | マスター崩れがないか1枚ずつ |
| Copilot 併用時 | Insert で画像になっていないか |

### 6.3 修正の原則

- **誤字1文字・言い回し** → PowerPoint で直接直す（AI に戻さない）
- **構成のやり直し（枚数・順序）** → Plus AI の Remix／再生成、またはアウトライン更新後に再生成
- **イラストだけ変えたい** → プレースホルダ画像だけ差し替え（全文再生成しない）

## 7. Copilot を使う場合の注意

Microsoft Copilot は便利だが、**Insert すると画像オブジェクトになる**報告がある。

| やり方 | 編集性 |
|--------|--------|
| Copilot ペインから **テキストをコピー → スライドのテキスト箱に貼る** | 高い（推奨） |
| Copilot の **Insert** だけで載せる | 低い（画像の可能性） |

Plus AI が使えるなら、客先提出の本線は **Plus AI** に寄せる。

---

## 8. トラブルシュート

| 症状 | 対処 |
|------|------|
| アドインが出ない | PPT 再起動、アドインストアのサインイン、組織制限 |
| 生成が英語 | プロンプト先頭に「すべて日本語で」 |
| レイアウトが崩れる | マスターのレイアウト種類を減らす／1メッセージ1スライドを徹底 |
| 見た目が NotebookLM より弱い | イラストは別生成して枠に入れる。全面画像化はしない |
| 機密を上げたくない | ローカルマスター＋最小限のプロンプト。必要なら社内 Copilot のみ |

## 9. 実験チェックリスト（導入直後）

同じ原稿で次を比較する（親ガイド §5）。

1. NotebookLM 画像デッキで誤字修正にかかる時間
2. Plus AI ネイティブデッキで誤字修正にかかる時間

**誤字修正が明らかに短ければ導入成功。** 見た目だけ NotebookLM が勝つ場合は、系統B（変換）を併用する。
