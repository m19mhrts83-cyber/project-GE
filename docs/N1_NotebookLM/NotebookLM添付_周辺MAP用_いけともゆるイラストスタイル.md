# NotebookLM添付用 — いけともゆるイラストスタイル（cute-illustration）

**用途**: 周辺MAP運営説明など、NotebookLM でスライド／図解を作るときに **このファイルをソースとして追加**し、Studio（Nano Banana Pro）の見た目を揃える。

- **由来**: いけともさん提供の「ゆるいイラスト」スタイル（Cursor コマンド `cute-illustration`）
- **Cursor 正本**: `~/git-repos/.cursor/commands/cute-illustration.md`
- **詳細版（N1）**: `docs/N1_NotebookLM/NotebookLM_マスタースタイル_cute-illustration.md`  
  ／ `いけともゆるキャラプロンプト.md`
- **対象資料の土台**: `運営説明_周辺MAP_構成案.md`（同じノートに一緒に添付）

---

## NotebookLM での進め方

1. ノートに **`運営説明_周辺MAP_構成案.md`** をソース追加する。
2. **このファイル**をソースとして追加する。インデックス完了を待つ。
3. **チャットの最初**で、下の「開始宣言」を貼る。
4. 構成案末尾の NotebookLM 投入用プロンプトでスライド原稿を整える。
5. **Studio** で **Nano Banana Pro** を選び、全スライド画像を生成する（このスタイルに従わせる）。

### 開始宣言（チャット冒頭にコピペ）

```
登録済みソースのマスタースタイル（いけともゆるイラスト／cute-illustration）に従うこと。
Studio で生成するすべてのスライド画像も、同一スタイル（白背景・水彩風ゆるイラスト・丸ゴシック）にすること。
周辺MAP運営説明のスライドは、構成案の見出し順を維持すること。
```

## スタイル指定（いけとも／cute-illustration）

### 目的

初心者向けに優しく説明する資料。

### スタイル

- 日本のビジネス書・解説本でよく使われる「ゆるいイラスト」スタイル
- **線**: 黒の細いペン線、手描き感のあるやや不均一な線（デジタルだが手描き風）
- **塗り**: 水彩風の淡い色（クリーム、薄い青、薄いオレンジ、薄い緑）、べた塗りではなくムラのある塗り
- **人物**: 2〜3頭身のデフォルメキャラ、丸い顔、シンプルな表情（点の目、線の口）
- **アイコン・オブジェクト**: シンプルな線画＋淡い色、影なし、フラット

### 色彩

- **背景**: 白（`#FFFFFF`）
- **メインカラー**: 黒（線）、薄いオレンジ/黄色（強調・見出し背景）
- **アクセント**: 薄い青、薄い緑、薄いピンク
- **強調**: 赤（×マーク、重要ポイント）、緑（✓マーク、OK）

### レイアウト

- グリッド状に情報を配置（1〜4列）
- 各セルに「イラスト＋短いテキスト」のセット
- 見出しは黄色/オレンジの帯やマーカー風の背景
- 矢印は手描き風、曲線的

### 人物表現

- **頭身**: 2〜3頭身
- **髪**: シンプルな塊
- **服**: 青、グレーなど落ち着いた色のシンプルな服
- **表情**: ◯と線だけ（困った顔、笑顔、考え中など）
- **ポーズ**: 指さし、腕組み、PC操作など説明的なジェスチャー

### テキスト

- **フォント**: 丸ゴシック風、手書き風
- **サイズ**: 大きめ、読みやすさ重視
- **配置**: イラストの横または下に短いキャプション
- **強調**: 黄色マーカー風のハイライト、太字

### 避けるべき要素

- リアルな人物描写
- グラデーション
- ドロップシャドウ
- 複雑な背景
- 3D表現

## コピペ用プロンプト（チャット・Studio 共通）

以下を **そのまま** NotebookLM のチャットや Studio の指示にコピーしてよい。

```
【スライド・図解の統一スタイル（全枚で厳守）】
目的: 日本のビジネス書・解説本の「ゆるいイラスト」で、初心者向けに優しく説明する。
（いけともさん提供スタイル／cute-illustration）

線: 黒の細いペン線。デジタルだが手描き感があり、やや不均一な線。
塗り: 水彩風の淡い色（クリーム、薄い青、薄いオレンジ、薄い緑）。べた塗りではなくムラのある塗り。グラデーションは使わない。
背景: 白 #FFFFFF。複雑な背景パターンは入れない。
人物: 2〜3頭身のデフォルメ。丸い顔。目は点、口は線などシンプルな表情。髪はシンプルな塊。服は青・グレーなど落ち着いた色。ポーズは指さし・腕組み・PC操作など説明的なジェスチャー。
アイコン・物体: シンプルな線画＋淡い色。影なし。フラット。
レイアウト: 1〜4列のグリッド。各セルは「イラスト＋短いキャプション」。見出しは薄いオレンジや黄色の帯、またはマーカー風の背景。
矢印: 手描き風で曲線的。
テキスト: 丸ゴシック風で大きめ。画像内の長文は避け、短い見出しと箇条書き程度。強調は黄色マーカー風のハイライトと太字。
強調記号: 重要・注意は赤（×）、OK・正解は緑（✓）。

禁止: リアルな人物写真風、グラデーション、ドロップシャドウ、複雑な背景、3D表現。

出力は上記に合わせたスライド1枚分（または指定の図）として。モデルは Nano Banana Pro を使う前提。
```

## Studio 用の短い追い文（例）

```
先に合意したマスタースタイル（白背景・水彩風ゆるイラスト・丸ゴシック／いけとも）を守って。このスライドだけ生成してください：slide_id ○○。画像内テキストは最小限。
```

（`slide_id ○○` を構成案の `s1` / `s2b` 等に置き換える。）
