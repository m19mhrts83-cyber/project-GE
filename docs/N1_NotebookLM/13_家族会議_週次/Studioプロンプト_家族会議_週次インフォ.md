# 家族会議・週次インフォグラフィック Studioプロンプト

## 宣言（厳守）

登録済みマスタースタイル（いけともゆるキャラ／`NotebookLM_マスタースタイル_cute-illustration.md`）に従うこと。
Studio で生成する画像も同一スタイルを厳守すること。
モデルは **Nano Banana Pro** を使用すること。

## 参照ソース（最重要・これ以外使わない）

インフォグラフィックの内容の根拠は、次の **2つだけ**:

1. **イラスト指定**＝マスタースタイル（いけともゆるキャラ）
2. **今回の議事録**＝当該週の `YYYYMMDD_家族会議_Genspark議事録.md`（この生成依頼で指定された最新分）

ノート内に過去週の議事録や他資料があっても **読まない・混ぜない・要約に使わない**。他週の決定・宿題を書いてはならない。

【スタイル】
- 背景: 白 #FFFFFF
- 線: 黒の細いペン線（手描き風）
- 塗り: 水彩風の淡色（クリーム・薄い青・薄いオレンジ・薄い緑）。グラデなし
- 人物: 2〜3頭身のゆるキャラ（丸顔・点目）。必要なら家族5人まで
- テキスト: 丸ゴシック風・大きめ。画像内の長文は禁止
- 禁止: リアル人物・グラデ・ドロップシャドウ・3D・ダーク霓虹UI

---

## 成果物

**1枚のインフォグラフィック**（当該週の家族会議の振り返り用）。

含める（**当該週議事録のみ**から抽出）:

1. **見出し**: `家族会議 YYYY-MM-DD`（日付は当該週議事録に合わせる）
2. **決定事項**（最大5つ・短い箇条）
3. **宿題・アクション**（誰が・何を・期日があれば）
4. **子ども別1行**（円香／珠己／紗和。該当がなければ省略可）
5. **数値・ルール**（視聴時間・チケット・勉強時間など、言及があれば）

レイアウト目安: 上にタイトル、中央に決定と宿題の2カラム、下に子ども別または数値の帯。余白多め・詰め込みすぎない。

議事録に無い事実は作らない。話者名の Speaker N は「父」「母」など文脈が分かる範囲で言い換えてよい。
