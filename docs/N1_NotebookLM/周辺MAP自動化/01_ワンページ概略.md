## 30秒で分かる話

物件名と住所を入れると、**洗い出し→実在寄り検証→地図ピン→ベージュ色付き下地（C0）**まで自動。  
**C1**は「もっとイラスト寄りに寄せる」任意ボタン。印刷の Access／吹き出しは **Canva**（人手）。  
**Google Workspace Studio**は社内のメール・Drive連携向きで、この地図パイプラインの本線にはしない。

---

## C0 と C1 の差

| | **C0（本線・毎回自動）** | **C1（任意・人が合否）** |
|---|---|---|
| 何か | クリーン地図に **ベージュ紙面ウォッシュ** | Gemini 画像編集で **さらにイラスト寄り色味** |
| 手段 | PIL（彩度下げ＋クリーム紙色＋軽いスムース） | 画像生成モデル（例: gemini-2.5-flash-image） |
| 道路・位置 | **ほぼ無傷**（描き直ししない） | 崩れることがある → **破棄可** |
| いつ完了？ | C0まで出れば検証のゴール達成 | 押さなくてもOK。気に入ったら採用して差し替え |
| 画面 | 「色付き下地を保存」 | 「色味をさらに寄せる」→プレビュー→採用／破棄 |

たとえ: **C0＝写真を紙のチラシ色に寄せるフィルター**／**C1＝画家に「もっとガイドマップ風にして」と頼む（当たり外れあり）**。

---

## Workspace Studio と単独Webの役割分担

| | Workspace Studio | 単独Web（`shuhen-auto`） |
|---|---|---|
| 何か | Workspace内のフロー／エージェント | 物件入力〜地図〜C0の専用アプリ |
| 向くこと | Gmail・Drive・Chatの通知・承認のつなぎ | Gemini連鎖＋Maps＋色付き下地 |
| 向かないこと | 地図スクショ連鎖・Places確定の本線 | 社内メール自動化の置き換え |
| 外部公開 | 組織内でフローのコピー共有が主 | 検証はローカルAPI＋（将来）共有URL |
| 今回の本線 | **使わない**（通知の後付け候補のみ） | **本線** |

「個人の Gemini チャットが裏で連鎖」ではなく、**運営の Gemini API＋サーバ**が順番に実行する。

## 自動で完結する流れ（メンバー／自分＋Jarvis）

1. 入力: 物件名／住所／ターゲット（任意）／施設数目安（任意）
2. 洗い出し（施設候補・エリア一言）
3. 検証（最大8件に絞る）
4. Maps Places で座標確定
5. 番号ピン地図表示＋「周辺施設にはこういうものがあります」
6. Static Maps → **C0色付き下地**ダウンロード
7. （任意）C1 → 人が採用／破棄
8. （スコープ外）Canvaで印刷仕上げ
