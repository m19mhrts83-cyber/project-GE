---

## 第1ターン — 企画ヒアリング

診断や長文生成に入る前に、次を聞き取る（分かる範囲でOK。同メッセージに既にあれば要約して不足だけ聞く）。

**1. 種別** — 乾杯音頭 / 開会 / 閉会 / 祝辞 / 自己紹介 / その他  
**2. いつ・どこ・会名**  
**3. 話し手** — 名前・立場（幹事等）・会員番号を言うか  
**4. 聴衆** — 誰向けか／先生・ゲストの有無  
**5. 尺** — 未指定なら乾杯は **45〜90秒（約180〜350字）**  
**6. 入れたい事実・避けたいこと**

神大家の懇親会・幹事なら、可能なら次も読む（止まらず）:

- `…/215_神・大家さん倶楽部/C1_cursor/1d_神大家手続き自動化/懇親会開催申請_入力記録.yaml`
- 必要なら申込書アーカイブ・幹事LINE

締め: 「上の番号で分かるところから教えてください。音声のままでも大丈夫です。」

すでに十分な文脈がある（例: 会名・日時・幹事が分かっている）場合は、質問リストを省略せず短く出したうえで、**すぐ【企画】案を提示**してよい。

## 第2ターン以降 — 企画→生成→編集

### 1. 企画（必須）

チャットに出してから生成する:

```
【企画】
- 目的:
- 読者（聴衆）:
- 構成:
- トーン:
- 尺・文字数目安:
```

**乾杯（幹事）の標準構成**（種別が乾杯のとき）:

1. 名乗り  
2. 歓迎・お礼  
3. 趣旨1フレーズ  
4. 配慮1行（初心者・お酒飲めない方など。説教にしない）  
5. ゲスト／先生がいれば一言  
6. 「乾杯！」

### 2. 生成

- 事実はユーザー／YAML等にあるものだけ（捏造しない）
- **案は2〜3本**（標準／ややフォーマル／ややカジュアル）
- AI臭さ予防: 類語併記禁止・接続詞最小・断定回避を避け言い切る・メタ前置き禁止
- 乾杯の締めは「お酒で」だけにせず、ソフトドリンク可の言い方を既定に

### 3. 編集・出力

```
【企画メモ】（4行以内）

【案A｜標準｜約N秒／約N字】
（本文）

【案B｜…】
（本文）

【当日メモ】
- 音読のコツ1行
- 確認してほしい事実
```

固有名詞・日付・会場名・先生の参加有無は人間確認。音読を促す。

依頼があれば OneDrive `01_運営サポート/飲み会幹事/` 等へ MD 保存してよい。

## 制約

- 「スピーチ書いて」だけで無難な一般論を出して終わらない（企画を先に）
- 乾杯を3分超の講演にしない（長尺指定時以外）
- 秘密（電話・住所・パスワード）を原稿に入れない
