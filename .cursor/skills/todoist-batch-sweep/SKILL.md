# Todoist 掃除・並列バッチ

## 目的

タスク数が多いとき、**松野の判断リソースをクリティカルだけに集中**する。  
実行は並列可。確認はまとめる。**確認だけで閉じられるもの**は Jarvis が `complete-task` まで進めてよい。

## 依頼テンプレ（ユーザー）

```
【Todoist掃除・並列モード】
対象: apps / ai_raimo の quick・表確認・要Jarvis連携
件数: 最大5
やり方: 別処理で並列可。対外送信・振込・解約は除外
止め位置: オーナー確認まで（ただし確認のみはJarvis完了可）
報告: 最後に一覧1ブロックだけ
```

## 分類（処置後）

| ラベル | 意味 | 完了権限 |
|---|---|---|
| **確認のみ** | 事実確認・画面照合・状態resume・既定どおりの確認結果。方針選択なし | **Jarvis が close 可**（オーナー確認列を経由してすぐ `complete-task`） |
| **要オーナー判断** | 方針・金額・対外・解約・HOLD・検討・曖昧・自信なし | オーナー確認に残す。チャットで短く聞く |
| **除外** | 対外送信・振込・解約・課金変更 | バッチに入れない |

### 確認のみの例

- `[表確認]` / UI確認で「一致／不一致」1行が出せた
- 画面に件数があるか等の yes/no 確認だけ
- launchd resume 等、観測可能な復旧で宿題が消える
- 既に正本 state で完了済みと分かるフォローのクローズ（再生成リスクをコメントに明記）

### 要オーナー判断の例

- 「検討する」「どうする？」
- 資金移動・返済・カード退会・年額切替
- 対外メール／LINE 送信
- 実装方針が複数ある／失敗リスクが高い

## コメント（必須・省略不可）

バッチでも単件でも、やったことは **Todoist コメント**に残す（チャット／Slack は要約）。  
形式は `jarvis-todoist-owner-confirm.mdc` と同型（サマリ＋アウトプット）。コメント無しの close 禁止。
**1行目先頭に `【Jarvis】` を必ず付ける**（FRIDAY は `【FRIDAY】`・ホークは `【ホーク】`／共通トークンのため編集ツール識別用）。

## 手順

1. 対象ラベル／レーンから最大 N 件を選ぶ（簡単・Jarvis可優先）
2. 並列可ならレーンを分けて処置（対外・金は触らない）
3. 各タスクにコメント（サマリ＋アウトプットリンク）— **必須**
4. **確認のみ** → `オーナー確認` 経由で即 `complete-task`（定型コメント必須）
5. **要判断** → `オーナー確認` に残し、聞きたいことをコメント＋報告ブロック
6. チャット報告は **最後に1ブロック**（途中の都度確認はしない）

### complete-task コメント（確認のみ）

```
【Jarvis】タスク完了したよ（確認のみクローズ）
サマリ: …
アウトプット:
- […](https://…)
```

### 報告フォーマット

```
📎 Todoist掃除バッチ（YYYY-MM-DD）
【Jarvis完了・確認のみ】
- [lane] タイトル — id=… — 1行結果
【オーナー判断待ち】
- [lane] タイトル — id=… — 聞きたいこと1行
【次】
- 続けてバッチする／止める
```

## やらないこと

- 要判断を黙って close
- 対外送信・金・削除をバッチに混ぜる
- 1件ごとにチャットで「いいですか？」を聞く（バッチ報告にまとめる）
