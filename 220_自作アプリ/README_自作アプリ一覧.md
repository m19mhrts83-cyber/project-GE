# 📱 220_自作アプリ クイックアクセス

左側エクスプローラーからいつでも開ける自作アプリの入口です。

---

## 1. 🚀 Jarvis ダッシュボード（自分用HQ）
👉 **[Jarvis ダッシュボードを開く（クリック）](https://jarvis-dashboard-amber.vercel.app/)**
- **URL**: `https://jarvis-dashboard-amber.vercel.app/`
- **機能**:
  - パートナーやり取り・トリアージ確認
  - 状況ウォッチ（カード年会費、ETC、Vポイント等）
  - お金管理・Zaim Watch
  - レーン別タスク管理・処置ログ
- **同フォルダ内のショートカット**:
  - `01_Jarvisダッシュボード.html`（ブラウザで自動遷移）
  - `01_Jarvisダッシュボード.webloc`（Mac標準ショートカット）

---

## 2. 🏢 KURASHIFT（クラシフト / ライフプラン・不動産HQ）
👉 **[KURASHIFT（ホーム）を開く（クリック）](https://jarvis-trade-desk.vercel.app/)**
- **URL**: `https://jarvis-trade-desk.vercel.app/`
- **主要画面**:
  - **[千三つ 物件Deals（問合せ準備・一覧）](https://jarvis-trade-desk.vercel.app/realestate/deals)**
  - **[Tier2 一括確認・問合せ（日次上限5件）](https://jarvis-trade-desk.vercel.app/realestate/deals/tier2)**
  - **[資金・収支オペレーション（/money-ops）](https://jarvis-trade-desk.vercel.app/money-ops)**
  - **[ライフプラン・事業計画（/mq）](https://jarvis-trade-desk.vercel.app/mq)**
- **同フォルダ内のショートカット**:
  - `02_KURASHIFT(クラシフト).html`（ブラウザで自動遷移）
  - `02_KURASHIFT.webloc`（Mac標準ショートカット）
