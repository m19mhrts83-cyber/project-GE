# セミナー動画の文字起こし手順（運営向け）

Q&Aチャットボットにセミナー動画の内容を検索できるようにするため、動画の文字起こしデータをいただきたいです。
文字起こしには **Notta** というAIツールを使います。

---

## Notta とは

- 動画ファイルをアップロードするだけで、AIが自動で文字起こしをしてくれるサービスです
- **動画を再生する必要はありません**（ファイルを置くだけでOK）
- 1時間の動画でも約5分で完了します
- 対応形式: MP4, MOV, AVI, WMV 等（一般的な動画形式はほぼ対応）

## 無料枠の制限（重要）

| プラン | 1回あたり | 月間上限 |
|--------|-----------|----------|
| **無料** | **3分まで** | 120分 |
| **Business（有料）** | 5時間まで | 月2,200円〜 |

セミナー動画（30分〜1時間超）は **無料枠では足りない** ため、有料プランが必要です。

---

## 2つの進め方

### パターンA: 運営側で文字起こしする場合

1. [Notta](https://www.notta.ai/) にアカウント登録（有料プラン推奨）
2. ログイン後、ダッシュボードの「インポート」をクリック
3. 動画ファイル（MP4等）をドラッグ＆ドロップ
4. 文字起こし言語で「**日本語**」を選択
5. 自動で文字起こしが開始（1時間の動画で約5分）
6. 完了後、以下をダウンロード:
   - **SRT (.srt)** — **必須**（これが正本データになります）
   - **Excel (.xlsx)** — 任意（照合用）
7. ダウンロードしたファイルを **Chatwork または Google Drive** で松野へ共有

### パターンB: 動画ファイルだけ共有する場合

1. 動画ファイル（MP4等）を **Google Drive の共有フォルダ** に置く
2. 松野側で Notta にアップロードして文字起こし
3. 追加費用は松野側で負担

---

## SRT ダウンロード手順（パターンAの詳細）

1. Notta で文字起こし完了後、該当の録音を開く
2. 右上の「**エクスポート**」をクリック
3. 形式で「**SRT (.srt)**」を選択してダウンロード
4. （任意）「**Excel (.xlsx)**」も選択してダウンロード
   - Include timestamps: **ON**
   - Include speakers: **ON**
   - Merge full text: **OFF**

---

## ファイル名の付け方（推奨）

```
セミナー名_YYYYMMDD.srt
```

例: `基礎STEP3_三段活用_20260716.srt`

## 管理画面からの取込（推奨・2026-07-29〜）

管理者ログイン後、サイドバー **「データ取込」** の **「セミナー動画 SRT 取込」** から `.srt` をアップロードできます。

| 項目 | 内容 |
|------|------|
| タイトル | 必須（検索結果に表示） |
| video_id | 必須（安定した英数字ID。同じIDで再取込すると上書き） |
| 動画URL / 講師名 | 任意 |
| 処理 | Supabase（意味検索）へチャンク＋埋め込み → Raimo 一覧にも反映 |

CLI 取込（`notta_to_knowledge.py`）は引き続き利用可。大量・バッチ時は CLI を優先。
