## 1. Gemini（枠と費用）

### いま使っているもの

| 用途 | モデル | 有料単価（公式・Standard） |
|------|--------|---------------------------|
| 通常検索の回答など（Raimo） | `gemini-3-flash-preview` | 入力 **$0.50** / 出力 **$3.00**（各 100万トークン） |
| 意味検索の要約（Edge） | 同上 | 同上 |
| 質問のベクトル化 | `gemini-embedding-001` | 入力 **$0.15** / 100万トークン（1問あたり極小） |

無料枠（Free）は **日次リクエスト上限が小さく、本番の会員規模では足りない** 前提。運営向けは **Paid（従量）** が必須。

### 1問あたりのざっくり単価（内部見積）

意味検索は回答文脈にコミュニティ最大約50件＋セミナー約25件（各スニペット上限あり）を載せるため、**入力トークンが支配的**。

| 経路 | 1問あたりの目安（Paid） |
|------|-------------------------|
| 意味検索（embed＋要約1回） | おおよそ **$0.01〜0.025** |
| 通常検索（キーワード／回答／出典で LLM 複数回） | おおよそ **$0.02〜0.04** |

（文脈が半分しか埋まらない日は下側、網羅回答・thinking が増えると上側。）

### 月額レンジ（Gemini のみ）

| シナリオ | 月間質問の目安 | Gemini 月額（USD） | 円換算の目安 |
|----------|----------------|--------------------|--------------|
| A 段階公開 | 約 0.6〜0.7万 | **約 $50〜200** | **約 0.8〜3 万円** |
| B 本格利用 | 約 3万 | **約 $400〜1,000** | **約 6〜15 万円** |
| C 上限寄り | 約 6.5万 | **約 $800〜1,600** | **約 12〜24 万円** |

**運営への一言**: 変動費の本体は Gemini。会員が一斉に使い始めると **月数万〜十数万円** になりうる。キルスイッチ・段階公開・意味検索比率の監視で抑えられる。

### 枠（レート）について

- Free のままでは **日あたりのリクエスト上限** にすぐ当たる想定（本番非推奨）。
- Paid でも **分あたり・日あたりのレート制限** はある。告知直後の同時集中は、通常検索誘導＋意味検索一時停止で緩和（Phase 14）。

## 2. Supabase（Free が厳しい理由と有料）

プロジェクト: **`kamiooya-qa` 1本**（用途ごとに新規プロジェクトは作らない方針）。

### Free のままが厳しい理由（会員本番）

| 理由 | 内容 |
|------|------|
| 休止 | 一定期間アクセスがないと **プロジェクトが止まる** → 会員向けサービス向きでない |
| バックアップ | 自動バックアップなし → 障害時のリスク |
| DB 容量 | Free は **約 500MB**。コメント＋ベクトル（embedding）が増えると逼迫しやすい |
| 同時・長時間 Edge | 意味検索は **最大約150秒**。ピーク時に Free の同時実行・公平利用で詰まりやすい |
| 運用品質 | ログ保持が短い・サポートなし。有料（Pro）の方が本番運用に合う |

Edge 呼び出し「回数」だけなら月数万でも Free の 50万回枠に収まる可能性はあるが、**休止・容量・本番信頼**の観点で **会員本格公開前に Pro 推奨**。

### 有料（Pro）の目安

| 項目 | 目安 |
|------|------|
| Pro 基本 | **約 $25 / 月**（組織課金。Micro コンピュートはクレジット込みで多くの場合この近傍） |
| 円換算 | **約 3,500〜5,000 円 / 月** |
| 超過時 | DB・egress・Edge 超過は従量。会員規模 B 程度なら、当面は基本料金近傍が多い想定 |
| Team（$599〜） | SOC2 等が要る場合のみ。倶楽部規模の通常運用では不要想定 |

**運営への一言**: Supabase は **月数千円の固定費**。Gemini の変動費に比べ小さいが、**Free のまま本番は避けた方がよい**。

## 3. 合計イメージ（Gemini ＋ Supabase）

| シナリオ | 月額のざっくり合計（円） |
|----------|--------------------------|
| A 段階公開 | **約 1〜4 万円**（Supabase 約0.4万 ＋ Gemini） |
| B 本格利用 | **約 7〜16 万円** |
| C 上限寄り | **約 13〜25 万円** |

含まないもの（別途確認）:
- Raimo 本体のホスティング／プラン料金
- ドメイン・メール送信（Resend 等）の従量
- 開発・保守の人件費（本試算の対象外）

### GitHub Actions（WeStudy 週次）— 副次コスト

Workflow: リポジトリ直下 `.github/workflows/westudy-raimo-weekly.yml`（日曜 06:30 JST・`ubuntu-latest`）。

| 項目 | 内容 |
|------|------|
| 何が動くか | WeStudy スクレイプ → 差分 CSV → Raimo／Supabase 取込 |
| 課金の種類 | **GitHub Actions の実行時間（分）**。Gemini／WeStudy の API 従量ではない |
| 目安 | 週1回・ジョブ上限180分。Private リポの無料枠を超えると分課金の可能性あり |
| 本体との比較 | 月額の主因は **Gemini**。Actions は副次 |

運営への一言: 「スクレイピングで別途大きな API 課金が乗る」わけではない。リポの Actions 分と、Secrets に入れる WeStudy／Raimo 認証の移管が論点。

## 4. コストを抑えるレバー（合意しやすい順）

1. **段階公開**（数百人ベータ → 拡大）… 実測で B に近づくか確認
2. **意味検索はオプトイン維持**＋混雑時キルスイッチ
3. **運営分析**で日次件数・失敗・**Gemini想定課金（試算）**を見て予算アラート
4. 将来: より安い Flash 系へのモデル変更・召還件数の調整（Phase 14-2）
5. **Gemini キーを倶楽部側の課金アカウントへ移管**（Phase 5）… 請求の透明性
