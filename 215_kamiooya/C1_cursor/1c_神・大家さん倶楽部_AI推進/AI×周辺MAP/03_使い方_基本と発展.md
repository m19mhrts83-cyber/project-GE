### 2. 基本フロー（2026-07-24 更新）

1. Step1 で店リストを得る → `要実測確認`を潰す  
2. **地図アプリ**（Pages／マイミニアプリ）でクリーン表示・範囲確定・**ピンなし**スクショ  
3. **C1** MyPrompt をコピー → Gemini にスクショ（＋任意で見本PDF）添付 → ベージュ下地  
4. ピン再合成（`jarvis_shuhen_recompose_decor.py`）→ Canva で Access／吹き出し  

詳細: `10c` / `11` / `12`

### 2. 変数を入れてプロンプトを生成

例:

- 物件名: Grandole志賀本通  
- 住所: 愛知県名古屋市北区（志賀本通駅周辺）※番地が分かれば番地まで  
- ターゲット: 単身・カップル  
- 施設数の目安: 15  

### 3. Gemini（推奨）に貼って実行

- 可能なら検索・マップ参照をオン  
- 出力の `要実測確認` を残したまま次に進まない（Accessの徒歩分は特に）

### 4. Googleマップで実測チェック

- 各 Access・推し施設について徒歩経路を確認  
- 閉店・移転がないか確認  

### 5. Canva で仕上げ

1. Canva無料で新規（例: A4横）  
2. アプリ → **Google Maps** → 住所検索 → **埋め込み**  
3. ズーム調整  
4. タイトル「物件名 周辺MAP」  
5. Access一覧をテキストで配置  
6. 吹き出し（推しのみ）  
7. エリア一言  
8. PDF / PNG でダウンロード  

公式参考:

- [地図作成（Canva）](https://www.canva.com/ja_jp/create/maps)  
- [Google Map 埋め込み](https://www.canva.com/ja_jp/features/google-map-embed)

## B. 発展版フロー

### B-軽：評判店だけ

1. 基本洗い出し（A）  
2. Deep Research（`02`）にターゲットを入れて実行  
3. 吹き出し更新 → 実測 → Canva  

### B-本：アドバンス（ペルソナ起点）

1. **ペルソナ設定**（`04` / Raimo「周辺MAP_アドバンス_ペルソナ設定」）  
2. 出力の「5-2 ペルソナ要約」「5-1 ターゲット一行」をコピー  
3. **アドバンス周辺MAP**（`05`）に貼って実行  
4. **Deep Research**（`02`）に同じ要約を渡して評判店を厚くする  
5. 実測 → Canva（吹き出しはペルソナ向け）

参考: 購入用二次判断（`473914`）は購入判断用。MAP用は `04` を使う。
