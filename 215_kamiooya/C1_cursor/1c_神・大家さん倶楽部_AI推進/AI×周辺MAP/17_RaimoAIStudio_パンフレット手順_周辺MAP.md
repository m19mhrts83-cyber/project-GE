## 2. 4ステップの欄定義（画面確認済み）

共通UI:
- 左: ステップタブ（1基本情報／2参考資料／3ページ構成／4レイアウト作成）
- 中央: **①このステップの入力** ＋ **プロンプトプレビュー** ＋ **プロンプトをコピー**
- 右: **② 外部AIの回答を貼り付け**（ChatGPT / Claude / Gemini 想定）
- 下: 「← 前のステップへ」「次のステップへ →」（最終は「ワークフローを完了」）

### Step1 基本情報

| 入力欄 | 必須 | 内容の入れ方 |
|---|---|---|
| パンフレットの種類 | * | 既定で「周辺MAP」入り。空なら `周辺MAP` |
| ページ数 | * | `1`（A4横・ペラ1枚） |
| 制作目的 | * | 作業シートの文案 |
| 想定読者 | * | 同上 |
| 使用・配布シーン | * | 同上 |
| 参考情報 | * | 物件名・住所・Access・施設文言など（作業シート） |

- 未入力があると「必須項目が未入力です: …」と出てコピー前に埋める。
- 出力先: 右の「AIから返ってきた回答」に **パンフレット基本情報シート** を貼る。

### Step2 参考資料

- **入力不要**（Step1の回答がプロンプトに埋め込まれる）。
- 「プロンプトをコピー」→ 外部AI → 回答を右に貼付。
- 出力: 【参考資料パート】形式。

### Step3 ページ構成

- **入力不要**（基本情報＋参考資料が埋め込まれる）。
- ※画面上のプロンプト見出しが「参考資料整理シート」寄りに見える場合あり。プレビュー全文を確認してからコピー。
- 出力: ページ構成／整理シート（1ページ想定で固定）。

### Step4 レイアウト作成

- **入力不要**（前3ステップの成果が埋め込まれる）。
- 出力: **レイアウト仕様書**（画像生成AIへ差し込む用）。
- 最終ボタン: **ワークフローを完了**。
- **クレジット消費・成果物確定の可能性があるため、完了直前はユーザー承認必須。**

## 3. 外部AIの使い方（このワークフローの本質）

Studio内で生成せず、**プロンプトをコピー → ChatGPT / Claude / Gemini で実行 → 回答を貼り戻す**。

推奨:
- Step1〜3: 通常チャット（Deep Research不要）
- Step4: 通常チャット（画像モードは、Studio側の次工程がある場合のみ）

Jarvis運用時: 各ステップのプロンプト内容に沿って Jarvis が回答文を用意し、右欄へ貼付してよい（外部AI相当）。
