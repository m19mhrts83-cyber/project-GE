# チャプロ概要と代替アプリ検討

- 作成日: 2026-08-10
- 目的: 周辺MAPで使っているチャプロ（MyPrompt）の仕様を振り返り、自前代替アプリ（prompt-share）の設計根拠にする
- 実地調査: chapro.jp / manage.chapro.jp（周辺MAP Step1.1 = 473908）

関連: `03_使い方_基本と発展.md` / `01` / `02` / `11` / `検証_チャプロ比較_周辺MAP.md`

## 1. サービス概要

| 項目 | 内容 |
|---|---|
| ブランド | 生成AIプロンプト研究所「チャプロAI」 |
| 運営 | 株式会社エキスパート（代表: 七里信一） |
| 公開サイト | https://chapro.jp/ |
| 管理画面 | https://manage.chapro.jp/ |
| 関連 | 生成AIの学校「飛翔」（chapro.works）、Raimo / Lime（同系統UI・別アカウント） |

チャプロはプロンプトテンプレートの登録・変数展開・URL公開・外部AIへのコピペ動線を提供する。周辺MAPでは Raimo の一般公開（未ログイン）が使えないため、暫定でチャプロにミラー公開してきた。

### Raimo / Lime との関係

| 項目 | 内容 |
|---|---|
| UI | チャプロと同系統（MyPrompt） |
| アカウント | 別（`CHAPRO_*` と `RAIMO_*`） |
| 現状の役割分担 | 編集本線は Raimo、外部・未ログイン共有はチャプロ暫定 |
| 既知差分 | Raimoは一般公開ログイン壁／コピー時の変数未展開の報告あり。チャプロは変数展開コピーが正常 |

## 2. 公開ページ仕様（実地確認）

URL例: `https://chapro.jp/prompt/473908`（`/prompt/{id}/{公開トークン}` 形式も可）

### 画面構成

1. タイトル・作者・説明（「もっと見る」で折りたたみ）
2. **左**: プロンプト本文プレビュー（変数箇所を色ハイライト、一般ユーザーは編集不可）
3. **右**: 変数入力欄（変数名ラベル＋テキストエリア＋「合体変数にする」）
4. 下部: 「プロンプトを生成」

### 利用フロー

1. 変数を入力（未入力があると「デフォルトの入力例が入ります」確認モーダル）
2. 「プロンプトを生成」→ 完成プロンプト全文モーダル
3. 「コピー」→ クリップボード
4. 外部AIリンク（新規タブ）: Claude / ChatGPT / Gemini / Google AI Studio  
   ※ 各サービスのトップを開くだけ。プロンプト本文はURLに載せず、コピー→貼付前提

ログイン不要で閲覧・利用できる。

## 3. カウント仕様（実験結果 2026-08-10）

管理画面 Myプロンプト一覧に「出力数」「コメント」列がある。

| 操作 | 出力数 |
|---|---|
| 公開ページを閲覧のみ | 増えない |
| 「プロンプトを生成」を押す（→コピー） | **+1**（Step1.1: 6→7 を確認） |
| 同一ページ表示中の2回目生成・コピー | 増えない |

**結論**: チャプロの「出力数」は **「プロンプトを生成」押下回数（1ページ表示につき初回のみ）**。コピー回数・AI遷移・閲覧はカウントされない。

代替アプリでは view / generate / copy / open_chatgpt / open_gemini をイベント記録し、チャプロより細かく把握できるようにする。

※実験のため Step1.1（473908）の出力数が 7 になっている（本文は未変更）。

## 4. 管理画面仕様（実地確認）

URL: `https://manage.chapro.jp/myprompt`

### 一覧

- Myフォルダ（グループ）。例: `AI×周辺MAP (3)`
- 種別タブ: 通常 / チェーン / オート / Assistant
- 列: タイトル / 公開 / 出力数 / コメント / 作成日
- 検索・ソート・リスト/カード切替

### 編集（2ステップ）

1. タイトル（必須）・一般公開設定（非公開/一般公開）・フォルダ・サムネイル・説明（リッチテキスト）
2. 本文エディタ ＋ 変数一覧  
   - 本文に `{変数名}` を書くと変数欄が自動追加／削除  
   - 変数記号（`{}` 等）を選択可  
   - 変数ごとに入力例（デフォルト値）を設定可

## 5. 周辺MAPでの現行利用

| Step | チャプロ暫定URL | Raimo本線 | 用途 |
|---|---|---|---|
| Step1.1 基本洗い出し | https://chapro.jp/prompt/473908 | 473911 | 通常チャット用たたき |
| Step1.2 実在検証 | https://chapro.jp/prompt/475607 | 473910 | Deep Research |
| Step3 下地色味寄せ | https://chapro.jp/prompt/475606 | 474296 | 画像モード（任意） |

運用の型: 変数入力 →「プロンプトを生成」→ 全文コピー → Gemini / ChatGPT に貼付。工程が変わったら新しいチャット。

プロンプト本文の型（チャプロ互換）: `#前提条件` → `#実行指示` → `#情報`（変数スロット）→ `#出力フォーマット` → `#補足`

## 6. 代替アプリ（prompt-share）対応表

| チャプロ機能 | 代替アプリ | 方針 |
|---|---|---|
| 公開URL・未ログイン利用 | `/p/{public_token}` | 踏襲（トークンのみ・推測困難） |
| 左プレビュー＋右変数 | 同レイアウト | 踏襲＋説明文を追加 |
| `{変数名}` 自動抽出 | 管理編集で同様 | 踏襲（既存本文をコピペ移行可） |
| 生成→コピー→AIリンク | コピー＋ChatGPT/Gemini | 踏襲（Claude/AI Studioは任意） |
| 出力数 | view/generate/copy/open_* イベント | **改善**（上位互換） |
| Myフォルダ | prompt_groups | 踏襲 |
| 一覧・公開状態 | 管理ダッシュボード＋公開一覧 | 踏襲 |
| チェーン/オート/Assistant | — | **対象外** |
| AIスタジオ（アプリ内実行） | — | **対象外** |
| コメント・サムネ・合体変数 | — | **対象外**（周辺MAP未使用） |
| Raimoコピー未展開 | プレビュー常時展開 | **構造的に回避** |
| 神大家メンバー限定 | access_level=member | **将来フック**（初期は public） |
