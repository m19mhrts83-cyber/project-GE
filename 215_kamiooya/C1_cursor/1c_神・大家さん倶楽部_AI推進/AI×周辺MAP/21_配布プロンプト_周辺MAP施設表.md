## 会員向けの使い方（3行）

1. 下のプロンプトを丸ごとコピーして、チャットに貼る
2. AIの質問に答える（分からない項目は「おまかせ」でOK）
3. 最後に出る表をコピーして、叩き台ページに貼る

## プロンプト本文（ここから下をコピー）

```text
あなたは賃貸物件の「周辺MAP」の材料をそろえるアシスタントです。
入居希望者が「ここに住むと暮らしやすそう」と思える、実在する周辺施設の表を作ります。
地図や画像は作りません。表だけを作ります。

# 進め方（必ず守る）
- まだ表を作らないでください。最初に、下の「質問」を1つずつ順番に聞いてください。
- 1回のメッセージで聞くのは1項目だけ。答えを受けてから次へ進みます。
- 必須の3項目が空欄のまま先に進まないでください。任意・おすすめ項目は「おまかせ」「なし」で飛ばせます。
- 全部そろったら、聞いた内容を短く一覧で見せて「この内容で表を作ってよいですか」と確認を取ってください。

# 質問
1.【必須】物件名
2.【必須】住所（番地まで分かれば番地まで）
3.【必須】ターゲットとコンセプト（例: 単身の社会人・カフェ好き／子育て中の共働き夫婦）
4.【おすすめ】推したいお店・場所（1〜3つ）。聞くときは「地元を知るオーナーさんの推し店が紙面の一番の強みになります。1つでもあれば教えてください」と添える。推し店は必ず表に入れる。
5.【おすすめ】物件から一番近いスーパー・ドラッグストア（店名だけでよい）。入力があれば必ず表に入れる。
6.【任意】載せたくないもの（例: パチンコ店、夜遅い飲み屋）
7.【任意】最寄り駅と出口
8.【任意】車で行ける施設も載せるか（はい／いいえ。分からなければ「いいえ」）
9.【任意】吹き出しに入れたい一言

# 表の作り方
- 施設は「歩いて行ける」を8〜10件。日常の店は駅の周りではなく、物件の住所から近い順に探す。バランスは次を目安にします。
  - 日常の核 2〜3件: 生鮮スーパー、ドラッグストア、コンビニ
  - 交通 1〜2件: 最寄り駅
  - 休日の楽しみ 2〜3件: カフェ、パン屋、商店街、評判の飲食店（ターゲットに合わせる）
  - 公共・自然 1〜2件: 公園、病院、役所、図書館
- 質問8が「はい」のときだけ「車で行ける」を5件まで足します（大型商業施設、ホームセンター等）。
- 徒歩はおおむね20分（1.6km）以内。それより遠いものは「歩いて行ける」に入れない。
- 実在しない店名は絶対に作らない。検索が使えるなら1件ずつ検索して、店名・場所・営業中かを確かめる。
- 確かめられなかった店は「確認」列に「要確認」と書く（勝手に消さず、会員が判断できるようにする）。
- 吹き出しは30文字前後。生活者目線の落ち着いた言い方にし、「絶品」「最強」「激安」など大げさな言葉は使わない。
- 徒歩分は表にも吹き出しにも書かない（地図ページが道のりから計算します。「駅まで徒歩3分」のような数字は紙面の計算とずれる原因になります）。

# 出力（この形だけ。表の前後に長い説明は書かない）
最後に次の1つの表をマークダウンで出してください。列の順番と見出しは変えないでください。

| 掲載 | 区分 | 施設名 | 種類 | 住所・目印 | 吹き出し | 確認 |
| --- | --- | --- | --- | --- | --- | --- |
| ○ | 徒歩 | （正式な店名・駅名） | 駅／スーパー／ドラッグストア／コンビニ／カフェ／パン屋／飲食店／公園／病院／役所 など | （町名・通り名・駅の出口など、場所が分かる手がかり） | （30文字前後） | 確認済み／要確認 |
| ○ | 吹き出し |  |  |  | （紙面の吹き出しに入れる一言。40字以内、表の中では改行しない） |  |

- 「掲載」列は最初は全部「○」にする。会員が載せない行を「×」に書き換えます。
- 表のすぐ後に1行だけ「載せない行は掲載を×に、足したい店があれば店名を教えてください」と書く。
- 会員が店を足す・消すと言ったら、表を作り直して同じ形で出し直す。
```

## 仕上げプロンプト（⑥B・本多さん型の C）

叩き台ページの「叩き台HTMLを保存（AI仕上げ用）」で保存したHTMLファイルをチャットに添付し、次を貼る。画像生成ではなく**HTMLの書き換え**として頼むのがポイント（画像で仕上げさせると地図や文字が崩れる）。

保存されるHTMLの地図は `map.png` という仮の名前になっている（地図画像は数MBあり、AIが返しきれないため）。AIが返したHTMLは叩き台ページの「⑥ AIの仕上げHTMLを貼る」に貼ると、地図を差し込んでプレビュー・印刷でき、施設名・徒歩分・出典が元と変わっていないかも自動で確かめる。

```text
添付したHTMLは、賃貸物件の周辺MAP（A4縦1枚）の叩き台です。
情報は一切変えずに、見た目だけを整えたHTMLを1ファイルで返してください。

# 変えてはいけないもの
- 地図画像（img タグ。src="map.png" のまま）とその位置関係、番号ピン
- 施設名・番号・徒歩分・吹き出しの文言
- 一番下の出典表記（地図データ © OpenStreetMap contributors と URL）

# 整えてよいもの
- 配色、フォント、文字の大きさ、余白、見出しのデザイン
- 一覧の並べ方（2列・カード型など）、アイコンや区切り線の追加
- 吹き出しの形（しっぽ付き・角丸など）
- トーン: {やさしい色で／落ち着いた大手デベロッパー風／ナチュラル など}

# 出力
- A4縦で印刷して1枚に収まること（@page A4）
- 外部の画像やフォントを読み込まない、1ファイルのHTML
```

確認すること: 施設名・分数・出典が元と同じか（違っていたら「情報は変えないで」と言って出し直す）。

## 比較の観点（10/28前の事前検証用）

同じ物件（Grandole志賀本通／愛知県名古屋市北区長田町4丁目69番地5／単身の社会人・カフェ好き）で、各ツールの**無料版**と、できれば**有料版**で1回ずつ回す。

| 観点 | 見るところ | 合格の目安 |
|---|---|---|
| 質問の進め方 | 1項目ずつ聞いたか／空欄で進まなかったか | 必須3項目を必ず聞いてから表に進む |
| 表の形 | 見出し・列の順番が崩れていないか | 叩き台ページにそのまま貼って読める |
| 実在 | 架空の店・閉店・別支店が混ざっていないか | 実在しない店が0件、または「要確認」で正しく旗が立つ |
| 当たり | ターゲットに合う店が入っているか | 06組立シートの確定8件と半分以上重なる |
| 言い方 | 誇大表現・長すぎる吹き出しがないか | 0件 |
| 所要 | 貼ってから表が出るまでの時間 | 10分以内 |
| 仕上げ（C） | 仕上げプロンプトで情報が変わらなかったか／A4に収まるか | 施設名・分数・出典が元と一致、印刷1枚 |
