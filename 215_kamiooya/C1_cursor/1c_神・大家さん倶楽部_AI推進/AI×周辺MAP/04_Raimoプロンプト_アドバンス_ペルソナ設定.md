# Raimo MyPrompt：アドバンス ペルソナ設定（周辺MAP用）

- **用途**: 空室対策・周辺MAPの前段で、**入居者ペルソナを1人に絞って決める**
- **位置づけ**: Step1（基本）とは別ルートの **アドバンス版 Step0**
- **参考元**: チャプロ／Raimo「(二次判断)周辺環境と入居者ペルソナ提案」  
  → 購入判断用ではなく、**募集・周辺MAP訴求用**に再設計
- **次工程**: 出力の「次工程コピペ欄」を  
  `05_...アドバンス周辺MAP` → `02_DeepResearch` へ渡す  
  （施設の地図プロット用リストは **05／02 の「地図アプリ投入用」コードブロック**で出す。本プロンプトでは出さない）
- **Raimo**: https://raimo.buzz/prompt/473915
- **知見**（Tavily）: チラシ・募集は万人受けより、詳細ペルソナに刺さる訴求の方が反応しやすい。吹き出しも「その人を案内する感覚」で書く。

---

## 二次判断との違い

| | 二次判断（購入） | 本プロンプト（アドバンスMAP） |
|---|---|---|
| 目的 | 買う前の入居付け見込み | **誰に向けた周辺MAPにするか**を決める |
| 出力の重心 | 周辺環境表＋購入アドバイス | **採用ペルソナ1人**＋MAP／店選びの指針 |
| マイナス環境 | 見送り判断用に詳述 | MAPに載せる／載せないの判断材料程度 |
| 次の使い方 | 購入可否 | Canva吹き出し・Deep Researchの入力 |

---

## 変数

| 変数 | 必須 | 例 |
|---|---|---|
| `{物件名}` | 必須 | Grandole志賀本通 |
| `{住所}` | 必須 | 愛知県名古屋市北区長田町4丁目69番地5 |
| `{構造・間取り}` | 推奨 | 木造 / 1K〜1LDK 中心 |
| `{想定家賃}` | 推奨 | 5.5〜6.5万円 |
| `{補足条件}` | 任意 | 駅徒歩10分圏・単身向け募集中 など |

空欄は「一般的な都市部アパート」として推定し、推定である旨を書く。

- 方針：
  - 万人受けの抽象ターゲット（例: 誰でも）は禁止。具体的な1人を描く
  - ペルソナは「その人を物件と街に案内する」つもりで書く
  - 周辺環境はペルソナの魅力訴求に必要な範囲に絞る（網羅調査が主目的ではない）
- データソース優先：Googleマップ／公式情報／信頼できる公開情報。断定しすぎない
