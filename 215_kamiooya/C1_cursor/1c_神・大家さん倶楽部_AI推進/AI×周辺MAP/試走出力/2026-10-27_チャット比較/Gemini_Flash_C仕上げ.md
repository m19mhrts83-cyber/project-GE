- 実施: 2026-10-27 02:35頃 JST（画面操作）。アカウント条件は Gemini_Flash.md と同じ（仕事用・Pro表示、モデルFlash）
- 入力: `2026-10-27_OSM見本/Grandole志賀本通_周辺MAP_叩き台_retry.html`。地図画像（base64・約3.6MB）はチャットに貼れないため `src="map.png"` に置き換えて本文に貼付。プロンプトは21の仕上げプロンプト、トーンは「落ち着いた大手デベロッパー風」
- 注: 実運用ではHTMLファイルを添付する想定。画像込みのファイル添付は今回未検証

## 結果
| 観点 | 結果 | メモ |
|---|---|---|
| 施設名・番号・徒歩分 | ◎ 一致 | 1〜8の名前・分数・吹き出し文をコード上で目視照合。元にあった「徒歩3分で大抵の買い物が済みます」（計算値2分と食い違う吹き出し）も**指示どおり変えずに残した** |
| 出典表記 | ◎ 一致 | 「地図データ © OpenStreetMap contributors（https://www.openstreetmap.org/copyright）」をそのまま保持（追加質問で全文確認） |
| 地図画像 | ◎ | img と src はそのまま。`.mapimg` に `max-height:128mm; object-fit:contain` を足してA4に収める工夫 |
| A4 | ○ | `@page { size: A4 portrait; margin: 0 }`。余白0は家庭用プリンタで端が切れる可能性あり（実印刷は未確認） |
| 見た目 | ○（未レンダリング） | ネイビー＋シャンパンゴールド、一覧は2列カード型、吹き出しは丸型。コードの説明ベース。画面での描画確認はできていない |
| 直しやすさ | △ | 出力はコードブロック。会員は「コピー→メモ帳に貼って .html で保存」が必要。コードが長く、横に切れて画面上では全文が読めない |

所見: 「情報は変えずに見た目だけ」は守られた（本多さん型Cの肝は成立）。課題は受け渡し。チャットからHTMLを取り出して保存する手順が会員には難しい → 叩き台ページ側に「AIの返したHTMLを貼るとプレビュー・印刷できる欄」を付けると一気に楽になる（提案）。
