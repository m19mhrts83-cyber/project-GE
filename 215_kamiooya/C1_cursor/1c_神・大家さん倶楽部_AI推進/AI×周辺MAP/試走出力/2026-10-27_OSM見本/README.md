# 周辺MAP OSM版 叩き台 — 実地図・実データ見本（2026-10-27）

`shuhen-osm.html` / `shuhen-osm.js`（ブランチ `claude/project-thread-wbrasn` の a6b6d67b）を、Mac 上でヘッドレス Chrome（selenium 4.36）から実行した記録。
ページは `python3 -m http.server 8790` で配信し、OSM タイル・Nominatim・routing.openstreetmap.de に実際に通信した。

## 実行内容

1. 「見本データを入れる」→「地図にピンを立てる」→ `#status` が「ピンを立てました」になるまで待つ
2. 「A4叩き台を作る」→ `.sheet` のスクリーンショット、ページ全体の A4 PDF（Chrome の印刷＝`@media print` 適用）、「叩き台HTMLを保存」のダウンロード
3. 見つからなかった・ずれた施設の住所・目印を直した表で再実行（`_retry`）

## 見つからない・ずれるときの直し方（気づき）

1. **店名の飾りを外す**: 「つばめパン&Milk」→「つばめパン」でヒット。記号（&・＆）や英字のサブ名は外したほうが当たる。
2. **目印の丁目は漢数字で書く**: OSM の町域名は「杉栄町二丁目」「大杉一丁目」「若葉通一丁目」のように漢数字。「杉栄町2丁目」「長田町4丁目」の算用数字では当たらない／別の場所に飛ぶことがあった（`名古屋市北区杉栄町` だけだと楠三丁目の別店舗に飛んだ）。→ ページ側で「数字丁目→漢数字丁目」の言い換えを足すと改善しそう。
3. **チェーン店の個店は OSM に無いことが多い**（ナフコトミダ杉栄店・ドラッグスギヤマ杉栄店・つけそば神宮寺・Cafe de Lyon Palette）。目印の町域の中心に「要確認」付きで置かれるので、編集地図でピンをドラッグして直す運用になる。
4. **同じ目印の施設はピンが完全に重なる**。紙面で番号が隠れるので、推定位置どうしは少しずらして置く処理があるとよい（今は人がドラッグで直す前提）。
5. **徒歩20分の施設（北区役所）が入ると地図が引きで小さくなる**。近隣の店の番号が密集するので、遠い施設は「車」区分にするか外すと見やすい。
6. **吹き出しの文と計算した徒歩分が食い違う**（表は「徒歩3分で…」、計算は2〜3分）。吹き出しに分数を書かせない、とプロンプトに入れるとよい。
7. **8件だと A4 が2ページにはみ出す**（印刷余白10mm）。6件なら1ページに収まった。一覧の行間を詰めるか、地図の高さを少し下げる調整が要る。
8. 「叩き台HTMLを保存」は地図を PNG で埋め込むため 2.5〜3.6MB になる。保存名が物件名だけなので、同じ物件で2回保存すると上書きされる。
