# 番号ピン骨格チェックリスト — Grandole（元アプリ寄せ）

利用者: 自分＋Jarvis。**マイマップ手打ちは不要**。

参照: `10_フェーズAtoC_ハイブリッド方針.md` / `06` / `09` / `shuhen-map.html`

---

## 0. 準備

- [ ] `06` の Access6・吹き出し8 を手元に開く（文言確認用）
- [ ] Google Maps API Key（Maps JS / Places / Geocoding）

---

## 1. アプリでピンを出す

```bash
cd ~/git-repos && python3 -m http.server 8000
```

1. [ ] http://localhost:8000/shuhen-map.html を開く  
2. [ ] APIキーを入力（管理会社検索と同じで可）  
3. [ ] 「Grandoleプリセット」→「ピンを表示」  
4. [ ] P0〜P8 が地図に載り、一覧に住所が出る  
5. [ ] 東西: P1（志賀本通）が西寄り、P2（尼ケ坂）が東寄りに離れている  
6. [ ] 近接: ナフコ／スギヤマが物件近く  

失敗した店名があれば検索語を直して再実行。

---

## 2. 骨格の保存

## 3. 装飾（縁スロット）

- [ ] Canva A4横に骨格を配置  
- [ ] 左 Access6（`06`）  
- [ ] タイトル・エリア一言
