## 試走から分かったこと

1. **本多さん型は「地図をAIに描かせない」**ので、松野の手堅さと両立する。
2. **初心者の抵抗**は Phase B（スクリプト／API）より **Phase A（何を埋めるか）** に寄る。加盟店向けは「住所＋ターゲット一行」から表を自動提案し、人が○×する形がよい。
3. **口頭修正**は「情報を変えない指示」（短く／色／余白）と「事実を変える指示」（店を足す）を分けないと危険。後者は Phase A に戻す。
4. Phase C（Opus／Claude Design）は **見た目の講座映え**用。ライト版の必須ではない。

## ライト版（加盟店・オーナー向け）— 次タイミング検討メモ

目標体験:

> 必要情報を入れたら手間なく叩き台ができ、口頭でちょっと直すと目指す周辺MAPになる

| 層 | ライト版の案 | 初心者に見せる？ |
|---|---|---|
| 入口 | 住所・物件名・ターゲット一行だけ | ○ Web／ミニアプリ |
| 事実 | 裏側で候補→実在チェック→ピン（今の Step1.2＋Places） | ×（結果の表だけ見せる） |
| 組版 | HTML or Canvaテンプレ自動 | ○「できた」画面 |
| 口頭修正 | 「もっとかわいく」「この店やめて」→ 描写 or 表の再選択 | ○ チャット／音声 |
| 禁止 | 地図の描き直し・未検証店の自動追加 | 運用ルール |

次に決めること（検討用）:

1. 入口を Raimo／Prompt Share／単独Webのどれにするか  
2. 加盟店が触ってよい範囲（口頭は描写のみか、店の差し替えまでか）  
3. 運営への提供物（手順1枚＋テンプレ＋デモPDF）
