## わかったこと（暫定、Claude結果待ち）
1. 画像生成AIに「デザインを作り直して」と頼むと、見た目は見本に寄るが、**中身（店名・分数・位置）は守られない**。架空の店や見本の店が混ざり、そのまま配ると誤情報になる。
2. 「人が喋っている姿」は ChatGPT なら1文の指示で入る。Gemini は見本と叩き台を合成しただけになった。
3. 「白地図で文字が消える」状態は、どちらも自然には起きなかった。白地図を使いたいなら、AIに地図を描かせるのではなく、shuhen-osm 側で白地図（ラベルなしタイル）を出し、その上にピンと吹き出しを重ねるのが確実。
4. したがって構成案Bの役割分担は「**中身は shuhen-osm（地図・番号・分数）で固め、AIには飾り（吹き出しの文言、キャッチコピー、配色案）だけ頼む**」が安全。画像AIの出力は「デザインの参考イメージ」止まりで、配布物にはしない。

## ChatGPT 版の見立て（叩き台との突き合わせ）

見た目は見本にかなり寄る。ただし**中身（地図・施設・徒歩分）を作り変えている**ので、このままは使えない。

**見本に寄った点**
- ピンクの帯見出し（所在地・駅徒歩・物件名・「周辺MAP」バッジ・徒歩分のチップ4つ）、外観写真枠
- **人が喋っている姿**: 女性・男性のイラスト＋吹き出し2つ。文面も叩き台の吹き出しをもとに作られている
- 地図の周りに写真付きカード（施設写真・名前・徒歩分・一言）、物件から駅への点線の動線、「駅まで徒歩10分」ラベル、方位・縮尺
- 下段「歩いて行ける」「車でおでかけ」の2列の一覧

**地図（ホワイトマップ化）**
- 叩き台の OSM 地図（店名・P などの文字が多い）は使われず、**文字の少ない淡い地図に描き直されている**。見た目は見本のホワイトマップに近いが、**実際の道路・駅位置とは別物の作り絵**（「出来町通」「名城線」などの文字も新たに描かれている）。

**作り変わった・混ざった点（要注意）**
- 施設が入れ替わった: セブンイレブン 名古屋長田町店（叩き台に無し）、イオン名古屋北店、西友、**黒壁スクエア（見本の長浜の施設が混入）**。尼ケ坂駅・ファミマ・クリボーが消えた
- 徒歩分が変わった: 志賀本通駅 8分→10分、コメダ 6分→5分、セブン 2分（新規）など。車の一覧の「徒歩7分」など区分の取り違えもある
- 地図上の番号と一覧の番号が一致しない（地図に②が2つ、⑥〜⑨の位置は根拠なし）
- 写真はすべて AI が描いた架空の写真（外観・店舗）。実物件・実店舗の写真ではない

## 白地図を叩き台ページ側で出す（10/27 追加）

画像AIでは白地図にならなかったので、shuhen-osm の「紙面の地図」に **白地図** を追加した（0d06cc5, 0d5f6d3）。
- 文字なしタイル（CARTO light_nolabels）は API キー必須になっていて使えなかったため、Overpass から道路・線路・川・公園の形を取り、ページ側で線と面だけを描く方式にした。
- 地図上の文字は物件名と駅名（駅のピンの横）だけ。道路・線路は実データなので位置は正確。ピン番号・徒歩分・駅への点線は表どおり。
- 出力: `白地図_叩き台.png`（白地図）、`ふつう地図_叩き台.png`（従来のOSMタイル）。
- 所要: 白地図 約30秒（Overpass が1回目 502 → 自動で取り直して成功）、ふつう地図 約3秒。Overpass は混雑で失敗しやすいので最大3回取り直す。本展開で人数が増えるなら有料のベクタータイル等に切り替えを検討。

## Claude Sonnet 5.5 版（10/28、松野さん実施）

条件の違い: 周辺MAP表を作ったチャットの続きで依頼（ChatGPT・Gemini は新規チャット）。`Claude_Sonnet.png`。

- **中身は叩き台のまま**: 施設9件・番号①〜⑨・徒歩分（1/2/2/5/6/7/8/10/24分）・クリボーの「地図外」まで一致。架空の店・見本（長浜）の混入なし。
- **地図は叩き台のOSM地図をそのまま使用**（描き直さない）。そのため白地図にはならず、地図上の文字・Pマークは残る。

- 評価: 3つの中で唯一「そのまま配れる」中身。見た目は ChatGPT ほど華やかではない。白地図（shuhen-osm の白地図）と組み合わせれば、見本にかなり近づく見込み。


## Claude Opus 5.5 版（10/29、松野さん実施）

条件: 新規チャットで依頼（Sonnet は表を作ったチャットの続き）。`Claude_Opus.png`（1588×2246）。

- **中身は叩き台のまま**: 施設9件・番号①〜⑨・徒歩分（1/2/2/5/6/7/8/10/24分）・クリボーの「地図外」まで一致。架空の店・見本（長浜）の混入なし。新規チャットでも中身は崩れなかった。
- **見栄えは Sonnet より見本に近い**: 地図の周りに施設カード（志賀本通駅・ナフコトミダ・コメダ）を置いて点線でピンとつなぐ、見本の「写真カード」の構成を再現。写真の代わりに素朴なイラストで、外観には「写真に差し替え」の札（架空写真は作らない）。
- **人が喋っている姿**: 女性・男性のイラスト＋吹き出し2つ（文面は叩き台の吹き出し・駅の説明）。
- 一覧を「歩いて行ける（暮らし・買い物）」「駅・通勤」「カフェ・喫茶」の3つに分け、種類タグ（公園・スーパー・薬局・地下鉄・名鉄…）を付ける。方位記号も追加。

- 評価: 3社＋Sonnet の中で、**中身を守ったまま見栄えが一番見本に近い**。「Opus は見栄えの調整が良い」という意見と合う。白地図の叩き台と組み合わせれば、さらに見本に近づく見込み。
