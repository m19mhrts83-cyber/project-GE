### 気づき

1. **素のままでは3社とも紙面にならない**。ヒットは2〜4件で、駅が出たのは Claude の表だけ。施設が少なすぎ、しかも残ったのは遠い施設（公園・図書館・区役所）が中心。
2. **「地下鉄名城線 志賀本通駅」のように路線名を前に付けると駅が見つからない**（Gemini・ChatGPT）。Claude は「志賀本通駅」と書いて目印欄に路線を回したのでヒットした。`locateFacility` の「短い名前」は `&・/（` などで切るだけで、スペースの前置きは外さない。
3. **目印からの推定が1件も効かなかった**。前回見本（町名だけの目印）では3〜4件推定できたが、今回の目印は「北区杉栄町2-48」のような番地付き・「志賀本通駅の近く」「若葉通沿い」のような文、「北区の地区公園」のような説明で、Nominatim に通らない。
4. **ChatGPT の表は住所が番地まで具体的なのに一番当たらない**。チェーン店名（ナフコ・スギヤマ・ファミマ・コメダ）は OSM 側に支店名付きで載っていないことが多い。番地を目印に入れても上記3の理由で推定に使えない。
5. **違う場所に当たっている疑い**: ChatGPT「喫茶・食堂クリボー」は目印が「長田町4-66-2」（物件の隣）なのに 1.9km 先（24分）に当たった。Gemini「B&Dドラッグストア 志賀本通店」も 2.2km（28分）で、志賀本通の店ではなく別の B&D の可能性。検索範囲が物件から2.5km四方のため、同名の別店舗を拾う。
6. **紙面の番号が飛ぶ**（例: Claude は ①③⑨⑩、Gemini は ②③⑧⑨）。見つからなかった施設も番号を持ったまま `renumber()` されるため（`minutes` が無い行の並べ替えも不定）。紙面に出る施設だけで振り直す必要がある。
7. 施設が少ないぶん3社とも A4 1枚に収まった（前回の8/8件ヒット時は2ページにはみ出した）。
