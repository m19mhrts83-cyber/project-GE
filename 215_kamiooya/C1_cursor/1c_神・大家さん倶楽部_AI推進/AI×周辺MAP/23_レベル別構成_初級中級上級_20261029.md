## 1. 10/28 打合せで出ていたこと（周辺MAP分だけ）

- 品質を上げるほど手順が増え、途中でついてこられなくなる → **初心者向けを先に、上級は希望者に段階的に**
- 入口は「いつものAIチャットに一問一答で答えて表を作る」形が取り組みやすい
- 無料の簡易版でも色や写真で一定の見栄えになる。細かい仕上げは有料・上位モデルが役立つ（Sonnet の例、Opus ならさらに良くなる可能性）
- 地図は **OpenStreetMap＋出典表記**の方向。Google マップは営利利用と見なされる懸念
- **普通のチャットだけでは位置の扱いがうまくいかない** → 表を別のアプリに渡す工程が要る
- 本多さんの作成例を見本にするなら**許可を得る**
- 周辺MAP は WeStudy バックアップより優先度を下げる可能性あり
- 利用者の大半は初級で満足、こだわる人は一部（感覚値）

## 2. 3段階の構成

| | 初級（まず全員） | 中級（見栄えを上げたい人） | 上級・アドバンス（こだわる人） |
|---|---|---|---|
| ゴール | 地図に番号ピンと徒歩分が入った**A4 1枚** | 本多さん風の見栄え（人物・吹き出し・カード・白地図） | 実写真入り・推し店入りの募集用完成版 |
| 費用 | **無料** | 無料〜有料（有料なら Opus） | 有料ツール可 |
| 目安時間 | 30分 | ＋30分 | ＋1〜2時間 |
| 使うもの | 普段の AI チャット（無料版）＋**周辺MAPページ** | 初級＋AI に「見た目だけ整えて」と頼む | 中級＋Canva、Deep Research、（松野さんの作り込み方式） |
| 人がやること | 質問に答える／載せない店に×／ピンのずれを見る | 仕上がりの見比べ | 写真の用意・店の実在確認・細部の調整 |

### 初級（無料）— 4ステップ

1. **プロンプトを1つコピーしてチャットに貼る**（[`21_配布プロンプト`](21_配布プロンプト_周辺MAP施設表.md)）
2. **一問一答で答える**（必須は 物件名・住所・ターゲットの3つだけ。分からなければ「おまかせ」）→ 最後に表が出る
3. **表をコピーして周辺MAPページに貼り、ボタンを押す** → 地図に番号ピン・徒歩分が自動で入る。載せない店は×、ずれたピンはドラッグ
4. **「A4叩き台を作る」→ 印刷・PDF保存**（ふつう地図／白地図を選べる）

ここで終わってよい。人物・吹き出しカード・写真は中級以降。

### 中級 — 見た目を整える

- 周辺MAPページの「叩き台HTMLを保存」→ AI チャットに添付して「見た目だけ整えて」（配布プロンプトの仕上げ文）
- 本多さん風（ピンク帯見出し・人物と吹き出し・施設カード）にしたいときは、見本画像も一緒に渡す（本多さんの許可が前提）
- 地図の文字を消したいときは周辺MAPページで**白地図**を選んでから保存する
- 有料版を使える人は Claude Opus に頼むと一番見本に近い

### 上級・アドバンス — 作り込み

- 推し店・評判店を Deep Research で探す（実在確認は人が行う）
- Canva で実写真・人物・吹き出しを仕上げる
- 松野さんの作り込み方式（Cursor、高精度の位置合わせ等）はここに置く。会員の大半はまだ求めていない前提
- AI の画像生成で地図ごと描かせる方法は**参考イメージ止まり**（店名・徒歩分・位置が変わるため）

## 3. どのモデルを使うか（10/27〜29 の検証から）

| 工程 | おすすめ | 理由 |
|---|---|---|
| 初級：表づくり（一問一答） | **普段使っている無料版でよい**（ChatGPT／Gemini／Claude） | 3社とも同じ形の表が出て、地図ページで A4 まで進めた。ページ側の直しの後、紙面に載った件数は ChatGPT 9/10・Claude 7/10・Gemini 6/9。迷う人には ChatGPT 無料版 |
| 中級：見た目の仕上げ | **Claude**（無料版の Sonnet で可、有料なら Opus） | 中身（店名・番号・徒歩分）を変えずに見た目を整えられたのは Claude だけ。Opus は新規チャットでも中身を守り、見栄えが一番見本に近かった |
| 使わない方がよい | ChatGPT・Gemini の**画像生成**で地図ごと作り直す | ChatGPT は見栄えは良いが、架空の店・見本（長浜）の店が混ざり、駅8分→10分、番号重複。Gemini は見本と合成しただけ・文字化け |
| 上級：店探し | 有料版の検索・Deep Research（どの社でも） | 実在確認は人が最後に見る |

## 4. 「表を入れたら場所が出てくるWebサイト」について（Miss Lemon の意見）

**必要です。そして、すでに試作があります。**

- 試作: 周辺MAPページ（`shuhen-osm.html`）。公開URL https://m19mhrts83-cyber.github.io/project-GE/shuhen-osm.html
- 表を貼る → OpenStreetMap の住所検索で場所を探す → 番号ピン・徒歩分（80m＝1分）→ A4 叩き台、まで**無料・ログインなし**で動く
- 普通のチャットは位置を正しく扱えない（10/28 の議論と検証の両方で確認）ので、「チャット＝表まで」「ページ＝地図と徒歩分」と役割を分けるのが一番簡単

初級向けに詰めたい点:

1. **画面を初級用に絞る**: いまは試作で、中級向けの機能（HTML 保存・仕上げ取り込み）も同じ画面にある。初級は「貼る → 地図にする → A4 にする」の3ボタンだけが見える形にしたい
2. **見つからない店の扱い**: 町名からの推定で置いた店は同じ場所に重なりやすい。初級では「見つからない／推定の店は×にしてよい」と案内するのが簡単
3. **無料地図の利用量**: OpenStreetMap の住所検索は1秒1件までの決まりがあり、大人数の同時利用には向かない。パイロット（2〜3名、30〜50名程度まで）はこのままで可。本展開の前に地図サービスを見直す（22_ の決定4と同じ）
4. **置き場所**: 会員に渡す URL を GitHub のままにするか、神大家側の場所（WeStudy からのリンク等）にするか
