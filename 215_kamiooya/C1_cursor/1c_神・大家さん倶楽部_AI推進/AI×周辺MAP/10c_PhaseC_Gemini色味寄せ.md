# Phase C — ベージュ／イラスト寄り下地寄せ

- **前提**: アプリで範囲確定した **ピンなしクリーン下地**（`基準_下地_Grandole_クリーン.png`）があること
- **原則**: 道路形状・東西を変えない。番号ピンは AI／ウォッシュに焼かず、**加工後に coords から再合成**
- **アプリ内ではやらない**: Maps API にベージュ／イラスト変換はない。**書き出し直後**が Phase C

関連: `10_フェーズAtoC_ハイブリッド方針.md` / 見本 `Gandole志賀本通_周辺MAP.pdf`


### コピペプロンプト（強化版・`11` と同旨）

```text
添付の地図画像を、もう一方の見本周辺MAPに近い「ベージュ紙面・簡略イラスト風」の下地に寄せてください。

成功条件（きれいな絵では合格にしない）:
①主要道路が追える
②南北感が崩れない
③色だけ寄った（道路・配置は入力のまま）

目標の見た目:
- 紙面のような暖かいベージュ／クリーム基調
- 街区は淡い塗りつぶし、道路は線としてはっきり残す（手描きガイドマップ風の簡略）
- 彩度は抑えめ。チラシの背景地図として使える静かさ

厳守:
- 道路の形状・交差・曲がり・東西南北の配置を変えない（新しい道や建物を描き足さない）
- 店名・丁目・POI・GoogleのUI・透かしを増やさない／復活させない
- 家並みのごちゃごちゃは簡略化してよいが、道路ネットワークは保持
- 衛星写真風・リアル写真風・3Dにしない
- 番号ピン・吹き出し・人物・料理イラストは描かない（下地のみ）

出力は地図下地1枚のみ。
```

## 合否ゲート（C0／C1・A/Bベージュ検証 共通）

**成功条件は「きれいな絵」ではない。** 次の3つが揃って初めて合格（チラシっぽさ・イラスト上手さは加点にしない）。

| 観点 | OK（必須） | NG→差し戻し |
|---|---|---|
| ①道路 | 主要道路が連続して追える | 道が消え／別の街に見える／付け替え |
| ②南北 | 南北感が崩れない（例: 北＝志賀本通寄り／南＝尼ケ坂寄り） | 駅の南北が逆転・潰れ |
| ③色だけ | 色味だけ寄った（道路・配置は入力のまま） | 描き直し／過加工で地理が読めない／色が変わっていないだけでも①②が崩れていれば不合格 |
| （付随）ピン再合成 | 番号が元座標に乗る | 焼き込みピンしかなくずれる |

合否チェック（目視メモ用）:

```text
□ 主要道路が追える
□ 南北感が崩れない
□ 色だけ寄った（きれいさ単独では合格にしない）
□ （再合成時）ピンや店名が焼き込まれていない
```
