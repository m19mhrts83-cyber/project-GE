## 0. 先に用意するもの（Canvaを開く前）

| # | 素材 | どこから |
|---|---|---|
| A | **クリーン地図PNG**（ピンを隠した状態のスクショ） | Step2 地図アプリ → トグル「ピンを隠す」ON → スクショ |
| B | **ピン付き地図PNG**（同じ画面でトグルOFF） | 同上。**画面を動かさずトグルだけ切替**（位置合わせのガイドに使う） |
| C | **文言（## H）** | Step1.2 の出力（H1物件名 / H2エリア一言 / H3Access / H4各ピン文言 / H5人物コメント） |

**最重要**: A と B は**同じ表示範囲**で撮る。スクロール・ズームを触ると重ねたときにズレる。

> Step3（下地色味寄せ）を通した PNG を背景に使ってもよいが、AI再描画のため細部が変わることがある。**位置の正確さを優先するなら A（Step2の素撮り）を背景にし、色味は Canva 側（手順3）で足す**のが安全。

---

## 1. A4横のデザインを新規作成

1. Canva トップ → 右上「**デザインを作成**」→ 「**カスタムサイズ**」
2. 単位を **mm** にして **幅 297 × 高さ 210**（A4横）→ 作成
3. ※「A4」プリセットは縦向き。無料プランは後からのリサイズ不可なので、**最初に横で作る**

---

## 2. 地図を背景に敷いて“動かないように固定”

1. 左メニュー「**アップロード**」→ A（クリーン地図）と B（ピン付き）を両方アップロード
2. **A をクリック**してページに配置 → 四隅をドラッグして紙面いっぱい（少し余白を残してもよい）
3. A を選択 → 右クリック → 「**ロック**」  
   → これで以後どれだけ作業してもA地図はズレない

---

## 3. 地図のトーンを“製本チラシ風”にやわらげる

1. 「素材」→ **四角形** を置く → 紙面全体を覆うサイズにする
2. 色を **ベージュ系**（例 `#F5EBDC`）にする
3. 上部ツールバー「**透明度**」を **20〜30%**（道路と駅名が読める範囲で）
4. その四角形も右クリック → **ロック**

これで「リアルな地図そのまま」感が抜け、イラストを乗せても浮かなくなる。

---

## 4. ピンの位置合わせ（ここが品質のキモ）

生成AIで位置がズレる問題を、この手順で完全に回避する。

1. **B（ピン付き地図）を配置** → A と**同じ大きさ・同じ位置**に重ねる
   - 正確に合わせるコツ: 上部「**位置**」→「配置」タブの **幅/高さ/X/Y** の数値を A と同じにする  
     （A の数値は、いったんロック解除して確認 → メモ → 再ロック）
2. B の**透明度を 40〜50%** にする（下のAが透けて見える状態）
3. 「素材」で **`マップピン`** や **`ロケーションピン`** を検索（左の「無料」フィルタON）  
   → B に見えているピンの真上に、Canvaのピンを1つずつ置く
4. 物件（自宅）だけは **`家 アイコン`**／**`家 いらすとや`** を検索して**赤系の家アイコン**にする（起点が一目で分かる）
5. 全部置き終わったら **B を削除**（ガイドはもう不要）

**ルール**: ピンに**番号やP表記は付けない**。識別は「アイコン＋店名ラベル」で行う。

---

## 5. 店名ラベルを作る（1個作って複製するだけ）

1. 「素材」→ **円/角丸四角** を選び、横長に伸ばす → 色 **白**、枠線 **細い黒**（ピル型ラベル）
2. その上に「テキスト」で店名（例: `ナフコトミダ杉栄店`）／フォントサイズ 10〜12pt
3. ラベル＋テキストを2つ選択 → 右クリック「**グループ化**」
4. あとは **⌘C / ⌘V で複製 → 文字だけ差し替え**（8個でも2〜3分）
5. 置き場所はピンのすぐ横。地図の線が読めなくなるほど大きくしない

---

## 6. 吹き出し（コメント）を貼る

1. 「素材」で **`吹き出し 手書き`** / **`ふきだし 手描き`** / **`吹き出し クレヨン`** を検索（無料フィルタON）
2. **エリア一言（H2）** ＝ 黄〜クリーム色の**大きめ**吹き出し（紙面の余白に1つ）
3. **各店のコメント（H4）** ＝ 白〜薄クリームの**小さめ**吹き出し（対象アイコンの近くに）
4. しっぽ（三角）を対象施設の側に向ける。**長い線で結ばない／点線で結ばない**
5. 文言は **Step1.2 の ## H をそのままコピペ**（自分で言い換えない＝誤情報防止）
6. 1個できたら**グループ化して複製**（フォント・サイズが揃う）

文のトーン例（製本チラシ相当）: 「カレーが有名なカフェです」「大抵の物は揃います」  
NG: 「絶品」「最強」「ご褒美」など誇大表現

---

## 7. いらすとや風の人物を置く（Canva内なら点数無制限）

1. 「素材」で **`いらすとや`** ＋ キーワード（例 `いらすとや 買い物`, `いらすとや 通勤`）を検索
2. 紙面の**縁・余白**に **2〜3体**（地図の上に大きく載せない）
3. 人物の口元に小さな吹き出し → **H5 人物コメント素材** を入れる（H5が空なら H2・H4 から短い口語を作る）
4. 紙面に「サキ」「ペルソナ」「日常コメント」などの**ラベルは書かない**

**ライセンス（重要）**: いらすとや公式規約に「**Canvaのみを利用し完成される資料であれば、商用目的でも20点の点数制限はありません**」とある（Canvaと提携済み）。  
→ Canva の素材パネルから入れる限り、募集チラシでも枚数を気にしなくてよい。  
→ 逆に、**いらすとや公式サイトからPNGを落として使う場合は「1制作物20点まで」**（21点以上は有償・1点1,100円）。**Canva内検索で入れるのが安全＆効率的**。

---

## 8. Access帯・タイトルを縁に置く

1. 「素材」→ 四角形を**左端に縦置き**（または下端に横置き）→ 薄いグレー／ベージュで塗る
2. その上に「テキスト」で **H3 Access** を貼る（`地下鉄名城線「志賀本通駅」 徒歩約7分` の形）
3. 上部にタイトル **`{物件名} 周辺MAP`**（太めフォント・24〜32pt）
4. 端で文字が切れないよう、**上下左右に5mm以上の余白**を残す（印刷時の裁ち落とし対策）

---

## 9. 書き出し（印刷用・共有用）

| 用途 | 手順 |
|---|---|
| 印刷・入居募集資料 | 右上「共有」→ ダウンロード → **PDF（印刷）**／トリムマークはチェックしない |
| LINE・メール共有 | 同 → **PNG** → サイズ「×2」 |

ファイル名例: `{物件名}_周辺MAP_YYYYMMDD.pdf`

---

## 10. 2件目以降を速くする（テンプレ化）

1. 完成デザインを右上「**ファイル**」→「コピーを作成」  
   → 新しい物件では **地図画像の差し替え＋テキスト差し替え**だけで済む
2. **パーツ棚を作る**: 2ページ目に「ピン／店名ラベル／吹き出し／人物」の完成パーツを並べて置いておく  
   → 必要なときに1ページ目へコピペ（毎回検索しなくてよい）
3. 運営・メンバーへ配る場合: 「共有」→「**テンプレートのリンク**」で渡すと、各自のアカウントに複製されて元が壊れない
4. Pro があるなら **ブランドキット**に色（ベージュ・赤ピン・文字色）とフォント2種を登録しておく

---

## 11. Canva AI の使いどころ（と、使ってはいけないところ）

| 機能 | 使う／使わない | 用途 |
|---|---|---|
| **マジック作文**（無料可） | ○ | 吹き出し文が長いときの**短縮・言い換え**。※事実の追加はさせない |
| **マジックメディア／Canva AI で画像生成**（無料は月あたり回数制限） | △ | **小物・アイコン単体**の生成（例「カフェカップのシンプルなイラスト」）。人物は素材で足りる |
| **マジックメディアで“地図そのもの”を生成** | **×** | Step4.1 と同じ幻覚（架空の駅・道の描き替え）が起きる。**地図は必ず Step2 の実地図** |
| **マジック消しゴム**（Pro） | ○ | 地図スクショの不要ラベル（無関係な店名・丁目名）を消す |
| **背景透過**（Pro） | △ | 素材の切り抜き。いらすとやは元から透過なので通常不要 |
| **マジックリサイズ**（Pro） | △ | A4横 → SNS用への転用 |
| **Canva AI に「周辺MAPを作って」と丸投げ** | **×** | レイアウトごと作り替えられ、位置の正しさが失われる |

**原則**: **地理＝Step2（実地図）／文言＝Step1.2（## H）／飾り＝Canva**。AIに地図と事実を作らせない。

## 12. 公開前チェック（印刷して確認）

- [ ] A4横1枚に収まっている（2枚に分かれていない）
- [ ] 家アイコンで物件位置が一目で分かる
- [ ] ピンに**番号・P表記がない**
- [ ] 施設ごとに「アイコン＋店名ラベル＋短いコメント」が揃っている
- [ ] Step1.2 に**無い店・駅を足していない**（幻覚防止）
- [ ] 徒歩分が Access（H3）と吹き出しで矛盾していない
- [ ] 誇大表現（絶品・最強・ご褒美）がない
- [ ] 端で文字が切れていない／地図の道路が読める明るさ
- [ ] 公開直前に、掲載店の**閉店・移転**を Googleマップで再確認した

## つまずきやすいポイント

| 症状 | 対処 |
|---|---|
| 地図が動いてしまう | A地図とベージュ四角形を**ロック**する（手順2・3） |
| ピン位置が合わない | ガイドB を A と**同じ幅/高さ/X/Y**にしてから重ねる（手順4） |
| 吹き出しがバラバラの見た目 | 1個作って**グループ化→複製**。新規検索で毎回違う素材を選ばない |
| 王冠マークで書き出せない | 素材検索の「**無料**」フィルタをONにして選び直す |
| 文字が地図に埋もれる | 白ラベルを下に敷く／ベージュ四角形の透明度を上げる |
| A4に収まらない | 装飾（人物・小物）を減らす。ページを増やさない |
