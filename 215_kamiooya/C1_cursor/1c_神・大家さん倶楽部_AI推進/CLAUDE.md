## 守ること

- **会員情報・金額・個人のメールアドレスは公開リポに入れない。** 新しく作るときは `.gitignore` に追加し、非公開側で保管する
- **本番反映**（会員に見える画面・DB・関数）は、松野さん本人の「本番反映OK」の一言があるまで行わない。新機能は段階公開スイッチ（off → owner → reviewers → all）で、まず松野さんだけに出す
- **外部送信**（Chatwork・LINE・メール等）は「送って」と言われても、送る直前に文面を見せて確認を取る
- **送信下書きの置き換え**（`4.送信下書き.txt` 等）はAI側が行う。松野さんに頼まない
- **新しい作業**は事前に見積もりを出し、運営の承認を得てから着手する（`docs/神大家運営_新規作業の事前見積もり承認ルール_20261029.md`）
- **Supabase** は Pro プランで運用中。プラン切替で場所が変わって混乱した経緯があるので、プロジェクト・組織・設定を変える作業は事前に松野さんに確認する
- **作業時間は必ず記録する。** 手順は `docs/神大家運営_作業項目と実行履歴_20261101.md`（`scripts/jarvis_kamiooya_work_history.py`）。本人時間とAI処理時間を分け、不明を0分にしない。請求に入れるかは松野さんが決める
- 反映作業（SQL・デプロイ等）は、松野さんの手作業を減らす形を優先して提案する
- `~/git-repos` の main には未コミットの変更があることが多い。main で直接作業せず、worktree（Orcaの作業スペース）で作業する
