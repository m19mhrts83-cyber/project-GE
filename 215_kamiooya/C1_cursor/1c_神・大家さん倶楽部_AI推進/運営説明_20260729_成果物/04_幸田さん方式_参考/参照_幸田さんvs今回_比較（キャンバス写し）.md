## 先に結論（要点）

幸田さん方式は ChatGPT+Gemini を往復して1枚絵を作り込む力作だが、位置ずれ・店名の幻覚を **10〜12回の手直し**で直す必要があった。  
今回は「実在検証プロンプト」で店を確定し、地図は **Google Maps API の実地図**を Canva に敷くため、位置と店名が崩れない。

いちばんの違い: **地図をAIに描き替えさせるかどうか**

| 指標 | 幸田さん | 今回 |
|------|----------|------|
| プロンプト回数 | 12回 | 5ステップ |
| 所要 | 毎回 30〜60分 | 初回は長め・2件目以降はテンプレ流用 |
| 地図の土台 | AIイラスト（描き替え） | **実地図** |

## 幸田さん方式（ChatGPT + Gemini）— 手順 0〜12

Google Map スクショ → AIでイラスト化 → 位置・色・ルート・名称を往復で微修正（30分〜1時間）

| # | ツール | 指示の内容 |
|---|--------|------------|
| 0 | 準備 | Snipping Tool で Google マップを切り出し（スクショ）してスタート |
| 1 | ChatGPT | この画像をイラスト風にして周辺マップを作成 |
| 2 | ChatGPT | 物件周辺マップに。S.masa を物件に。入曽駅からの最短ルートを強調。家や木々は除去 |
| 3 | ChatGPT | コンビニ・スーパー・銀行・病院・マクドナルドをマークではなく建物イラストに。最短ルート徒歩6分。全体をかわいく |
| 4 | ChatGPT | さがみ典礼を除去。ヤオコーはオレンジ色。駅前にイオンタウンをさりげなく追加 |
| 5 | ChatGPT | 物件位置が違う。水色の位置に訂正 |
| 6 | Gemini | 「この物件」を水色矢印の●に移動。赤点線もそこまで引く |
| 7 | Gemini | 最短ルートを消す |
| 8 | Gemini | 青●を消す。入曽駅→物件を赤点線でつなぐ |
| 9 | Gemini | 信号方向へ向けた点線を消す |
| 10 | ChatGPT | 日本語の文字をはっきりさせる |
| 11 | ChatGPT | 名称違い8件を実名に訂正（幻覚した店名 → 正しい店名） |
| 12 | ChatGPT | 最短ルート約540m。不要店を削除。物件名を変更 |

出典: 成果報告共有.pptx（周辺マップの作成方法 2/3・3/3）

## 今回（松野）の方式 — 手順 1.1〜Canva

AIで候補 → 実在検証 → 実地図で位置確定 → 色味把握 → Canvaで仕上げ（**本線**）

| # | 工程 | 内容 |
|---|------|------|
| 1.1 | 作成プロンプト | 住所・物件名・ターゲットから周辺施設・Access・コメントの候補を出す（たたき台） |
| 1.2 | 実在検証（Deep Research） | 候補を1件ずつ検索して実在・営業を確認し、幻覚・閉店を除外。評判店を補完。**## E（位置）**と **## H（文言）**を出力 |
| 2 | 地図アプリ | shuhen-map（Google Maps API）に ## E を投入 → 背景地図と施設位置を自動生成。駅→物件の動線つき。クリーン／ピン付きをスクショ |
| 3 | 下地色味寄せ | 色味を1回だけ試し、紙面イメージを掴む（完璧は求めない） |
| C | **Canva 仕上げ** | 実地図を背景に固定し、## H の文言でピン・吹き出し・いらすとや風人物を手置き（本線） |

## 観点別の比較（スライド s2c 用・1枚に収める表）

| 観点 | 幸田さん方式 | 今回（松野） |
|------|--------------|--------------|
| 地図の作り方 | Google Map のスクショを AI で「イラスト風」に描き替え | Google Maps API の**実地図**をそのまま背景（描き替えない） |
| 位置の正確性 | AIが位置をずらす → 毎回プロンプトで手直し | 実地図なので位置がブレない |
| 施設名の信頼性 | 幻覚した店名を後から口頭で8件訂正 | 実在検証プロンプトで先に除外・確定 |
| ツール | ChatGPT + Gemini を往復（Copilot非推奨） | Raimoプロンプト群 + 地図アプリ + Canva |
| 手戻り | 10〜12回の微修正（位置・色・ルート・名称） | 検証を先に済ませ、仕上げはCanvaで手置き |
| 所要時間 | 毎回 30分〜1時間 | 初回は長め・2件目以降はテンプレ流用で短縮 |
| 再現性 | 作り込めるが個人差・修正回数に依存 | 手順化されており誰でも同水準を狙える |
| 仕上げ | AIの1枚絵（トーンは出るが直しにくい） | Canvaで手置き（品質・修正しやすさが高い） |

## 両方式の長所（用途分け用）

### 幸田さん方式が優れている点

- ツールが ChatGPT / Gemini だけで完結し、追加アプリが不要
- イラスト調のトーンが1枚絵で一気に出る
- 「AIでここまで作れる」学習の入口として分かりやすい

### 今回の方式が優れている点

- 地図が実地図なので位置・道・駅が崩れない
- 店名を先に実在検証するので幻覚を載せない
- 手順化され、2件目以降はテンプレ流用で速い

### 結論（話者メモ）

幸田さん方式は **挑戦枠・学習の入口**として残し、全員展開の本線は **「AIでネタと下地 → Canvaで仕上げ」**。
