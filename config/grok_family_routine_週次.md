# Grok ルーティン「家族コーチング · 週次」— 指示コピペ用

Grok チャンネル **家族コーチングチーム** のルーティン UI に貼る。  
Bot 恒久ルールの正本は `config/grok_family_manager_grok_paste.md`（こちらはスケジュール起動文だけ）。

材料（Journal週次）は **Jarvis が Notion に置く**（**金締＝土〜金**・日曜 08:00 投影）。Grok は Notion を自分で読む（チャット貼付待ち禁止）。

## ルーティン設定（推奨）

| 項目 | 値 |
|---|---|
| 名前 | `家族コーチング · 週次` |
| 投稿先 | **家族コーチングチーム** |
| Active | ON |
| トリガー | スケジュール **毎週日曜 21:00（JST）**（家族会議のあと・ユーザー確定） |
| 役割 | 家族コーチ統括が司令。専属3本は @委譲で動く |

家族会議が日曜夜より遅いときは、時刻を会議後にずらす。  
同じ週に初回フル／手動「今週の材料」を既に投げてまとめが返っているなら、ルーティンは重複せず1行スキップ。

## 指示（そのまま貼る）

```
チャンネル「家族コーチングチーム」で週次コーチングを実行する。
今週すでに【今週の材料】または【今週の材料 · 初回フル】でまとめ1通が返っているなら、重複実行せず「週次は完了済み」と1行だけ返す。

【実行順・厳守】
1. 家族コーチ統括が開始宣言:
【週次パック · 方式C】Notion読取 → 専属へ振分け → 松野向け1通

2. 統括が Notion を自己読取（貼付待ち禁止）
参照順:
- 家族会議の直近の日付付き子ページ
- 子供コーチング配下の Journal週次（最新週）
- 必要なら円香／珠己／紗和ページ
読めたら1行: Notion読取: OK · 家族会議 YYYY-MM-DD · Journal週次 {週}
読めないとき: Notion読取: NG · 理由… で止めてよい（推測で埋めない）

3. 統括が専属へ @委譲（方式C）
@まどかコーチ @たまきコーチ @さわコーチ
各人に Notion から要約した事実だけ渡す。親への助言と「今夜やること1つ」を返させる。
完了をチャンネルに1行。

4. 統括が松野向けにまとめフォーマットで1通
- まどか／たまき／さわ（助言＋親が今夜やること1つ）
- マサハルQOL 1ブロック（帰宅後ゾーン・睡眠・家族と仕事のバランス）
- 全体の優先 最大3
- 能動提案（材料が薄いときほど質問を厚く）
- 日報メールは送らない

【禁止】
- 松野に専属へ手動転送させること
- 子ども本人への説教文を Bot が送る前提
- 学校・塾への自動メール／電話
- 不動産・アプリ開発・パスワード
- Notion を読めるのに「貼ってください」で止まること
```
