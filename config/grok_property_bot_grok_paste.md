## 調査手順

### 0. 耐震区分（最初に確認 · 必須）

**調べた物件が「新耐震」か「旧耐震」かを必ず先に判定**する。

| 区分 | 目安 |
|---|---|
| **新耐震** | 建築確認が **1981-06-01（昭和56年6月1日）以降** |
| **旧耐震** | それより前（築年のみのときは「築年ベース推定」と明記） |

- ポータルの **築年月／建築年月**、可能なら確認申請日を見る。不明なら `不明`＋確認方法1行
- **旧耐震の戸建**は火災保険等が高くなりやすい（紙屋さん情報 2026-08-29）。運用目安として **年あたり約10万円級の追加負担** を織り込（実額は見積で上書き）
- `[Grok調査]` の **## 耐震** に必ず書く。旧耐震なら総合理由に1行入れる
- 旧耐震だけで即見送りはしない（土地値・HZと総合）。買付時の減額交渉は **S6** へ引き渡し

### 1. 相続税路線価

chikamap → 倍率なら rosenka.nta.go.jp → 土地値%（土地積算／価格×100）→ 判定

| 種別 | 聞く寄りの土地値%目安 |
|---|---|
| **戸建** | **100%超** |
| **一棟アパート** | **150%前後**（目安 140〜170。フルローン≒価格に対する土地値） |

APで土地値が薄い／区分のみは原則見送り。

### 2. ハザード

disaportal.gsi.go.jp → 洪水・土砂・高潮・内水 → 評価 OK|注意|除外（原則除外）

### 3. 人口（簡易）

チャプロ軸: 安全|選別|攻め

### 4. 一棟アパート · 滋賀銀行枠（必須チェック）

地主大家情報（2026-08-30）:
- 滋賀銀行は **土地値あり・価格1000〜3000万** の一棟APでフルローン余地あり
- **家賃収入が給与を上回ると使えなくなる**
- 個人APは **あと1棟まで**（`remaining_shiga_slots: 1`）。枠消化後は副線AP探索を原則止める

聞く判定に含める1行例:
`融資: 滋賀銀行候補|非候補 · 枠: 残1|枠なし · 土地値%/価格: …%`

### 5. 利回り・返済比率（戸建は必須 · APは補助）

正本: `config/grok_property_search_criteria.yaml` → `buy_economics`

| 段階 | 戸建の目安 |
|---|---|
| **聞く（表面）** | 表面利回り **≥10%**。未満は原則保留\|見送り（土地値だけ良くても厳しい） |
| **買う（交渉後）** | 修繕費を織り込み価格交渉で **15〜20%** に持っていける見込み |
| **返済比率** | 金利上昇込みで **年返済÷満室年収 ≈50%** 付近（概算フラグ。確定計算は /roi · S7） |
| **ストレス金利** | 楽天等の高金利帯は目安 **年7%前後**（断定しない。案件で上書き） |

- AP: 土地値150%が主。表面は最低 **8%** 目安
- **地場への初回文面に利回り%は書かない**（内部評価のみ）
- `[Grok調査]` に **## 収支・利回り** を必ず書く
