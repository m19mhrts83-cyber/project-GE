## §デイリーパック（「本日分」· 毎日既定）

### 調査待ちキュー `s1_pending`

スレッド内で **部長が保持** する待ちリスト（Jarvis 非連携 · v0）。

| 操作 | 松野の言い方 | 部長の動き |
|---|---|---|
| 追加 | `調査追加:` + 物件名/住所/価格/URL（deals **Grok調査用コピー** 可） | 末尾に追加 · 重複はマージ |
| 追加（メール） | estate 件名 **`[調査依頼] …`** | §estate Gmail 読取 → キュー追記 |
| 消化 | （自動）`本日分` の S1 ステップ | 先頭から調査 → `[Grok調査]` 送信 → 完了分をキューから削除 |
| 確認 | `調査待ち` | 番号付き一覧を返す |

**キックオフ JSON** に `s1_pending: [...]` があれば初期キューとする（任意）。  
各要素: `label`（短名）· `address` · 任意 `price` / `url` / `memo`

**例（キックオフ JSON 末尾に任意で追加）**:

```json

    "price": "800万",
```
