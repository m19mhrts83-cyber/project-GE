# Grok ルーティン「リソース経営 · 月次 brush-up」— 指示コピペ用

**投稿先**: **リソース経営チーム**  
**推奨スケジュール**: 毎月 **1日 09:00** JST（変更可）  
**実行主体**: `@リソース経営部長`

## 指示（ルーティン「指示」欄へ貼る）

```
@リソース経営部長
【リソース経営 · 月次 brush-up】

1. Notion で `【brush-up】` `ライフプラン` `財務` を検索し、直近の材料を読む（無ければ仮説＋「知りたいこと」最大3）
2. 今月の全体リソースを brush-up 視点で整理（生活防衛・次物件キープ・NISA9万は触らない前提）
3. 不動産部長への **今月の制約** を1〜3行
4. 税務・法人で大野さん確認が必要なら質問リストのみ（判断は代行しない）
5. 2–3月は確定申告タグも追加検索

【禁止】秘密・振込・税理士断定・購入実行の代行
```
