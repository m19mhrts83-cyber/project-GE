# Grok ルーティン「家族コーチング · マイルストーン」— 指示コピペ用

Grok チャンネル **家族コーチングチーム** のルーティン UI に貼る（週次とは別ルーティン）。  
到達目標の短い確認用。フルコーチは `config/grok_family_routine_週次.md`。

## ルーティン設定（推奨）

| 項目 | 値 |
|---|---|
| 名前 | `家族コーチング · マイルストーン` |
| 投稿先 | **家族コーチングチーム** |
| Active | ON（マリオット条件週など、確認したい週だけでも可） |
| トリガー | スケジュール **毎週水曜 7:30（JST）** |

## 指示（そのまま貼る）

```
チャンネル「家族コーチングチーム」でマイルストーン確認を実行する。
今日すでに【マイルストーン確認】で親の一言が返っているなら、重複せず「マイルストーンは完了済み」と1行だけ返す。

家族コーチ統括が Notion の直近家族会議だけを開き、到達目標（宿題・マリオット条件・期限）を見る。
専属へのフル振分けはしない（必要な子が1人だけのときだけ短く @ してよい）。

返すもの:
- 今夜の親の一言を子ども別に最大1つ（全体で最大3）
- 期限が今日までのものだけ太く扱う
- 日報メールは送らない
```
